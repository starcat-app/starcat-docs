## What this is for

What GitHub can rebuild, and what is gone if you delete the folder. Stack: GRDB.swift + FTS5. Shipping apps use versioned migrations. **Do not delete the database to “fix” it.**

| Data | Rebuildable? |
|------|----------------|
| Repo metadata / README cache | Yes |
| Tags / notes / status / collections | **No** |
| AI / RAG history | Back up if you care |
| AI summary cache | Regenerable |

Keychain: GitHub OAuth / PAT, AI keys, local integration secrets.

App Store and Direct use different containers and **do not share data**. See [Install](/getting-started/installation). GitHub accounts are isolated locally; switching accounts does not wipe the other. Cloud sync is not shipped. See [Backup](/data-privacy/backup).
