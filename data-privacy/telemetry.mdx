## Purpose

Whether coarse product metrics leave this Mac, and what a support pack contains. Path: Settings → Diagnostics → Anonymous telemetry (off by default).

May include: allow-listed event names (launch, open Manage, search, sync start/end), app version, coarse buckets. Does not include: GitHub username, Stars contents, query strings, README, notes, AI prompts / responses, API keys, local paths. The pipe is Aptabase-like; the privacy policy wins.

Menu export: version, database status, recent errors (redacted), sync hints. Send [dong4j@gmail.com](mailto:dong4j@gmail.com).
