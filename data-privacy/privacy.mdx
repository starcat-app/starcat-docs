## 原则摘要

Starcat 以**本地优先**为默认：

- 标签、笔记、状态等用户数据优先只在本机  
- 不出售个人数据、无广告追踪  
- 不读取 GitHub 密码  
- AI Key 存 Keychain；笔记不用于「拿去训练你们的模型」这类用途  

完整法律文本以官网为准：[starcat.ink/privacy](https://starcat.ink/privacy)。

## 数据分类

| 类型 | 例子 | 可否从 GitHub 重建 |
|------|------|--------------------|
| 仓库缓存 | 元数据、README | 可以 |
| 用户数据 | 标签、笔记、状态、集合规则 | **不可以** |
| 密钥 | GitHub Token、AI Key | Keychain |

跨设备云同步尚未上线 → [备份](/data-privacy/backup)。

## AI 与第三方

- **BYOK**：请求发往你配置的 Provider → [BYOK](/subscribe/byok)  
- **外部搜索**：仅在启用时把查询发给对应 Provider → [外部搜索](/search/external-search)  
- **分享**：卡片导出或公开链接需你主动操作 → [分享卡片](/share-export/share-cards)  

## 遥测

匿名遥测**默认关**，在 **设置 → 诊断** 开启。详见 [遥测](/data-privacy/telemetry)。
