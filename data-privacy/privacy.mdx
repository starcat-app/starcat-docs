## 隐私保护

Starcat 将隐私保护作为核心设计原则。

## 隐私原则

### 本地优先

- 你的数据（标签、笔记、状态、设置）优先存储在本地
- 没有你的明确操作，数据不会离开你的设备

### 数据分离

- **仓库缓存**：可以从 GitHub 重建，不包含个人信息
- **用户数据**：标签、笔记等，是你个人创造的内容，受到保护

### AI 隐私

- **BYOK 模式**：AI 请求直接到你配置的 Provider，不经过 Starcat 服务器
- Starcat 不会存储或转发你的 API Key
- AI 摘要的公开分享需要你的明确操作

## 数据收集

### 匿名遥测

Starcat 收集匿名的使用统计数据以改进产品：

- 功能使用频率
- 性能指标
- 崩溃报告

> 你可以选择关闭匿名遥测。

### 不上传的内容

- 你的 GitHub Stars 数据
- 你的标签、笔记
- 你的 README 浏览历史
- 你的 AI 对话内容
