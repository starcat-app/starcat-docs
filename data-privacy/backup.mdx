## 为什么要备份

标签、笔记、状态、智能集合规则等**无法从 GitHub 重新生成**。换机、重装、误点恢复出厂前，请先备份。

## 手动备份（推荐）

<Steps>
  <Step title="完全退出 Starcat">避免拷贝到正在写入的数据库。</Step>
  <Step title="复制数据目录">
    Direct 常见路径：
    ```text
    ~/Library/Application Support/Starcat/
    ```
    App Store 版在沙盒容器内，路径不同。可在 **设置 → 存储** 用 Finder 入口定位后再拷贝。
  </Step>
  <Step title="存到安全位置">外置盘 / 加密备份均可。</Step>
</Steps>

## 手动恢复

1. 完全退出 Starcat  
2. 将备份恢复到**同一渠道**对应路径（App Store 与 Direct 不要混用）  
3. 再打开 App

## 优先级表

| 优先级 | 数据 |
|--------|------|
| 高 | 标签、笔记、状态、集合规则 |
| 中 | AI / RAG 会话历史 |
| 低 | README / 图片 / 摘要缓存（可重建） |

Stars 列表可重新同步，一般不必单独备份。
