## Purpose

The first session only needs three things: sign in to GitHub, tap Sync to pull Stars, then open one repo and organize it a little. Tags, knowledge base, and AI can wait until you have data.

Signing in creates a session. The Getting Started checklist usually checks **Sync** only after you tap the toolbar control.

## Three steps

<Steps>
  <Step title="Connect GitHub">
    Use **Sign in with GitHub** or a PAT. The App Store build uses the system browser; Direct also offers Device Flow / PAT. Scopes and multiple accounts: [Connect GitHub](/getting-started/github-connection).
  </Step>
  <Step title="Tap Sync">
    After sign-in, tap **Sync** in the middle-column toolbar (the rotating-arrows icon).
    <Warning>
      Do not wait for the list to fill itself. Without Sync, it often stays empty.
    </Warning>
    - Progress shows on the sync control
    - Large libraries can take minutes; already-fetched rows are browsable meanwhile
    - If you synced recently, launch may skip auto-sync. Tap once anyway on day one.
  </Step>
  <Step title="Organize one repository">
    Sidebar **Manage → All Stars**:
    1. Select a row and read the README on the right
    2. Add a tag or a one-line note
    3. Heart long-term keepers into the [knowledge base](/knowledge-base/adding-repos)
  </Step>
</Steps>

## Getting Started checklist

After sign-in the main window may show a collapsible checklist (~10+ steps): sync, select a repo, open GitHub, ingest, organize, search, try AI, open RAG, share card, Unstar, and similar.

| Behavior | Detail |
|----------|--------|
| How it advances | **Real actions**, not a Next wizard |
| Dismiss | Fold or close anytime |
| Replay | **Settings → General → Replay first-run guide** (also resets checklist progress) |

The welcome screen includes feature shots. Some controls use yellow capsule hints (Sync, Search, AI) so they do not stack on system alerts.

## First-day actions

| You want to… | Do this |
|--------------|---------|
| Search local + GitHub + the web | **⌘K** [Search Center](/search/search-center) |
| Filter the current list | **⌘F** + [filters](/search/filters) |
| Open repo AI | **⇧⌘A** (needs [Pro](/subscribe/plan-comparison) and [AI configuration](/ai-features/configuration)) |
| Open RAG workspace | **⇧⌘K** or toolbar **Knowledge Q&A** |
| Follow versions | [Release subscriptions](/release/subscription) (free cap: 5 repos) |

Shortcuts are editable in [Shortcuts](/settings/shortcuts).

## Notes

- Sync is limited by the GitHub API. First full sync on a large account takes time; see [FAQ · Sync](/faq/sync).
- You can tag and take notes without AI. Pro is not a prerequisite for getting started.
- Private **My Projects** need a GitHub App install. See [My Projects](/main-interface/my-projects).
