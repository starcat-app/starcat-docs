## Goal

On first launch: **sign in → sync Stars → browse and organize one repository**.

## Three steps

<Steps>
  <Step title="Connect GitHub">
    Use GitHub sign-in or a PAT. Details: [GitHub connection](/getting-started/github-connection).
  </Step>
  <Step title="Tap Sync yourself">
    After sign-in, click the list toolbar **Sync** button to fetch Stars.
    <Warning>
      In the Getting Started checklist, Sync usually completes only when **you** tap Sync. Signing in alone is not a sync.
    </Warning>
    - Progress shows on the sync control
    - Large libraries may take minutes; already-fetched repos are browsable meanwhile
  </Step>
  <Step title="Browse and organize">
    Sidebar → **Manage → All Stars** (labels follow the app):
    1. Select a repo → read the README on the right
    2. Add tags or notes in the detail pane
    3. Heart a repo into the [knowledge base](/knowledge-base/overview) when ready
  </Step>
</Steps>

## Getting Started checklist

After sign-in you may see a collapsible checklist (~10+ steps): sync, select a repo, open GitHub, ingest, organize, search, try AI, open RAG, share card, Unstar, and more.

| Trait | Detail |
|-------|--------|
| Progress | Driven by **real actions**, not a “Next” wizard |
| Dismiss | Fold or close anytime |
| Replay | **Settings → General → Replay first-run guide** (also resets checklist progress) |

The first-run welcome includes feature screenshots. Some controls use yellow capsule hints (Sync, Search, AI, and similar) so they do not stack on system alerts.

|--------|------------------|
