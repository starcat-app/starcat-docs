## 快速上手

第一次打开 Starcat 只需几步，就能开始管理你的 GitHub Stars。

<Steps>
  <Step title="连接 GitHub 账号">
    启动 Starcat 后，你会看到登录页面。点击「使用 GitHub 登录」按钮：

    1. 浏览器会打开 GitHub 授权页面
    2. 登录你的 GitHub 账号并授权 Starcat
    3. 授权完成后自动返回 Starcat

    <Tip>Starcat 只需要 `read:user` 和 `public_repo` 权限，不会访问你的私有仓库。</Tip>
  </Step>

  <Step title="等待首次同步">
    登录成功后，Starcat 会自动开始拉取你的所有 Stars：

    - 同步进度显示在工具栏的同步按钮中
    - 首次同步可能需要几分钟（取决于 Star 数量）
    - 同步完成后，侧边栏会显示统计数据

    <Note>同步过程中你可以正常使用 Starcat，数据会逐步出现。</Note>
  </Step>

  <Step title="浏览你的 Stars">
    同步完成后，在左侧边栏选择「All Repos」即可浏览你的全部 Star 仓库：

    - **点击仓库**：右侧详情面板显示 README 和元数据
    - **搜索**：按 `Cmd+F` 打开全局搜索
    - **打标签**：在详情面板中为仓库添加标签

  </Step>
</Steps>
