## Requirements

| Requirement | Detail |
|-------------|--------|
| **OS** | macOS 15 Sequoia or later |
| **Chip** | Apple Silicon (M-series) |
| **Network** | Needed for GitHub sync, Explore, online purchase |
| **GitHub** | Account required to sync Stars |

Desktop clients are macOS-only. CLI can run on more platforms, but data still comes from a paired Starcat app.

## Download channels

### Mac App Store

- [Starcat for GitHub](https://apps.apple.com/cn/app/starcat-for-github/id6788809803?mt=12)
- Auto updates; App Store **sandbox**
- Pro via StoreKit (Apple ID)

### Direct (website)

- [starcat.ink](https://starcat.ink)
- Download DMG → drag to Applications
- Updates via **Sparkle**
- Pro via web checkout + license key

<Warning>
  App Store and Direct builds use **separate local data directories**. Switching channels means a new local library—back up first; do not copy database files blindly.
</Warning>

## Install steps

<Steps>
  <Step title="Download">Get the latest build from the App Store or website.</Step>
  <Step title="Install">
    - App Store: installs into Applications automatically
    - Direct: open the DMG and drag Starcat to Applications
  </Step>
  <Step title="First launch">
    If Gatekeeper blocks: System Settings → Privacy & Security → Open Anyway.
  </Step>
  <Step title="Onboarding">
    Full-screen welcome appears once. Replay later from **Settings → General** (resets Getting Started checklist progress).
  </Step>
</Steps>

## Updates

| Channel | How |
|---------|-----|
| App Store | Auto-detects a new version on launch or when the app becomes active again. You can also choose **Check for Updates** from the **Actions** menu or the menu bar, then upgrade in the Mac App Store. Starcat does not download the store package itself. |
| Direct | **Sparkle** checks on launch; you can also check and install from Settings or the **Actions** menu |
