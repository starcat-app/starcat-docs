## 系统要求

| 要求 | 说明 |
|------|------|
| **操作系统** | macOS 15 (Sequoia) 或更高版本 |
| **芯片** | Apple Silicon (M1 / M2 / M3 / M4 系列) |
| **网络** | 需要互联网连接以同步 GitHub 数据 |
| **GitHub 账号** | 需要 GitHub 账号以使用 Star 同步功能 |

> **注意**：Starcat 目前仅支持 macOS，暂不提供 Windows / Linux 版本。

## 下载渠道

Starcat 提供两种分发渠道：

### App Store（推荐）

从 Mac App Store 下载可获得自动更新、最简安装体验。

<Note>
  App Store 版本受 Apple 沙盒保护，数据存储在沙盒容器中。
</Note>

### Direct 分发

从 [starcat.ink](https://starcat.ink) 下载 DMG 安装包，适合偏好手动管理的用户。

<Note>
  Direct 版本需要手动拖拽到 Applications 文件夹，更新通过 Sparkle 自动完成。
</Note>

## 安装步骤

<Steps>
  <Step title="下载 Starcat">
    从 App Store 或官方网站下载最新版本。
  </Step>
  <Step title="安装">
    - **App Store**：自动安装到 Applications 文件夹
    - **Direct**：打开 DMG 文件，将 Starcat 拖入 Applications 文件夹
  </Step>
  <Step title="首次启动">
    首次打开时，macOS 可能会提示确认。点击「打开」即可。

    > 如果系统提示「无法验证开发者」：前往「系统设置 → 隐私与安全性」中点击「仍要打开」。
  </Step>
</Steps>

## 版本更新

- **App Store**：通过 App Store 自动更新
- **Direct**：通过 Sparkle 框架自动检查更新，启动时或手动触发
