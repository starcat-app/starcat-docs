## GitHub Stars List

GitHub 在 2025 年推出了 Stars List 功能，允许用户在 GitHub 上将 Stars 组织到不同列表中。

Starcat 会同步你在 GitHub 上创建的 Stars List，在侧边栏的「Starred」区域展示。

## 功能说明

- **自动同步**：GitHub 上创建/修改的 List 会自动同步到 Starcat
- **本地查看**：点击 List 名称查看该列表下的仓库
- **双向一致**：Starcat 中的操作不会影响 GitHub 上的 List 结构

<Note>
  GitHub Stars List 是 GitHub 官方的功能，Starcat 仅作为查看和管理的增强界面。
</Note>

## 与标签的区别

| | Stars List | Starcat 标签 |
|---|---|---|
| **存储位置** | GitHub | 本地 |
| **跨设备同步** | GitHub 原生 | CloudKit |
| **自定义程度** | 简单分组 | 颜色、图标、层级 |
| **可见性** | 公开/私有（按 List 设置） | 仅本地 |

> 建议：用 Stars List 做公开分类，用 Starcat 标签做个人精细整理。
