## 是什么

GitHub 提供 [Stars Lists](https://github.blog/changelog/)（官方 Stars 分组能力；以 GitHub 当前产品为准）。Starcat 会把你的 List **同步到侧栏**，方便在本地浏览。

## 在 Starcat 里能做什么

| 能力 | 说明 |
|------|------|
| 同步查看 | GitHub 上创建/调整的 List 会反映到侧栏 |
| 打开列表 | 点击 List 名称查看其中仓库 |
| 批量移动 | 多选时可能提供「移动到 List」（以 App 为准） |

List 的结构以 GitHub 为准；不要把 Starcat 标签体系等同于 List。

## 与标签对比

| | Stars List | Starcat 标签 |
|--|------------|--------------|
| 存哪里 | GitHub | 本机 |
| 跨设备 | 随 GitHub 账号 | 本机（云同步[尚未上线](/data-privacy/backup)） |
| 自定义 | 相对简单的分组 | 颜色、图标等更细 |
| 可见性 | 按 List 公开/私有设置 | 仅本机 |

**建议**：需要跟 GitHub 网页一致的分组用 List；个人精细分类用[标签](/manage-stars/tags)。
