## What they are for

GitHub’s own [Stars Lists](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars) group Stars on your account. Starcat **syncs those lists into the sidebar** so you can open them locally instead of grouping in the browser.

They are not “cloud tags”. Lists live on GitHub; tags live on this Mac.

## What you can do in Starcat

| Capability | Detail |
|------------|--------|
| Sync and browse | Lists you create or edit on GitHub show up in the sidebar |
| Open a list | Click the name to see its repositories |
| Batch move | Multi-select may offer Move to List |

The structure follows GitHub. Do not invent a parallel “fake List” inside Starcat.

## vs tags

| | Stars List | Starcat tags |
|--|------------|--------------|
| Stored | GitHub | This Mac |
| Other devices | Follows the GitHub account | This Mac ([cloud sync not shipped](/data-privacy/backup)) |
| Shape | Groups | Color, icon, fine classification |
| Visibility | List public / private | This Mac only |

Use Lists when the grouping must match github.com. Use [tags](/manage-stars/tags) for personal taxonomy.
