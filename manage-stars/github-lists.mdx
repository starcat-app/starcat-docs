## What they are

GitHub offers [Stars Lists](https://github.blog/changelog/) (official Stars grouping; follow GitHub’s current product). Starcat **syncs your Lists into the sidebar** for local browsing.

## What you can do in Starcat

| Capability | Description |
|------------|-------------|
| Sync and view | Lists created or edited on GitHub appear in the sidebar |
| Open a list | Click a List name to see its repos |
| Batch move | Multi-select may offer **Move to List** (follows the app) |

List structure is authoritative on GitHub; do not equate Starcat tags with Lists.

## Tags vs Lists

| | Stars List | Starcat tag |
|--|------------|-------------|
| Stored | GitHub | This Mac |
| Cross-device | With GitHub account | Local only (cloud sync [not shipped yet](/data-privacy/backup)) |
| Customization | Relatively simple grouping | Finer control: color, icon, and more |
| Visibility | Per List public/private settings | Local only |

**Suggestion**: use Lists when you want grouping aligned with GitHub on the web; use [tags](/manage-stars/tags) for personal fine-grained classification.
