## What they are for

Tag thirty untagged Swift repos at once, or ingest everything marked **using**, instead of opening detail one by one. **Narrow the list first.** Do not multi-select hundreds of rows on raw All Stars.

## How to do it

1. Pick a sidebar category, then [filters](/search/filters) or ⌘F
2. Toolbar **Multi-select**, check rows
3. Choose an action on the bottom bar and confirm
4. Starcat usually exits multi-select and toasts a summary; Esc cancels

## Manage actions

| Action | Behavior | Watch out |
|--------|----------|-----------|
| Tags | Appends; does not clear existing tags | Free cap 20 tags |
| Ingest / remove from library | Changes ingest | [Ingest](/knowledge-base/adding-repos) |
| Unstar | GitHub API | **Cannot** undo in-app; extra confirm for many rows |
| Move to Stars List | If Lists are synced | [GitHub Lists](/manage-stars/github-lists) |

Explore more often Stars / Unstars or ingests. See [Explore overview](/discover/explore/overview).

## Notes

- Batch Unstar really unstars on GitHub.
- A full free tag quota will fail or gate batch tagging. Delete unused tags or upgrade Pro.
