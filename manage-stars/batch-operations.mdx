## 多选模式

批量操作可以一次性处理多个仓库，大幅提升整理效率。

### 进入多选模式

点击仓库卡片左侧的复选框。底部会出现浮动操作栏。

### 退出多选模式

点击操作栏的「取消」或按 `Esc` 键。

## 批量操作类型

### 批量打标签

1. 勾选目标仓库
2. 点击操作栏「标签」按钮
3. 选择一个或多个标签
4. 点击「应用」

> 批量打标签是**追加**操作，不会移除已有关联。

### 批量加入知识库

1. 勾选目标仓库
2. 点击操作栏「知识库」按钮
3. 确认加入

详见 [知识库](/knowledge-base/overview)。

### 批量 Star/Unstar

1. 勾选目标仓库
2. 点击「Unstar」批量取消收藏

<Warning>
  取消 Star 会调用 GitHub API，**不可撤销**。操作前请确认。
</Warning>

## 快捷全选

- 拖拽选择：在列表区域拖拽可快速选中连续仓库
- `Cmd+A`：全选当前列表
