## 何时用

- 清空一大批未分类：筛选后批量打标  
- 把「正在使用」批量入库  
- 探索里一次 Star / 入库多个榜单项目  

## 标准流程

<Steps>
  <Step title="收窄范围">侧栏选分类 + [筛选](/search/filters) / 列表搜索。</Step>
  <Step title="多选">工具栏 → 多选 → 勾选仓库。</Step>
  <Step title="执行">底部栏选动作并确认。</Step>
  <Step title="结束">通常自动退出多选并 Toast 摘要；或 Esc 取消。</Step>
</Steps>

## Manage 动作

| 动作 | 行为 | 注意 |
|------|------|------|
| 标签 | 追加，不删旧标签 | 免费标签上限 20 |
| 加入/移出知识库 | 改入库状态 | [入库](/knowledge-base/adding-repos) |
| Unstar | 调 GitHub API | 不可在 App 内一键撤销；多仓二次确认 |
| 移到 Stars List | 若已同步 List | [GitHub Lists](/manage-stars/github-lists) |

## Explore 动作

更常见：Star / Unstar、加入知识库。见 [探索概览](/discover/explore/overview)。
