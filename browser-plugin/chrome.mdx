## Chrome 浏览器插件

Starcat 的 Chrome 插件让你在浏览 GitHub 时直接查看和操作 Starcat 数据。

## 安装

从 Chrome Web Store 搜索「Starcat」并安装插件。

<Note>
  浏览器插件需要 Starcat 桌面应用在后台运行，因为插件通过本地 HTTP 代理与 Starcat 通信。
</Note>

## 功能

### GitHub 页面增强

在 GitHub 仓库页面上：

- 显示该仓库在你的 Starcat 中的标签
- 显示笔记内容
- 快速打标签/写笔记
- 显示是否已入库

### Token 配置

插件设置页面可以配置本地代理 Token，确保通信安全。

### 操作按钮

插件在 GitHub 页面注入 Starcat 操作按钮，与页面原生元素融合。

## 配置

在 Chrome 扩展管理页面 → Starcat → 选项：

- 设置本地服务地址
- 输入 Token
- 测试连接
