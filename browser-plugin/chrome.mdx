## What it is for

Let GitHub repo pages in Chrome read on-device notes and Health. The extension does not hold your Stars library. **Starcat must be running.**

## How to install

1. Starcat is installed and **running**
2. **Settings → Integrations**: Local API key and Browser Plugin (port, token)
3. Install the Chrome extension

Repo / release notes: [starcat-chrome-plugin](https://github.com/starcat-app/starcat-chrome-plugin). If it is on the Chrome Web Store, prefer the site or README install link.

```text
Chrome extension ──HTTP──► 127.0.0.1:port /plugin/v1/*
        Bearer token (same as Integrations)
                │
                ▼
         Starcat on this Mac
```

Quitting the app breaks the inject. Launch Starcat, then reload GitHub.

Verify on any starred GitHub repo page. You should see the enhance block ([features](/browser-plugin/features)). If not: extension permission, port / token, app running.

## Notes

A leaked token is a local API credential (lower risk while bound to 127.0.0.1; still do not screenshot Settings into a chat). Safari: [Safari extension](/browser-plugin/safari).
