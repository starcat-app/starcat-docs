## Safari 浏览器插件

Starcat 同样提供 Safari 浏览器插件，功能与 Chrome 插件一致。

## 安装

Safari 插件随 Starcat 桌面应用一起分发。在 Starcat 设置 → 浏览器插件中启用。

<Steps>
  <Step title="启用插件">
    在 Starcat 设置 → 浏览器插件中开启 Safari 插件。
  </Step>
  <Step title="在 Safari 中启用">
    打开 Safari → 设置 → 扩展，勾选 Starcat 扩展。
  </Step>
  <Step title="授权">
    允许插件访问 GitHub 页面。
  </Step>
</Steps>

## 功能

与 Chrome 插件相同：

- GitHub 页面增强
- Google 搜索结果中显示 Starcat 入库状态
- 标签同步
- 笔记写入

## 注意事项

- Safari 插件走 macOS 原生扩展机制
- 需要 Starcat 桌面应用在后台运行
- 首次使用需要在 Safari 中手动启用
