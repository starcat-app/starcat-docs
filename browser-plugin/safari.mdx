## How to set it up

Repo: [starcat-safari-plugin](https://github.com/starcat-app/starcat-safari-plugin)

1. Starcat is running
2. Port and token in **Settings → Integrations**
3. Install / trust the Safari extension per the README

Scope: [Features](/browser-plugin/features).

## Notes

Safari requires the extension to be enabled in Settings → Extensions. If nothing injects, use the same checklist as Chrome: app running, token match.
