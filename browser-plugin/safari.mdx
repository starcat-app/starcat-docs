## 状态

Safari 扩展与 Chrome Companion **共用本机 Local API** 模型。设置页可能已有入口；**功能完整度可能落后于 Chrome**，以当前扩展版本为准。

仓库：[starcat-safari-plugin](https://github.com/starcat-app/starcat-safari-plugin)

## 配置

与 Chrome 相同：

1. Starcat 运行中  
2. **设置 → 集成** 中端口与 Token  
3. 按仓库 README 安装 / 信任 Safari 扩展  

能力边界见 [功能说明](/browser-plugin/features)。
