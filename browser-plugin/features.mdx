## What it is for

A thin layer of **local Starcat** on GitHub repository pages so you switch to the desktop less. v1 is an enhancement, not the whole app in a browser.

## What v1 includes

| Capability | Detail |
|------------|--------|
| Similar repos | Read-only list (capped) |
| Wiki | Jump / open Wiki |
| Private notes | Edit on-device notes; usually **starred** repos only |
| Health / OpenSSF | Shows cached scores; does not fully recompute in the page |
| CodeFlow / Codebase buttons | Jump into the desktop app when those features are on |

**Out of v1:** full Inbox, desktop AI summary workflows, heavy context menus. Full AI stays in the app.

Traffic: `http://127.0.0.1:{port}/plugin/v1/...` with `Authorization: Bearer <token>`, all on localhost. Manage the token in [Integrations](/settings/integrations).

## Notes

| Symptom | Try |
|---------|-----|
| No inject | Is the app running? Is the extension enabled? Port / token match? |
| Notes locked | Is the repo starred? Did the token expire? |
| No Health | Is there a local cache? Open detail in the app to score it |
