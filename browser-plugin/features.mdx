## 浏览器插件功能详解

Starcat 浏览器插件在 GitHub 页面上注入增强功能，让你在浏览 GitHub 时无缝使用 Starcat。

## 核心功能

### 标签同步

- GitHub 仓库页面上显示你在 Starcat 中为该仓库打的标签
- 可以直接在页面上添加/删除标签
- 标签实时同步到 Starcat 桌面应用

### 笔记联动

- 显示该仓库的 Starcat 笔记
- 在浏览器中直接编辑笔记
- 保存后自动同步到桌面应用

### 入库标识

- 显示仓库是否已加入你的知识库
- 提供一键入库/移出操作
- 已入库的仓库有心形角标

### Google 搜索结果增强

在 Google 搜索结果中：

- GitHub 仓库结果旁显示 Starcat 标记
- 已 Star 的项目显示星标
- 已入库的项目显示心形

### AI 摘要

插件在 GitHub README 旁展示 Starcat 生成的 AI 摘要（需要 Pro）。

## 技术说明

- 插件通过本地 HTTP 代理与 Starcat 桌面应用通信
- 请求走 `localhost`，不经过外部网络
- Token 用于认证本地通信
