## The job

You are on a GitHub repository page and want the note you wrote before, plus the Health score already cached, without switching back to Starcat to search.

The browser extension is that layer on the page. Full AI stays in the app. The extension itself exists on both builds.

## What v1 includes

| Capability | Detail |
|------------|--------|
| Similar repos | Read-only list (capped) |
| Wiki | Jump / open Wiki |
| Private notes | Edit on-device notes; usually starred repos only |
| Health / OpenSSF | Shows cached scores; does not fully recompute in the page |
| CodeFlow / Codebase buttons | Jump into the desktop app when those features are on |

v1 does not include full Inbox, desktop AI summary workflows, or heavy context menus. Full AI stays in the app.

Traffic: `http://127.0.0.1:{port}/plugin/v1/...` with `Authorization: Bearer <token>`, all on localhost. Manage the token in [Integrations](/settings/integrations).

<DirectVersionBadge /> You do not want to paste a long key into the extension. Confirm the six-digit code in the app. Each browser is authorized on its own, and you can review or revoke it later. App Store 1.9.1 still asks you to type the token.

## Notes

| Symptom | Try |
|---------|-----|
| No inject | Is the app running? Is the extension enabled? Port / token match? |
| Notes locked | Is the repo starred? Did the token expire? |
| No Health | Is there a local cache? Open detail in the app to score it |
