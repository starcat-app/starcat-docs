## 添加入库

将仓库加入知识库会自动触发 README 下载和完整 RAG 索引构建。

## 入库方式

### 单个入库

在仓库详情面板中，点击 ❤️ 心形图标即可将仓库加入知识库。

### 批量入库

1. 在仓库列表进入多选模式
2. 勾选目标仓库
3. 点击操作栏「加入知识库」

### 自动入库

将仓库状态标记为「在用」时，可选择自动加入知识库。

### 从 RAG 工作台添加

在 RAG 工作台中，可以搜索并批量添加 Stars 到知识库。

## 入库后会发生什么

<Steps>
  <Step title="下载 README">
    自动拉取仓库的最新 README 文件。
  </Step>
  <Step title="构建分片索引">
    将 README 拆分为语义分片，建立关键词和向量索引。
  </Step>
  <Step title="可以检索">
    索引完成后，该仓库的内容即可以在 RAG 问答中被检索到。
  </Step>
</Steps>

## 移出知识库

在详情面板再次点击心形图标即可移出。移出不会删除本地缓存，但该仓库不再参与 RAG 检索。

## 知识库与 Stars 的独立性

- Star 一个仓库 **不会** 自动加入知识库
- Unstar 一个仓库 **不会** 自动移出知识库
- 两者完全独立管理
