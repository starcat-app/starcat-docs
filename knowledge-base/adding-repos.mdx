## Purpose

Ingest a repository so it enters the default RAG scope. Starcat then fetches README-like sources, chunks them, and builds keyword and vector indexes.

## How to ingest

| Method | Best for | How |
|--------|----------|-----|
| Detail heart / ingest control | One curated repo | Open detail → add to knowledge base |
| Multi-select | Dozens at once | [Batch operations](/manage-stars/batch-operations) |
| Search / Explore | Discover then keep | Ingest control on the result |
| Status prompt | Libraries you are using | When marking **using**, follow the prompt → [Status](/manage-stars/notes-and-status) |

Batch: toolbar multi-select → optionally [filter](/search/filters) → Add to knowledge base → open the [RAG workspace](/knowledge-base/rag-workspace) and watch coverage.

After ingest: fetch sources locally → chunk and index keywords / vectors (needs Embedding) → default RAG scope. Progress and failures: [Index management](/knowledge-base/index-management).

## Remove

Tap the ingest control again. The repo leaves default RAG. Whether local caches disappear immediately follows the app.

An empty library shows onboarding. A starred repo that was never ingested is outside default RAG.

## Notes

```text
Star   ──✗──► auto ingest
Unstar ──✗──► auto remove
Ingest ──✓──► may be unstarred
```

Ingesting too many at once raises both the Embedding bill and wait time. Prefer **using** and repos you reopen often.
