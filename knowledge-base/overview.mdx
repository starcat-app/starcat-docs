## 知识库是什么

知识库是你**主动入库**的精选仓库集合，供 RAG 工作台检索与问答使用。它和「全部 Stars」不是同一回事。

## Stars vs 知识库

| | Stars | 知识库 |
|--|-------|--------|
| 来源 | GitHub 收藏同步 | 你在 Starcat 标记入库 |
| 规模 | 可达数千 | 建议精选（常见几十～两百） |
| 列表搜索 | ✅ | ✅（也可限定 knowledge） |
| 默认 RAG 范围 | ❌ | ✅ 仅已入库 |
| 典型索引 | FTS 等 | 分片 + 关键词 + 向量 |

独立性（务必记住）：

- Star **不会**自动入库  
- Unstar **不会**自动移出知识库  
- 未 Star 但已入库：仍可问答，也可 [订阅 Release](/release/subscription)
