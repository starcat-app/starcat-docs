## 什么是知识库？

知识库是 Starcat 的核心差异化功能，将你的 GitHub Stars 转化为可对话的**个人技术知识库**。

### 与 Stars 的关系

| | Stars | 知识库 |
|---|---|---|
| **定位** | 收藏列表 | 知识资产 |
| **数量** | 可能有几千个 | 精选 50-200 个 |
| **用途** | 标记感兴趣的项目 | 沉淀可检索的知识 |
| **索引** | FTS5 关键词 | FTS5 + 向量 + 分片 |

> 知识库是你 **真正关注和使用的项目**，而不是随手 Star 的所有仓库。

## 核心能力

### RAG 问答

基于知识库内容进行问答，AI 会：

1. 理解你的问题
2. 从知识库中检索相关分片
3. 结合检索结果生成回答
4. 提供引用来源

### 分片索引

每个入库仓库被拆分为语义分片（Chunk），建立：

- **关键词索引** — FTS5 全文搜索
- **向量索引** — Embedding 语义相似度
- **元数据索引** — 语言、Star、更新时间等

## 知识库工作台

独立的 RAG 工作台窗口，提供完整的知识库交互体验。详见 [RAG 工作台](/knowledge-base/rag-workspace)。
