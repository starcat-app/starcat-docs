## 索引管理

知识库中的每个仓库都会被索引，建立多维度的检索能力。

## 索引类型

### 关键词索引 (FTS5)

基于 SQLite FTS5 的全文索引，支持：

- 关键词搜索
- 前缀匹配
- BM25 排序

### 向量索引 (Embedding)

基于 AI Provider 的 Embedding 向量索引：

- 语义相似度搜索
- 使用 vDSP 加速余弦相似度计算
- 本地向量缓存（SQLite BLOB）

### 分片索引 (Chunk)

README 按语义边界拆分为分片：

- 每个分片独立索引
- 支持分片级检索和引用
- 分片可用性状态（绿色/红色标记）

## 索引状态

知识库浏览器中查看每个仓库的索引状态：

| 状态 | 说明 |
|------|------|
| **待索引** | 刚入库，尚未开始索引 |
| **索引中** | 正在构建索引（显示进度） |
| **已索引** | 索引完成，可以检索 |
| **索引失败** | 索引过程中出错 |

## 增量索引

- 仓库 README 更新后，索引自动增量更新
- 支持手动触发单仓库重建索引
- Embedding 队列独立计数和分批消费

## 索引覆盖范围

索引构建覆盖范围为 Stars + 知识库的并集，未入库的外部仓库不参与 RAG 检索。
