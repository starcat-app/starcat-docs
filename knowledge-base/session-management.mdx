## 左栏能做什么

| 操作 | 说明 |
|------|------|
| 新建会话 | 开一条新问答线程 |
| 打开历史 | 回看过往问答 |
| 置顶 | 固定到列表前部（后置顶的通常更靠前） |
| 重命名 | 用主题名方便找回 |

切换会话时，未发送输入会按产品逻辑保留或提示，避免误丢。

## 导出

可将单次回答或会话 transcript 导出为 Markdown，便于：

- 贴进博客 / 笔记软件  
- 做技术调研归档  

入口在工作台菜单或会话操作中（以界面为准）。

## 存储与清理

会话占本地磁盘 → **设置 → 存储** 可清「RAG 会话历史」。见 [存储管理](/settings/storage)。

清理历史**不会**取消入库，也不会删标签笔记。
