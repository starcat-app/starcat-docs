## Purpose

The left pane of the RAG workspace lists Q&A threads. Start a new session when the topic changes. Export Markdown into a notes app if you want a copy outside Starcat.

## How to use it

| Action | Detail |
|--------|--------|
| New session | Start a fresh thread |
| Open history | Re-read past Q&A |
| Pin | Keep it near the top (later pins usually sit higher) |
| Rename | A topic name is easier to find later |

Unsent composer text is kept or confirmed when you switch, so you do not lose it by accident.

You can export one answer or a full transcript as Markdown. The control lives in the workspace menu or session actions (follow the UI).

## Notes

Sessions use local disk. **Settings → Storage** can clear RAG session history. See [Storage](/settings/storage).

Clearing history does not un-ingest repos or delete tags or notes.
