## What it is for

Ask **across ingested repos**: conflict strategies, how two libraries compare in an embedded setting. Single-repo README questions belong in [AI chat](/ai-features/chat). Default RAG does **not** scan Stars you never ingested.

## How to open it (Pro)

| Method | Detail |
|--------|--------|
| Shortcut | Default **⇧⌘K** ([editable](/settings/shortcuts)) |
| Toolbar | Knowledge Q&A |
| Other | Library page / related Smart Collection |

Requires [Pro](/subscribe/plan-comparison), Chat + Embedding in [Settings → AI](/settings/ai), and some [ingested](/knowledge-base/adding-repos) repos.

Layout: sessions (new / pin) | stream + composer + @ | citations / plan / index. Side panes are resizable and often restore. During generation you see retrieve / plan / generate steps and can collapse them. The UI stays usable during long thinking; plan substeps appear only after planning finishes.

## How to ask

1. Be specific, e.g. “Which local-first sync libraries in my knowledge base discuss conflict strategy?”
2. Optional: type `@` to pick repos; chips on top are removable. Use only / prefer / exclude as the UI defines them
3. Send and watch the timeline
4. Click citation chips → evidence on the right. See [Citations](/knowledge-base/citations)

An empty library onboards you to ingest from Smart Collections, Search, or Explore.

If External Search is live context: successful answers may mix web evidence; failures may send you to **Settings → Integrations → External Search**. See [External search](/search/external-search).

The gear edits inference backend, prompts, and retrieval. Prompts: [AI configuration](/ai-features/configuration).

**Direct:** you can pick local Codex CLI or Claude Code CLI and reuse their own login. The workspace detects install / version / path. The App Store build has no such path.

Generated [Insights](/main-interface/insights) can be removable read-only context. Custom prompts without the insights placeholder do not inject them silently.

## Notes

- The workspace is Q&A: it does **not** change tags / notes / status without confirmation. Mutate data in the tidy UI or [CLI `--apply`](/cli/usage).
- Low header coverage → [Index management](/knowledge-base/index-management).
- Export: [Sessions](/knowledge-base/session-management).
