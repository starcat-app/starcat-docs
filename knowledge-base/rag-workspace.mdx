## RAG 工作台 (Pro)

RAG 工作台是独立的问答窗口，让你与知识库中的仓库内容对话。

## 界面布局

工作台采用三栏布局：

```
┌─────────────┬──────────────────┬─────────────────┐
│  会话列表    │    问答区        │   引用与详情     │
│  Sessions   │   Q&A Area      │   Citations     │
├─────────────┼──────────────────┼─────────────────┤
│ · 置顶会话  │  AI 回答        │  引用分片展示    │
│ · 分组      │  执行时间线      │  元数据面板      │
│ · 会话列表  │  输入框          │                 │
│             │  @选择仓库       │                 │
└─────────────┴──────────────────┴─────────────────┘
```

## 开始问答

<Steps>
  <Step title="输入问题">
    在底部输入框输入你的问题。例如：
    - "React 中状态管理的最佳实践是什么？"
    - "有没有适合 Go 微服务的框架？"
    - "比较一下我收藏的几个 CSS 框架"
  </Step>
  <Step title="@ 选择仓库（可选）">
    在输入框中使用 `@` 符号选择特定仓库，限制检索范围。支持多选。
  </Step>
  <Step title="发送">
    点击发送按钮（上箭头图标），AI 开始：
    1. 制定检索计划
    2. 检索相关分片
    3. 生成回答
    4. 附上引用来源
  </Step>
</Steps>

## 回答解读

### 引用

回答中的引用标记 `[1]`, `[2]` 等对应右侧的引用详情，点击可查看原文片段。

### 执行时间线

点击回答上方的时间线，可以查看 AI 的完整执行过程：

- 计划制定
- 关键词/向量检索
- 重排序
- 上下文裁剪
- 回答生成

### 元数据面板

右侧面板展示知识库的统计数据：仓库数量、分片覆盖、语言分布等。

## 联网搜索

开启联网搜索后，RAG 可以结合网络上的最新信息回答问题。需在设置中配置外部搜索 Provider。
