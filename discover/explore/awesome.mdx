## Purpose

Awesome lists repos from theme lists such as awesome-go and awesome-rust, not from Stars already on this Mac. Open it from Explore → Awesome.

## How to pick sources

The first visit opens Choose Awesome sources. Later you can reopen Manage Awesome sources from the Awesome page.

| Source | Detail |
|--------|--------|
| Starcat curated | Public Awesome catalog from the explore service; check items and confirm |
| Custom | Paste a public GitHub repo (`owner/awesome-xxx`); it enables after a successful check |

Custom sources must be public. Archived or unavailable repos cannot be added. Sources, READMEs, and parse results stay in the local database for the current GitHub account.

Custom lists parse incrementally in the background. Progress shows on the source card. Ready items can be browsed before parsing finishes.

## How to browse

After you select a source, the middle column lists repos from that Awesome README. Opening one shows detail: Star, tag, [ingest](/knowledge-base/adding-repos), or [subscribe to Releases](/release/subscription).

The toolbar can refresh the current source. Catalog and items are cached locally; a brief network failure keeps the last good data.

## Notes

The custom URL must be publicly reachable on GitHub. Private awesome repos cannot be added.

Incremental parse progress on a card does not mean every README link is done.

Awesome discovery and the Stars list are separate. After you Star, go back to Manage to tag.
