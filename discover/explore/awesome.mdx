Sidebar **Explore → Awesome**. Use it to discover repositories from topic lists, not to re-browse Stars you already have.

## Choose sources

The first time you open Awesome, Starcat shows **Choose Awesome sources**. You can open **Manage Awesome sources** again from the Awesome page later.

| Source | What it is |
|--------|------------|
| Starcat curated | Public Awesome catalog from the Explore service; enable items and tap Done to save |
| Custom | Paste a public GitHub repository URL (for example `owner/awesome-xxx`); it is enabled as soon as validation succeeds |

Custom sources must be public repositories. Archived or unavailable sources cannot be added. Sources, READMEs, and parse results stay in the current GitHub account’s local database.

Custom lists parse incrementally in the background. Progress appears on the source card. You can browse entries that are already ready before parsing finishes.

## Browse a list

After you select a source, the middle column lists repositories from that Awesome README. Opening a row shows detail on the right, where you can Star, tag, [ingest](/knowledge-base/adding-repos), or [subscribe to Release](/release/subscription).

The toolbar can refresh the current source. The catalog and entries are cached locally; a brief network outage keeps the last successful data on screen.
