## Purpose

Hot lists high-heat repos. New releases lists projects that recently shipped a stable Release. Both come from Starcat’s discovery pool, not from local Stars. Whether to Star or ingest is still a separate step.

## Hot

Sidebar Explore → Hot. Source: Starcat discovery pool.

- Archived repos and forks are excluded
- Needs 1,000 Stars, or a composite heat threshold
- Heat considers Stars, Forks, Release downloads, and recent activity

Cache lasts 3 hours and is shared with Discover and New releases. After expiry the shared catalog is refetched and Hot is recomputed. On failure the last good cache stays, with a stale hint.

## New releases

Sidebar Explore → New releases. Source: GitHub Releases inside the discovery pool.

- Only projects with a stable Release in the last 180 days
- Drafts, prereleases, Releases with nothing to download, archived repos, and forks are excluded
- Default sort is last release time

Same 3-hour shared catalog. After expiry, projects and Release info are refetched. Failures keep the last good cache.

## Notes

After a find: optionally Star → tag / one-line note → [ingest](/knowledge-base/adding-repos) if you will keep it. Heat is not a fit score for a given stack. A recent Release is not a production-ready signal.
