## 热门项目

展示当前技术社区中热度上升的项目，数据由 Discovery API 提供。

### 热门信号

每个热门项目附带专属信号标签：

- **🔥 Trending Up** — 热度快速上升
- **⭐ Rising Star** — 新星项目
- **📈 Steady Growth** — 持续增长

## 新发布项目

展示最近发布或大版本更新的优秀开源项目。

### 新发布信号

- **🆕 New Release** — 新版本发布
- **🚀 Just Launched** — 全新项目首秀

## 筛选

- **语言筛选** — 按编程语言过滤
- **平台筛选** — macOS / iOS / Web 等
- **主题筛选** — AI / DevTools / Framework 等

## 与 Trending 的区别

| | Trending | 热门/新发布 |
|---|---|---|
| **数据来源** | GitHub Trending 页面 | Discovery API |
| **排序依据** | Star 增长速率 | 多维度评分 |
| **覆盖范围** | GitHub 当日热门 | 更广泛的项目库 |
| **更新频率** | 每日 | 每日 |

> 热门和新发布模块使用紧凑的本地缓存和分页机制，数据秒开。
