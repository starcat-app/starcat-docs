## 三个一级区域怎么选

| 区域 | 目的 | 文档 |
|------|------|------|
| **Manage** | 整理已有 Stars / 知识库 | [侧边栏](/main-interface/sidebar) |
| **探索** | 发现新项目 | 本页 |
| **Activity** | 动态与通知流 | [Activity](/discover/activity/activity) |

## 五种探索模式

| 模式 | 你在找什么 | 专页 |
|------|------------|------|
| **发现** | 综合推荐流；可按 topic / platform 筛 | 本页 |
| **趋势** | 近期热度变化 | [趋势](/discover/trending/trending) |
| **热门** | 高热度仓库 | [热门与新发布](/discover/explore/hot-and-new) |
| **新发布** | 新出现 / 新版本相关 | 同上 |
| **周刊** | 编辑精选周刊条目 | [周刊](/discover/weekly/weekly) |

数据来自 Starcat 的 discovery / trending / weekly 等服务，不是本机 Stars 镜像。

## 发现好项目之后

建议流水线：

1. 打开详情读 README  
2. 可选：Star  
3. 打标签或写一句笔记  
4. 长期要用 → [入库](/knowledge-base/adding-repos)  
5. 要追版本 → [订阅 Release](/release/subscription)（注意免费 5 仓限额）  

批量处理见 [批量操作](/manage-stars/batch-operations)。
