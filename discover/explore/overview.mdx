## What it is for

**Explore** finds projects you have not starred yet. It is not a mirror of local Stars. Data comes from Starcat discovery / trending / weekly services. Already-starred repos belong in [Manage](/main-interface/sidebar). GitHub notifications belong in [Activity](/discover/activity/activity) (default is **Notifications**, not All).

## Which mode

| Mode | You are looking for | Page |
|------|---------------------|------|
| **Discover** | Mixed recommendations; topic / platform filters | Below |
| **Awesome** | Curated or custom Awesome lists | [Awesome](/discover/explore/awesome) |
| **Trending** | Short-term attention | [Trending](/discover/trending/trending) |
| **Hot** | High-heat repos | [Hot and new](/discover/explore/hot-and-new) |
| **New releases** | Stable Release activity | Same |
| **Weekly** | Multi-source weekly items | [Weekly](/discover/weekly/weekly) |

To point at your own instance, see [Self-hosting](/self-hosting/overview).

## Discover

Sidebar **Explore → Discover**.

**Sources:** GitHub Search, repository metadata, and Release data.

**Inclusion:** high-attention repos, activity in the last 30 days, and projects that appeared in the last year. Ranking considers recent activity, topic fit, and platform match. The pool updates periodically and is **not** all of GitHub.

**Cache:** 3 hours, shared with Hot and New releases. Fresh cache is used first; after expiry the catalog is refetched; on failure the last good cache stays, with a stale hint. First open restores cached counts for Discover, Hot, New releases, and Weekly so you do not have to click each once.

## After you find something

1. Open detail and read the README
2. Optionally Star
3. Tag or write a one-line note
4. Long-term use → [ingest](/knowledge-base/adding-repos)
5. Follow versions → [Release subscription](/release/subscription) (free cap is 5 repos)

Batch: [Batch operations](/manage-stars/batch-operations).

## Notes

- Explore filters are not the same set as Manage. Do not expect the All Stars funnel.
- To search unstarred repos on purpose, use [Search Center · GitHub scope](/search/search-center). Use this section to browse lists.
