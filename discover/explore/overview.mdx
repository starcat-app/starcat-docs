## Purpose

Explore lists projects that are not in local Stars yet. Data comes from Starcat discovery, trending, and weekly services. Already-starred repos belong in [Manage](/main-interface/sidebar). GitHub notifications belong in [Activity](/discover/activity/activity), which opens on Notifications rather than All.

## Which mode

| Mode | You are looking for | Page |
|------|---------------------|------|
| Discover | Mixed recommendations; topic / platform filters | Below |
| Awesome | Curated or custom Awesome lists | [Awesome](/discover/explore/awesome) |
| Trending | Short-term attention | [Trending](/discover/trending/trending) |
| Hot | High-heat repos | [Hot and new](/discover/explore/hot-and-new) |
| New releases | Stable Release activity | Same |
| Weekly | Multi-source weekly items | [Weekly](/discover/weekly/weekly) |

To point at your own instance, see [Self-hosting](/self-hosting/overview).

## Discover

Sidebar Explore → Discover.

Data comes from GitHub Search, repository metadata, and Release data.

The pool includes high-attention repos, activity in the last 30 days, and projects that appeared in the last year. Ranking uses recent activity, topic fit, and platform match. The pool updates periodically and is not all of GitHub.

Cache lasts 3 hours and is shared with Hot and New releases. Fresh cache is used first; after expiry the catalog is refetched; on failure the last good cache stays, with a stale hint. First open restores cached counts for Discover, Hot, New releases, and Weekly so each item does not have to be opened once.

## After you find something

1. Open detail and read the README
2. Optionally Star
3. Tag or write a one-line note
4. Long-term use → [ingest](/knowledge-base/adding-repos)
5. Follow versions → [Release subscription](/release/subscription) (free cap is 5 repos)

Batch: [Batch operations](/manage-stars/batch-operations).

## Notes

Explore filters are not the same set as Manage. The All Stars funnel does not apply here.

To search unstarred repos on purpose, use [Search Center · GitHub scope](/search/search-center). Use this section to browse lists.
