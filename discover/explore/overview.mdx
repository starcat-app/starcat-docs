## 探索页

探索页汇集了多种发现新项目的渠道，帮助你扩展技术视野。

## 四大模块

| 模块 | 内容来源 | 更新频率 |
|------|----------|----------|
| **发现** | Discovery API 智能推荐 | 每日 |
| **热门** | 社区当前热门项目 | 每日 |
| **新发布** | 近期新发布的开源项目 | 每日 |
| **趋势** | GitHub Trending | 每日/周/月 |

## 界面布局

```
┌──────────────┬────────────────────┬──────────────────┐
│  模块导航     │     项目列表        │    项目详情       │
│              │                    │                  │
│ · 发现       │  排序 · 筛选       │  README          │
│ · 热门       │                    │  推荐理由         │
│ · 新发布     │  项目卡片列表      │  信号标签         │
│ · 趋势       │  (UnifiedRepoRow)  │  Release 信息     │
│              │                    │  AI 摘要          │
└──────────────┴────────────────────┴──────────────────┘
```

## 使用方法

1. 在侧边栏点击「Explore」
2. 选择子模块（发现/热门/新发布/趋势）
3. 浏览项目，支持排序和语言筛选
4. 点击项目查看详情
5. 感兴趣可以直接 Star 或加入知识库

## 快捷操作

- **Star**：点击星标按钮一键收藏到 GitHub
- **入库**：点击心形按钮加入知识库
- **查看详情**：点击展开 README 和元数据

> 探索页的项目数据通过 Discovery API 下发，享受本地缓存加速。
