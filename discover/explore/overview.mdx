### Data source

GitHub Search, repository metadata, and Release data.

### Selection rules

- Starcat includes high-attention projects, projects active in the last 30 days, and new projects that appeared within the last year.
- Recommendations weigh recent activity, topic relevance, and platform fit.
- The project pool updates regularly and does **not** represent every repository on GitHub.

### Cache

- **TTL**: 3 hours; shares one project-catalog cache with Hot and New releases.
- **Refresh**: Prefer local cache while valid; refetch the catalog after expiry.
- **Offline**: On update failure, keep the last successful cache and note that content may be stale.

## After you find something good

Suggested pipeline:

1. Open detail and read the README  
2. Optional: Star  
3. Tag or jot a short note  
4. Long-term use → [Ingest](/knowledge-base/adding-repos)  
5. Track versions → [Subscribe to Release](/release/subscription) (free **5**-repo limit)  

Batch work: [Batch operations](/manage-stars/batch-operations).
