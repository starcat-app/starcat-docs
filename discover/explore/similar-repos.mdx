## 桌面端（Pro）

在仓库详情操作区打开 **相似仓库 / 推荐**。

- 需要网络访问推荐服务  
- 用于发现替代实现或同领域项目  
- 非 Pro 会遇到付费墙  

见 [方案对比](/subscribe/plan-comparison)。

## 浏览器插件

GitHub 仓库页可展示只读推荐列表（通常有条数上限）。需本机 App + [集成设置](/settings/integrations)。见 [插件功能](/browser-plugin/features)。
