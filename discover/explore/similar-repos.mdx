## The job

You opened a repository and want alternatives or the same kind of project immediately, without searching the topic yourself.

Similar repositories are that list. Desktop opens it from the detail actions. The browser extension shows a read-only list. The feature exists on both builds and requires Pro.

## Desktop (Pro)

Open Similar / Recommended in repository detail.

- Needs a network
- App Store 1.9.1 still uses the previous recommendation path
- Direct 1.9.6 uses Starcat's own model and no longer calls a third party
- Non-Pro hits the paywall

See [Plans](/subscribe/plan-comparison).

## Browser extension

GitHub repo pages can show a read-only recommendation list (usually capped). Requires the desktop app plus [Integrations](/settings/integrations). See [Extension features](/browser-plugin/features).

## Notes

Suggestions are "maybe related", not a dependency audit. Read the README and license before you Star.

An unreachable service can look empty or stale. That is not proof that no similar project exists.
