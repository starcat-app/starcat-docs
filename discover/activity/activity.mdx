## Activity 活动页

Activity 聚合展示你关注的仓库动态，包括 Release 更新、公告和关注动态。

## 内容分类

### Release 更新

你订阅的仓库发布新版本时的动态。详见 [Release 订阅](/release/subscription)。

### 公告

仓库维护者发布的重要公告。

### 关注动态

你关注的仓库的活跃动态。

## 界面

```
┌──────────────┬────────────────────┬──────────────────┐
│  分类导航     │     动态列表        │    动态详情       │
│              │                    │                  │
│ · Release   │  每条动态展示：     │  Release 详情    │
│ · 公告       │  · 仓库名          │  Markdown 渲染   │
│ · 关注       │  · 事件描述        │  资产列表        │
│              │  · 时间           │                 │
│              │  · 来源图标        │                 │
└──────────────┴────────────────────┴──────────────────┘
```

## 分类图标

左侧分类使用语义图标区分不同类型：

- Release：版本发布图标
- 公告：喇叭图标
- 关注：眼睛图标

## 数量展示

每个分类旁显示该分类下的动态数量，帮助判断是否有新内容。
