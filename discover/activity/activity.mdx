## 入口

侧栏一级 **Activity**。

## 常见分类

| 分类 | 说明 |
|------|------|
| 全部 | 综合流（部分特殊类可能单独列出） |
| 公告 | 产品 / 运营公告 |
| Release | 与订阅 Release 相关 |
| Star | Star 相关动态 |
| 仓库 | 仓库事件 |
| 关注 | Following 等事件缓存 |
| 推荐 | 推荐类条目 |
| Undo Star | 取消 Star 相关（可能不并入「全部」） |

点击条目可跳到仓库、[Release 时间线](/release/timeline) 或外部链接。

## 与通知的关系

系统通知点进来后，往往落到 Activity 或时间线。见 [Release 通知](/release/notifications)。
