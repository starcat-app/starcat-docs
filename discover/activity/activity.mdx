## Entry

Top-level sidebar **Activity**.

## Common categories

| Category | Description |
|----------|-------------|
| All | Combined feed (some special types may be listed separately) |
| Announcements | Product / ops announcements |
| Release | Related to subscribed Releases |
| Star | Star-related activity |
| Repository | Repository events |
| Following | Following and similar cached events |
| Recommendations | Recommendation entries |
| Undo Star | Unstar-related (may not appear under All) |

Tap an entry to jump to a repo, the [Release timeline](/release/timeline), or an external link.

## Relationship to notifications

Tapping a system notification often lands in Activity or the timeline. See [Release notifications](/release/notifications).
