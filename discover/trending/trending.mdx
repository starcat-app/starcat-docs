## Data source

GitHub Trending, with repository details completed via the GitHub API.

## Selection rules

- Shows projects from GitHub’s **daily, weekly, and monthly** trending lists.
- Trends reflect **short-term** attention shifts—not the same as long-term popularity.

## Cache

- **TTL**: daily **1 hour**, weekly **6 hours**, monthly **24 hours**.
- **Refresh**: After expiry, show the existing list first while updating in the background; a manual refresh requests the latest data immediately.
- **Offline**: On update failure, keep the current cache; the list is not cleared.

## What you can do

- Browse recently trending repos by language and other filters (controls follow the app)  
- Open detail, Star, ingest  

Good for a daily scan of “what’s hot today,” then tagging or ingesting follow-ups worth keeping.
