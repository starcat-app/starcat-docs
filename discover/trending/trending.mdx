## GitHub Trending

Starcat 集成了 GitHub Trending 功能，让你在应用内直接浏览趋势项目。

## 时间范围

- **日榜** — 今日热门的项目
- **周榜** — 本周热门的项目
- **月榜** — 本月热门的项目

## 语言筛选

按编程语言过滤趋势项目。语言列表基于实际有 trending 数据的语言聚合。

## 项目信息

每个 trending 项目展示：

- 项目名称和描述
- Star 数和增长趋势
- 主要语言
- **AI 摘要**（Pro）— 快速了解项目
- **趋势信号** — 上升趋势等级

## 一键操作

- **Star**：收藏到你的 GitHub Stars
- **查看详情**：展开 README 和完整信息
- **入库**：加入知识库

## 数据缓存

Trending 数据缓存到本地 SQLite，包含 README 缓存，支持离线浏览。
