## 数据来源

GitHub Trending，并通过 GitHub API 补全仓库资料。

## 入选规则

- 展示 GitHub **日榜、周榜和月榜**中的项目。
- 趋势反映短期关注度变化，**不等同于长期热门**。

## 缓存说明

- **缓存有效期**：日榜 **1 小时**、周榜 **6 小时**、月榜 **24 小时**。
- **更新方式**：过期后先显示已有榜单，同时在后台更新；手动刷新会立即请求最新数据。
- **离线处理**：更新失败时保留当前缓存，不会清空已有榜单。

## 能做什么

- 按语言等条件查看近期趋势仓库（控件以 App 为准）  
- 打开详情、Star、入库  

适合每日扫一眼「今天热门」，再把值得跟进的项目打上标签或入库。
