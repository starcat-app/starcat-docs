## What it is for

Sidebar **Explore → Trending** shows short-term attention on GitHub **daily / weekly / monthly** charts. Good for a daily glance at what is moving. It is **not** the same as [Hot](/discover/explore/hot-and-new) long-term heat.

## Data and rules

Source: GitHub Trending, with GitHub API metadata fill-in. Shows daily, weekly, and monthly lists.

Cache: daily **1 hour**, weekly **6 hours**, monthly **24 hours**. After expiry the current list stays on screen while a background refresh runs. Manual refresh requests immediately. Failures keep the cache; the list is not wiped.

Filter by language and similar controls (follow the app). Open detail, Star, ingest.

## Notes

Trending is noisy on purpose. Charting is not a reason to ingest. Read the README first. External service: [starcat-trending-api](https://github.com/starcat-app/starcat-trending-api).
