## What it is for

Sidebar **Explore → Weekly** aggregates repository items from several weekly / intel sources. Treat it as weekly input: scan → Star → tag → curated ingest. It is not your library.

## Data and rules

Sources include: 阮一峰’s weekly, ZRead, Hacker News, HelloGitHub, and verified AI intel. Browse by source or language (follow the UI).

A project appears only after at least one **enabled** source lists it. The same project can come from several sources. **Editor-pinned** items sort first.

Cache: **6 hours**. Fresh cache is used as-is; after expiry existing content stays while a silent refresh runs. Manual refresh requests immediately. Failures keep the last good cache.

After a find you can [subscribe to Releases](/release/subscription).

## Notes

Disabling a source drops projects that only that source listed. External service: [starcat-weekly-api](https://github.com/starcat-app/starcat-weekly-api).
