## Was this page helpful?

Most pages show Mintlify’s **thumbs up / down** (“Was this page helpful?”). Use it to improve docs structure and wording.

<Tip>
  If feedback controls are missing, ensure telemetry is not disabled (`integrations.telemetry.enabled`) and that page feedback is enabled in the Mintlify Dashboard.
</Tip>

## Product support

| Topic | Channel |
|-------|---------|
| Install / login / sync / purchase / license | Email with channel, macOS version, steps |
| Docs errors | Email with URL + expected copy |
| Feature requests | Short scenario + priority |

**Email:** [dong4j@gmail.com](mailto:dong4j@gmail.com)

Please include:

1. Starcat version (Settings → About) and channel (App Store / Direct)  
2. macOS version and Apple Silicon chip  
3. What happened vs expected, with repro steps  
4. Optional: diagnostics export (Settings → Diagnostics)—**redact secrets first**
