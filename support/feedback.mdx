Most pages have Mintlify Was this page helpful? If missing: telemetry (`integrations.telemetry`) and Mintlify Dashboard → Feedback.

| Kind | Channel |
|------|---------|
| Install / login / sync / purchase / license | Email channel (App Store or Direct), OS, repro |
| Wrong / missing docs | Email the URL and expected wording |
| Feature ideas | Email the scenario and priority |

Email: [dong4j@gmail.com](mailto:dong4j@gmail.com)

Include: Starcat version (Settings → About) and channel; macOS and chip; what happened vs expected, repro; diagnostics if relevant (redact first). Urgent purchase / license: put `License` or `Purchase` in the subject.
