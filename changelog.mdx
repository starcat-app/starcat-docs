## 1.4.0

GitHub notifications in Activity, plus knowledge-base indexing and Explore refinements. Online services were upgraded: update to 1.4.0; older builds can still show local cache, but live refresh, recommendations, Discovery, Wiki, and sharing no longer work.

### New

- **GitHub notification inbox**: mentions, review requests, assignments, discussions, releases, and security alerts in Activity, with Unread / Mentions / Reviews / Issues / PRs filters — [Activity](/discover/activity/activity)
- **Issue / PR threads**: read the opening post and comments, write or preview a reply, mark Done without closing the issue, and jump to GitHub or the repository in Starcat
- **AI comment drafts**: generate a reply from the thread, or polish text you already typed; the reply follows the thread language
- **Thread translation**: segmented or full translation of the opening post and comments; titles, repository names, and the composer stay original

### Improvements

- Long thinking stays responsive in knowledge Q&A and repository chat
- Semantic search and knowledge-base index status, prefetch, and Chinese infix matching
- README translation can follow the app UI language and skip same-language paragraphs
- Explore offline cache and first-launch category counts

### Fixes

- Query planning timeline waits until planning finishes
- Embedding cancel no longer reports a network error
- Global filter panel opens without a noticeable delay

## 1.3.0

My Projects, library-wide and repository insights, macOS desktop widgets, reusable insight context for AI / RAG, and desktop launcher integrations.

### New

- **My Projects**: browse personal, organization, and collaborator repositories; GitHub App unlocks authorized private / Internal projects alongside public ones — [My Projects](/main-interface/my-projects)
- **My Insights**: organization progress, tech distribution, status, and action items across Stars or Knowledge Base, with drill-down lists — [Insights](/main-interface/insights)
- **Repository Insights**: Star growth, collaboration, commits, contributors, releases, health, community, and security signals
- **Insight context**: reuse generated insights in AI summary, repo chat, and RAG as removable read-only XML context
- **macOS widgets**: Starcat Focus, Rediscovery, Release Watch, Collection Trend — [Desktop widgets](/main-interface/widgets)
- **Desktop launchers**: Alfred, uTools, and Raycast search local Stars and GitHub — [Desktop launchers](/integrations/desktop-launchers)

### Improvements

- Insight aggregates feed RAG knowledge-base answers
- RAG prompt settings: compare / copy read-only defaults; clearer Markdown templates
- Custom prompt diagnostics for supported placeholders (no silent rewriting)
- First-run onboarding polish (screenshots, welcome audio, card hierarchy)

### Fixes

- Share card theme controls use full click targets
- RAG citations show real snippets for keyword-hit metadata and library stats without requiring vectors

## 1.2.0

Stability, usability, and visual polish: 18 UI languages, pinning, share links, shortcuts, and richer README features.

### New

- **18 UI languages**: English, Simplified / Traditional Chinese, Japanese, Korean, German, French, Spanish, Brazilian Portuguese, Italian, Russian, Dutch, Polish, Ukrainian, Turkish, Vietnamese, Indonesian, Arabic — [General settings](/settings/general)
- **Repository pinning** in Manage (Pin / Unpin, most-recently-pinned first, corner badge) — [Repository list](/main-interface/repo-list)
- **Share links** that open Starcat and locate the repository — [Share links](/share-export/share-links)
- **Customizable shortcuts**: Search Center, list search, refresh, RAG workspace, current-repo AI (master + per-action toggles) — [Shortcuts](/settings/shortcuts)
- **README Mermaid** diagrams with local rendering and source fallback
- **README translation modes**: segmented bilingual by default; full mode replaces visible text while keeping structure — [README translation](/ai-features/readme-translation)

### Improvements

- Tag popover, Pro sidebar username gradient, Starred / Explore navigation hierarchy
- Faster README translation (smaller first batch, concurrency, segment cache, resume)
- Personal notes: AI generate / refine from README with Markdown preview
- AI sharing reuses existing summaries; cancel / regenerate links
- Knowledge-base chunk cards show update time and approximate token counts

### Fixes

- Knowledge Base entry reliability (no-response, restore after minimize, empty-library gate timing)

## 1.1.0

Local-first, explainable RAG knowledge base plus performance and macOS UX work.

### Highlights

- Full **RAG workspace**: multi-repo context, streaming answers, citations, groups / pins, history and drafts
- **Hybrid retrieval**: vectors, bilingual keywords, metadata, Wiki, RepoContext; optional rerank, live GitHub context, external search
- Index management: batch Star ingest, README fill, chunk edit / exclude, rebuild, health checks
- Explainable execution UI and local AI usage dashboard (no prompt/answer body stored)
- Global Star-status filters and AI-summary indicators

## 1.0.0

Initial public release: native three-column Stars manager, sync, tags/notes/status, search, Explore/Weekly/Activity, Release tracking, BYOK AI, health signals, share cards, App Store + Direct.
