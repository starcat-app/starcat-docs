## 1.2.0 (upcoming)

### New

- Share links that open Starcat and locate the shared repository
- Customizable shortcuts for search, refresh, RAG workspace, and current-repo AI

### Improvements

- AI sharing reuses existing summaries; cancel / regenerate supported
- RAG workspace UI polish

## 1.1.0

Local-first, explainable RAG knowledge base plus performance and macOS UX work.

### Highlights

- Full **RAG workspace**: multi-repo context, streaming answers, citations, groups / pins, history and drafts
- **Hybrid retrieval**: vectors, bilingual keywords, metadata, Wiki, RepoContext; optional rerank, live GitHub context, external search
- Index management: batch Star ingest, README fill, chunk edit / exclude, rebuild, health checks
- Explainable execution UI and local AI usage dashboard (no prompt/answer body stored)
- Global Star-status filters and AI-summary indicators

## 1.0.0

Initial public release: native three-column Stars manager, sync, tags/notes/status, search, Explore/Weekly/Activity, Release tracking, BYOK AI, health signals, share cards, App Store + Direct.
