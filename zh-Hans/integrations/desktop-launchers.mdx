## 用途

在常用启动器里搜本机 Stars / 仓库和 GitHub，命中后用 `starcat://` 打开。各启动器是独立仓库，安装以对应 README 为准。

## 配套项目

| 启动器 | 项目 |
|--------|------|
| Alfred | [starcat-alfred-workflow](https://github.com/starcat-app/starcat-alfred-workflow) |
| uTools | [starcat-utools-plugin](https://github.com/starcat-app/starcat-utools-plugin) |
| Raycast | [starcat-raycast-extension](https://github.com/starcat-app/starcat-raycast-extension) |

典型能力：检索本机库；需要时回退 GitHub 搜索；在 Starcat 中打开命中项。

按扩展要求保持 Starcat 运行或近期用过，以便本地搜索 / 配对可用。完成各项目说明里的权限、关键词与 macOS 隐私授权。

## 注意

App Store 沙盒不能拉起任意用户 CLI。启动器扩展是独立进程，但仍依赖本机 App 的 Local API / 深层链接。链接形态见 [分享链接](/zh-Hans/share-export/share-links)。
