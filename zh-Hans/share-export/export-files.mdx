## 用来做什么

需要一份可读快照（发同事、丢进笔记软件）时，导出 HTML 或 Markdown。它**不能**替代尚未上线的整库 JSON 备份。换机请先 [手动备份目录](/zh-Hans/data-privacy/backup)。

## 已支持

| 范围 | 格式 |
|------|------|
| Starred | HTML / Markdown |
| 知识库 | HTML / Markdown |

知识库导出可包含本地笔记、标签、状态、README、Health、摘要缓存等只读快照（以实际文件为准）。

1. 打开分享 / 导出入口
2. 选择 Starred 或知识库
3. 选择 HTML 或 Markdown
4. 选保存位置

其它：单仓 README 用详情 README 工具栏 → 导出 Markdown；RAG 会话用工作台导出 `.md` → [会话管理](/zh-Hans/knowledge-base/session-management)。

整库 JSON 见 [数据导出](/zh-Hans/share-export/data-export)（即将推出）。

## 注意

HTML/MD 是只读快照，导回去不会重建标签体系。不要把它当完整迁移方案。
