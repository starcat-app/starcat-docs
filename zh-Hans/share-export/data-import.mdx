## 现在怎么迁移

1. 用 GitHub 登录 Starcat，先同步 Stars（仓库列表不丢）
2. 重要标签 / 笔记先手工重建，或保留旧工具导出文件等 JSON 导入上线
3. 本机已有 Starcat 数据时，换机先 [备份](/zh-Hans/data-privacy/backup)

## 从本机 App Store 版迁到 Direct <DirectBadge />

你已经在商店版里整理过，现在改用官网版，不想从零再同步一遍笔记。

第一次打开 Direct 时，可以把这台 Mac 上 App Store 版的仓库、笔记和缓存拷过来，也可以跳过、从头开始。不迁移 Apple 订阅。已经处理过这次选择，或本机已经有数据时，不会再次要求同一份授权。

JSON 导入仍然没有。这一步只拷贝本机已安装的 App Store 版数据。
