## 用途

[`starcat-cli`](https://github.com/starcat-app/starcat-cli) 是命令行客户端，也可当 AI Agent 的 stdio MCP 桥。它不打开 SQLite；读写走 App 的 MCP Tools。权限、dry-run、Pro、审计仍由 macOS 上的 Starcat App 执行。App 跑在 Mac；CLI 可装在同一台 Mac，或经可信网络连已配对的 App。

## 怎么装

### Homebrew

```bash
brew tap starcat-app/starcat-cli
brew install starcat
```

Tap：[`homebrew-starcat-cli`](https://github.com/starcat-app/homebrew-starcat-cli)。

### macOS / Linux 一键脚本

```bash
curl -fsSL https://github.com/starcat-app/starcat-cli/releases/latest/download/install.sh | sh
```

默认 `~/.local/bin/starcat`（可用 `STARCAT_INSTALL_DIR` 覆盖）。脚本会校验 SHA-256。

### Windows PowerShell

```powershell
irm https://github.com/starcat-app/starcat-cli/releases/latest/download/install.ps1 | iex
```

## 配对（必做）

1. Starcat → 设置 → MCP → 启用。需 [Pro](/zh-Hans/subscribe/plan-comparison)
2. 复制配对命令；URI 约 5 分钟有效、单次兑换
3. 终端：

```bash
starcat pair "starcat-pair://connect?..."
starcat doctor
```

4. 回到 App 确认设备。未确认则配对未完成。也可 `starcat pair` 后粘贴 URI。长期凭据进钥匙串。见 [MCP 设置](/zh-Hans/settings/mcp)。

```bash
starcat --version
starcat doctor
starcat capabilities
```

## 注意

App Store 沙盒不能拉起任意用户 CLI。CLI 是独立进程，仍需要能托管 MCP 的 App 在运行。下一步：[使用指南](/zh-Hans/cli/usage)、[Agent Skill](/zh-Hans/cli/skill)。
