## 定位（Beta）

App 内 **Agent 工作台**面向需要多步骤、调用工具的任务，与单仓 AI 浮层、RAG 问答互补。

| 能力 | 文档 |
|------|------|
| 单仓聊天 / 摘要 | [AI 对话](/zh-Hans/ai-features/chat) |
| 跨入库仓问答 | [RAG](/zh-Hans/knowledge-base/rag-workspace) |
| 外部 Agent + CLI | [CLI](/zh-Hans/cli/usage)、[Skill](/zh-Hans/cli/skill) |
| App 内 Agent 工作台 | 本页 |

当前处于 **Beta**：界面与可用工具仍会迭代；文档只描述已贯彻的安全边界与入口，不罗列未交付的「调研报告生成器」等路线图当操作说明。

与全体 Starcat AI 的保守策略一致。见 [AI 概览](/zh-Hans/ai-features/overview)。
