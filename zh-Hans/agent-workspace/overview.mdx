## 用来做什么

App 内 **Agent 工作台**面向需要多步骤、调用工具的任务：查库、对比、在你授权后改本机整理数据。它和单仓 AI 浮层、RAG 问答互补，不是把那两套再做一遍聊天窗口。

当前是 **Beta**：界面和可用工具还会变。文档只写已经落地的入口和安全边界，不把未交付的路线图当成操作说明。

## 怎么用

前提：[Pro](/zh-Hans/subscribe/plan-comparison)、[AI 配置](/zh-Hans/ai-features/configuration) 可用。外部 Runtime 还要先完成 [Codex 与 DeepSeek 配置](/zh-Hans/agent-workspace/runtime-setup)。

打开独立 Agent 窗口，选 Runtime，发一个**小任务**先看时间线：思考摘要、工具调用、错误与产物。任务检查器补充结构化步骤和运行指标。

**Direct** 可在内置 Loop、Codex App Server 与 DeepSeek Harness 之间切换。外部 Runtime 以本机子进程运行，不打进 DMG。**Mac App Store 版始终用内置 Runtime**，不能启动用户安装的可执行文件。
