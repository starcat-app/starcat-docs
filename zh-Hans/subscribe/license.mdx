## 用来做什么

Direct 用 License 管 Pro；App Store 用 Apple 订阅 / 买断。换机前先搞清楚自己是哪一种，避免「席位已满」或「恢复购买没反应」。

## 两种授权

| | Mac App Store | Direct（官网） |
|--|---------------|----------------|
| 支付 | Apple / StoreKit | 官网结账 |
| 凭证 | Apple 订阅 / 买断交易 | License |
| 换机 | 「恢复购买」+ 同一 Apple ID | 解绑旧设备 → 新设备激活 |
| 设备 | 遵循 Apple 规则 | Lifetime 等：本人最多 **2** 台 Mac |

Direct：购买后 License 通常自动绑当前设备。也可在 **设置 → Pro → 许可证** 查看状态与设备列表。可解绑以释放席位。席位已满时无法在新设备启用 Pro。

| 状态 | 说明 |
|------|------|
| **有效** | Pro 可用 |
| **已过期** | 月付 / 年付未续费 |
| **席位已满** | 已达设备上限 |
| **已解绑** | 本机已移除授权 |

Direct 离线：启动时从本地恢复权益，定期静默校验，异常或过期时提示重新验证。

App Store 用户不用手动管 License。换机用同一 Apple ID + [恢复购买](/zh-Hans/subscribe/restore)。

## 注意

- 两渠道凭证不互通。
- 解绑旧机前确认那台已经不用，避免两台同时掉权。
