## 用途

免费版已经能整理 Stars、搜索、探索。Pro 解锁 AI、知识库、更高限额。App Store 与 Direct 权益一致，按安装渠道选择即可。价格以 [starcat.ink](https://starcat.ink) 与 App 内购买页为准，和本文不一致时以购买页为准。

## Pro 定价与渠道

| 方案 | 价格 | 说明 |
|------|------|------|
| Pro Monthly | $3.99/月 | 按月自动续费 |
| Pro Yearly | $29.99/年 | 按年自动续费 |
| Pro Lifetime | $39.99 | 一次性买断；本人使用最多 2 台 Mac |

- Mac App Store：[Starcat for GitHub](https://apps.apple.com/cn/app/starcat-for-github/id6788809803?mt=12)
- 官网 Direct：[starcat.ink](https://starcat.ink)

两渠道 Pro 权益一致；购买凭证不互通。见 [购买](/zh-Hans/subscribe/purchase)、[恢复购买](/zh-Hans/subscribe/restore)。

更在意 Apple ID / 家庭共享 → App Store。官网买断 / Direct 安装 → starcat.ink。两台 Mac 长期用 → Lifetime（席位见 [许可证](/zh-Hans/subscribe/license)）。先试一年 → Yearly。

AI 请求走你自己的 Key，见 [BYOK](/zh-Hans/subscribe/byok)。

## 注意

App Store 与 Direct 是两套安装，License 和 StoreKit 不能互相恢复。

Direct 才有本机 CLI / Agent Runtime；App Store 受沙盒限制。见 [GitHub 连接](/zh-Hans/getting-started/github-connection)。

云同步、JSON 导入导出尚未上线。Pro 不是云盘。
