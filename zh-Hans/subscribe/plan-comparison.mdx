## 定价方案

Starcat 提供免费版和 Pro。免费版覆盖 Stars 整理与搜索；Pro 解锁 AI、知识库、更高限额等能力。

<Note>
  下列价格以 [starcat.ink](https://starcat.ink) 与 App 内购买页为准；若页面展示与本文不一致，以购买页实时价格为准。
</Note>

## Pro 定价

| 方案 | 价格 | 说明 |
|------|------|------|
| **Pro Monthly** | $3.99/月 | 按月自动续费 |
| **Pro Yearly** | $29.99/年 | 按年自动续费（相对月付更省） |
| **Pro Lifetime** | $39.99 | 一次性买断；本人使用的最多 **2** 台 Mac |

## 购买入口

- **Mac App Store**：[Starcat for GitHub](https://apps.apple.com/cn/app/starcat-for-github/id6788809803?mt=12)
- **官网 Direct**：[starcat.ink](https://starcat.ink)

两种渠道 Pro 权益一致。详见 [Pro 购买](/zh-Hans/subscribe/purchase)。

## BYOK 模式

Pro 用户在「设置 → AI」配置自己的 Provider API Key：

- 使用你自己的 API 配额
- 请求直达你配置的 Provider
- 灵活切换模型

详见 [BYOK 模式](/zh-Hans/subscribe/byok)。
