## 用途

换机或重装后，Pro 不会跟着 Stars 从 GitHub 同步回来，要按安装渠道恢复。标签、笔记仍在旧机器的本机库里，见 [备份](/zh-Hans/data-privacy/backup)。

## 怎么恢复

App Store：新设备登录同一 Apple ID → 安装 [Starcat for GitHub](https://apps.apple.com/cn/app/starcat-for-github/id6788809803?mt=12) → 设置 → Pro → 恢复购买。

Direct：安装 Direct（[starcat.ink](https://starcat.ink)）→ 设置 → Pro → 许可证 → 登录 / 输入 License。席位已满：先在旧设备解绑，再在新设备激活。见 [许可证管理](/zh-Hans/subscribe/license)。

## 注意

用户数据（标签、笔记、状态）目前只在本机。换机请先备份 Application Support，或等尚未上线的跨设备同步。Stars 列表可从 GitHub 重新拉，不必备份。

Direct Lifetime 本人最多 2 台 Mac；超出先解绑。App Store 买断跟 Apple 账号规则，优先用恢复购买。

App Store 和 Direct 不能自动互通。
