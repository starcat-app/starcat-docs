## 用来做什么

Starcat 的 AI **不代扣模型费用**：你在「设置 → AI」配 Provider 和 API Key，请求发往你指定的服务。这是当前正式方式，不是「即将推出」。用 AI 功能仍需要 **Pro**。

## 怎么配

优势：配额自控、路径清晰、可按任务切 Chat / Embedding。

示例 Provider：OpenAI、OpenAI-compatible、DeepSeek、Gemini、OpenRouter、Ollama（需本机服务）。列表以 App 为准。

1. 已购买并激活 Pro
2. **设置 → AI** 添加 Provider，填 Key / Base URL
3. 为摘要、对话、Embedding 等选模型
4. 测试连接

详见 [AI 配置](/zh-Hans/ai-features/configuration)。

API Key 经 AES-GCM 加密后进 macOS Keychain。Starcat 不会把 Key 当明文传到自有业务服务器。请在 Provider 控制台设用量上限。

## 注意

- 不必绑死 OpenAI；兼容接口、Ollama 等都可以。
- Key 存本机；请求发往你配置的端点。见 [隐私](/zh-Hans/data-privacy/privacy)。
- 配好 Chat 仍不能 RAG：通常是 **Embedding** 空着。
