## 怎么买

| 渠道 | 适合谁 | 入口 |
|------|--------|------|
| Mac App Store | 用 Apple ID 管订阅 | [App Store 页面](https://apps.apple.com/cn/app/starcat-for-github/id6788809803?mt=12) |
| 官网 Direct | 从 [starcat.ink](https://starcat.ink) 下 DMG | 官网定价区，或 App 内「设置 → Pro」 |

价格以购买页为准（当前官网参考：月付 $3.99 / 年付 $29.99 / 买断 $39.99）。目前没有独立试用期；免费版已含同步、限额内标签、搜索。

App Store：从商店安装 → 设置 → Pro → 选方案 → Apple ID / StoreKit → 权益即时生效。

Direct：starcat.ink 或 设置 → Pro → 结账 → License 激活到当前设备（席位见 [许可证](/zh-Hans/subscribe/license)）。

买完：Pro 功能立即解锁；侧栏 / 设置出现 Pro 状态；订阅可看到期日；买断永久有效（遵守席位）。

## 注意

装错渠道会「买了却恢复不了」。MAS 用恢复购买，Direct 用 License。

Direct Lifetime 本人最多 2 台 Mac。

购买前确认渠道、看购买页价格。下一步：[方案对比](/zh-Hans/subscribe/plan-comparison)、[恢复购买](/zh-Hans/subscribe/restore)。
