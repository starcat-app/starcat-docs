## 你要解决的事

Star 已经多到你不会再把每份 README 从头读完。你要的是先知道这个仓库值不值得打开，再决定要不要把标签写进去。

这些 AI 功能做的就是阅读前的这一步。标签和笔记都要你确认后才写入。设备端模型两边都有，而且不要求 Pro。云端 Provider 要 Pro。

## 使用前提

1. 设备端模型：首次启动会接入，免 API Key，这些任务不要求 Pro。模型没下完时会提示下载，而不是付费墙。见 [AI 配置](/zh-Hans/ai-features/configuration)。
2. 云端 Provider：需要 [Pro](/zh-Hans/subscribe/plan-comparison)，再在 **设置 → AI** 填写 Key（[BYOK](/zh-Hans/subscribe/byok)）。
3. 为任务选默认模型：Chat（摘要 / 对话 / 标签）和 Embedding（语义 / RAG）。

缺 Embedding 是最常见的「模型已接通仍不能语义 / RAG」原因。标签和笔记仍要确认后才写入。

## 能力一览

| 功能 | 典型入口 | 文档 |
|------|----------|------|
| AI 摘要 | 详情浮层 **⇧⌘A** | [摘要](/zh-Hans/ai-features/summary) |
| AI 对话 | 同上，可拆独立窗口 | [对话](/zh-Hans/ai-features/chat) |
| 标签推荐 | 浮层 / Auto Tidy | [标签推荐](/zh-Hans/ai-features/tag-recommendation) |
| README 翻译 | README 工具区 | [翻译](/zh-Hans/ai-features/readme-translation) |
| AI 个人笔记 | 笔记区「AI 生成」 | [个人笔记](/zh-Hans/ai-features/personal-notes) |
| 语义搜索 | 列表语义模式 | [语义搜索](/zh-Hans/search/semantic-search) |
| RAG 问答 | **⇧⌘K** | [知识库](/zh-Hans/knowledge-base/overview) |
| Auto Tidy | 设置 → AI | [自动整理](/zh-Hans/ai-features/auto-tidy) |
| Agent 工作台 | 独立窗口 | [Agent Beta](/zh-Hans/agent-workspace/overview) |

[Search Center](/zh-Hans/search/search-center) 的网页 Scope 不强制 Pro。AI 若附带联网上下文，仍受 Pro / 开关约束 → [外部搜索](/zh-Hans/search/external-search)。

## 保守策略

| 场景 | 规则 |
|------|------|
| 标签推荐 | 确认后才写入 |
| AI 笔记 | 草稿确认后才保存 |
| Agent | 改数据需明确授权 |
| Auto Tidy | 只跑你打开的动作与触发器 |

## 推荐上手顺序

1. [AI 配置](/zh-Hans/ai-features/configuration) → 测试连接
2. 详情 → ⇧⌘A → 摘要或问一句
3. 需要语义时补齐 Embedding → 建索引 → 列表语义
4. 跨仓问答：精选入库 → [RAG 工作台](/zh-Hans/knowledge-base/rag-workspace)
5. 输出稳定后再开 [Auto Tidy](/zh-Hans/ai-features/auto-tidy)
