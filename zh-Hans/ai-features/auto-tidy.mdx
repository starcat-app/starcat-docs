## 是什么

**设置 → AI → Auto Tidy** 里的后台整理：在你允许的时机，对仓库跑摘要、标签推荐等动作。

## 典型可配项

| 项 | 说明 |
|----|------|
| 总开关 | 立即停用全部自动整理 |
| 触发 | 启动后延迟、同步完成、定时等 |
| 动作 | 摘要、标签推荐等（以界面勾选项为准） |
| 立刻执行 | 手动跑一轮，用于试配置 |

## 建议开启顺序

1. 先在单仓浮层确认模型输出可读  
2. 动只勾选你真正需要的动作  
3. 小范围触发（例如仅同步完成）观察一天  
4. 再考虑定时  

## 风险与限额

- 大库 + 定时 = Provider 账单上升  
- 标签写入仍受[确认策略](/zh-Hans/ai-features/tag-recommendation)与免费 **20** 标签上限约束  
- 需要 Pro 与有效 Provider
