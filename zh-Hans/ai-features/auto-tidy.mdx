## 用来做什么

不想每个新 Star 都手动开 ⇧⌘A 时，用 **设置 → AI → Auto Tidy** 在同步完成或定时时跑你勾选的动作。它是加速器，不是「全自动整理完不用看」。

## 怎么配

| 项 | 说明 |
|----|------|
| 总开关 | 立刻停用全部自动整理 |
| 触发 | 启动后延迟、同步完成、定时等 |
| 动作 | 摘要、标签推荐等（以界面为准） |
| 立刻执行 | 手动跑一轮，试配置 |

建议顺序：单仓浮层确认输出可读 → 只勾真正需要的动作 → 小范围触发（例如仅同步完成）观察一天 → 再考虑定时。

## 注意

- 大库 + 定时 = Provider 账单上升
- 标签写入仍要 [确认](/zh-Hans/ai-features/tag-recommendation)，且受免费 **20** 标签上限约束
- 需要 Pro 与有效 Provider
- 关掉总开关应立即停下后续批次；正在跑的一轮可能还会结束
