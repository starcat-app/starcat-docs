## 用途

在详情里翻译 README：按段对照，或全文替换可见文本。代码块和表格可能不如原文整齐。

## 怎么用

本地仓库详情 README 工具区的 **翻译** 按钮。

| 场景 | 通常是否可用 |
|------|----------------|
| Manage / Explore 本地详情 | 是 |
| 部分 Activity / 外链预览 | 可能否 |

| 模式 | 行为 |
|------|------|
| 分段（默认） | 按段对照 / 双语阅读 |
| 全文 | 替换可见 README 文本，尽量保留结构 |

步骤：等 README 加载完 → 点翻译 → 选目标语言和模式 → 在译文与原文间切换。需要 Pro，并在 [AI 配置](/zh-Hans/ai-features/configuration) 指定翻译模型。目标语言可自动跟随界面。已经是目标语言的段落会跳过。失败时右下角 toast。

翻译会用更小的首批请求、增量展示、最多 4 路并发、分段缓存，未完成段落可续译。

## 注意

- 超长 README 更耗时、更费 token
- 代码块 / 表格可能排版不如原文
- Mermaid 与复杂图表不理想时，译文可能更接近原文
- 用来阅读即可，不要当发布级本地化交出去
