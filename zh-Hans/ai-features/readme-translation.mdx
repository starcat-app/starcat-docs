## 入口

本地仓库详情 README 工具区中的 **翻译** 按钮。

| 场景 | 通常是否可用 |
|------|----------------|
| Manage / Explore 本地详情 | 是 |
| 部分 Activity / 外链预览 | 可能否 |

## 步骤

<Steps>
  <Step title="打开详情">等待 README 加载完成。</Step>
  <Step title="点翻译">选择目标语言；默认可跟随界面语言。</Step>
  <Step title="对照阅读">可在译文与原文间切换（以 App 为准）。</Step>
</Steps>

需 Pro，并在 [AI 配置](/zh-Hans/ai-features/configuration) 指定翻译模型。

## 注意

- 超长 README 耗时与费用更高  
- 代码块 / 表格可能排版不如原文  
- 翻译结果是否缓存以 App 行为为准
