## 打开方式

| 方式 | 说明 |
|------|------|
| 快捷键 | 默认 **⇧⌘A**（[可改](/zh-Hans/settings/shortcuts)） |
| 详情浮层 | 选中仓库后打开 AI 面板 |
| 独立窗口 | 浮层内拆出，便于对照 README |

需 [Pro](/zh-Hans/subscribe/plan-comparison) + 已配置 Chat 模型 → [AI 配置](/zh-Hans/ai-features/configuration)。

## 浮层常见结构

- **摘要**相关操作 → [AI 摘要](/zh-Hans/ai-features/summary)  
- **对话** Tab：针对**当前仓库**提问  
- 可能附带标签推荐等入口 → [标签推荐](/zh-Hans/ai-features/tag-recommendation)  

具体 Tab 文案以 App 为准。

## 适合问什么

- 「用三条概括这个库解决什么问题」  
- 「快速上手步骤是什么（依据 README）」  
- 「有哪些明显限制或非目标」  

跨多个入库仓库对比，请用 [RAG 工作台](/zh-Hans/knowledge-base/rag-workspace)，而不是单仓浮层硬撑。

较长思考过程中界面保持可操作，完成后仍可展开阅读全文。失败时右下角 toast 提示。

## 外部上下文

若启用 AI 外部搜索上下文，回答可能附带网页来源。配置在 **设置 → 集成**。见 [外部搜索](/zh-Hans/search/external-search)。
