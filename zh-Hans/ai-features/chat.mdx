## 用途

浮层针对当前仓库的 README 提问。跨很多入库仓对比，用 [RAG 工作台](/zh-Hans/knowledge-base/rag-workspace)。

## 怎么打开

| 方式 | 说明 |
|------|------|
| 快捷键 | 默认 **⇧⌘A**（[可改](/zh-Hans/settings/shortcuts)） |
| 详情浮层 | 选中仓库后打开 AI 面板 |
| 独立窗口 | 浮层内拆出，便于对照 README |

需要 [Pro](/zh-Hans/subscribe/plan-comparison) + 已配置 Chat 模型 → [AI 配置](/zh-Hans/ai-features/configuration)。

浮层常见结构：摘要相关操作、对话 Tab、可能还有标签推荐。Tab 文案以 App 为准。

## 适合问什么

- 「用三条概括这个库解决什么问题」
- 「快速上手步骤是什么（依据 README）」
- 「有哪些明显限制或非目标」

较长思考过程中界面保持可操作，完成后仍可展开全文。失败时右下角 toast。

若启用 AI 外部搜索上下文，回答可能带网页来源。配置在 **设置 → 集成**。见 [外部搜索](/zh-Hans/search/external-search)。

## 注意

- 模型只看见当前仓上下文（外加你打开的联网），不会自动扫遍全部 Stars。
- 许可证、安全公告、最新 Release 仍要自己核对。
