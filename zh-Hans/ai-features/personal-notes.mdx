## 用途

对着 README 生成一份给你自己看的学习笔记草稿，例如为什么 Star、打算怎么用。确认前不会覆盖已有正文。笔记只在本机，GitHub 协作者看不到。

## 怎么用

入口：详情「私有笔记」头部的 **AI 生成**。需要 Pro + Chat 模型。笔记区本身见 [笔记与状态](/zh-Hans/manage-stars/notes-and-status)。

1. 触发生成或优化：可基于 README 生成，或优化已有草稿；过程有进度
2. 用 Markdown 编辑预览；草稿可复制。未确认不覆盖正文
3. 确认保存，写入私有笔记并显示保存状态

## 注意

- 笔记只存本机，不上传 GitHub。
- 生成会把必要上下文发给你配置的 AI Provider（BYOK）。见 [隐私](/zh-Hans/data-privacy/privacy)、[BYOK](/zh-Hans/subscribe/byok)。
- 没确认的草稿不会进列表搜索。
