## 入口

详情「私有笔记」区域头部的 **AI 生成** 控件。

需 Pro + Chat 模型。笔记区本身说明见 [笔记与状态](/zh-Hans/manage-stars/notes-and-status)。

## 流程

<Steps>
  <Step title="触发生成或优化">可基于当前 README 生成学习笔记，或优化已有草稿。生成过程有进度提示。</Step>
  <Step title="编辑预览">用 Markdown 编辑并预览；草稿可复制。未确认不会覆盖已有正文。</Step>
  <Step title="确认保存">写入私有笔记，并显示保存状态。</Step>
</Steps>

## 存储与隐私

- 笔记只存本机，不上传 GitHub  
- 生成过程会把必要上下文发给你配置的 AI Provider（BYOK）  
- 见 [隐私](/zh-Hans/data-privacy/privacy)、[BYOK](/zh-Hans/subscribe/byok)
