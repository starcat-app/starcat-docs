## 用途

知道要什么、但没有仓库名时，用一句话找还没 Star 的 GitHub 仓库。结果带匹配理由和证据，不是关键词命中列表。

## 怎么用

1. 打开 [Search Center](/zh-Hans/search/search-center)（默认 **⌘K**）。
2. 选择 **智能发现**，写下需求。
3. 结果会陆续出现。不够就继续找。
4. 用顶部来源筛选只看某一类：关键词、语义、GitHub、网页、智能发现。每一类单独计数，同一仓库不重复出现。

内置规则会隐藏不适宜的结果，普通搜索和智能发现用同一套规则。

## 注意

<Warning>
  智能发现和语义搜索共用权益。设备端本地模型可以免费使用。改成云端 Provider 后需要 [Pro](/zh-Hans/subscribe/plan-comparison)，并配好对话模型。见 [AI 配置](/zh-Hans/ai-features/configuration)。
</Warning>

它找的是尚未收藏的公开仓库。已经 Star 的库用本地 Scope 或 **⌘F**。
