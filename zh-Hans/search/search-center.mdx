## 用途

Search Center 是独立面板，用来在不确定东西在哪时一次搜：已经 Star 的本地缓存、GitHub 上还没 Star 的库、以及网页。当前列表的 ⌘F 做不到跨源。

## 怎么打开

- 默认 **⌘K**
- 列表旁的全局搜索入口
- 菜单「打开全局搜索」（文案以 App 为准）

## 四个 Scope

| Scope | 搜什么 | 备注 |
|-------|--------|------|
| **全部** | 多源聚合 | 不确定来源时用 |
| **本地** | 你的 Stars / 本地库 | FTS；和列表搜索同源 |
| **GitHub** | GitHub Search API | 可看入库角标；可 Star / 入库 |
| **网页** | External Search | 配置见 [外部搜索](/zh-Hans/search/external-search) |

网页搜索对所有用户开放（Provider 可能要 Key）。语义搜索仍是 Pro，主要在列表语义模式。

GitHub Scope 常见筛选：语言、topic、最低 stars、创建 / 推送时间、排序。适合发现尚未 Star 的库，再一键入库或 Star。

## 结果上能做什么

- 打开本地详情或系统浏览器
- 加入知识库 / Star（视结果类型与登录状态）
- 从 GitHub 结果直接进入整理流

## 注意

| 现象 | 处理 |
|------|------|
| ⌘K 没反应 | [快捷键](/zh-Hans/settings/shortcuts) 是否改键或冲突 |
| GitHub Scope 空 | 登录与 Rate Limit → [FAQ 同步](/zh-Hans/faq/sync) |
| 网页 Scope 失败 | [集成 → External Search](/zh-Hans/settings/integrations) 的 Key / 测试 |
| 本地找不到笔记里的词 | 笔记是否已保存；试 [列表搜索](/zh-Hans/search/global-search) |
