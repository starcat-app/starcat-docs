## 用来做什么

侧栏决定「这一大类」，筛选决定「这一类里还要满足哪些硬条件」。适合每天整理：先点「未分类」或某个 Smart Collection，再用漏斗收窄，最后 [批量](/zh-Hans/manage-stars/batch-operations)。比在 All Stars 里裸勾高效。

## 怎么用

Manage（以及部分列表页）工具栏的统一筛选（漏斗，文案以 App 为准）：

1. 侧栏先选范围
2. 打开筛选，勾维度
3. 需要时再 ⌘F 或批量

## 有哪些维度

| 维度 | 说明 | 延伸 |
|------|------|------|
| **状态** | 未读 / 已读 / 正在使用 | [笔记与状态](/zh-Hans/manage-stars/notes-and-status) |
| **已 Star / 未 Star** | 顶栏也可能有快捷切换 | — |
| **知识库** | 已入库 / 未入库 | [知识库](/zh-Hans/knowledge-base/overview) |
| **语言** | 多选；可与「感兴趣语言」配合 | [列表偏好](/zh-Hans/settings/list-preferences) |
| **标签** | 按标签收窄 | [标签](/zh-Hans/manage-stars/tags) |
| **Wiki** | 仅有 Wiki 信号的仓库 | 详情 Wiki 入口 |
| **Health** | 已有健康度缓存 | [Repo Health](/zh-Hans/main-interface/repo-health) |
| **OpenSSF** | 已有安全评分缓存 | 同上 |
| **隐藏归档** | 去掉 archived | — |
| **隐藏 Fork** | 去掉 fork | — |

不是每一页都露出全部维度；探索列表通常更少。

## 组合与叠加

多条件一般为 **AND**。例如：语言 = Swift **且** 状态 = 正在使用 **且** 未入库。

| 层 | 作用 |
|----|------|
| 侧栏分类 | 最大范围 |
| 筛选 | 结构化约束 |
| 列表搜索（⌘F） | 关键词 / 语义再找 |

三者同时生效时，当前列表已经是子集。见 [列表搜索](/zh-Hans/search/global-search)。

## 重置

- 菜单底部 **重置**：清掉当前筛选
- 条件常按模块记住：切到「标签 A」再切回 All Stars，可能各自恢复上次条件
- 行为怪异时：[通用设置](/zh-Hans/settings/general) → 重置列表偏好

想把同一套规则天天留在侧栏，用 [智能集合](/zh-Hans/manage-stars/smart-collections)，不要指望筛选菜单当收藏夹。
