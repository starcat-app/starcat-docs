## 用来做什么

把第三方网页检索接到 Starcat，给两处用：

1. [Search Center](/zh-Hans/search/search-center) 的 **网页** Scope
2. AI / RAG 需要时的**联网上下文**（受开关和隐私选项约束）

AnySearch、Tavily 等是 Provider，不是另一套互不相干的产品。

## 怎么配置

| Provider | 说明 |
|----------|------|
| AnySearch | 常用选项；是否需 Key 以 App 为准 |
| Tavily | 需 API Key |
| Exa | 需 API Key |
| Brave LLM Context | 需 API Key |

1. **设置 → 集成 → External Search**
2. 启用 Provider，填写 Key（如需），保存
3. 用测试连接确认可用
4. 为网页搜索 / AI 上下文选默认 Provider（选项以界面为准）

也见 [集成设置](/zh-Hans/settings/integrations)。

在 Search Center：⌘K → Scope 选 **网页** → 输入查询 → 看带来源站点的结果。

## 注意

- 结果会本地缓存，减少重复计费 / 请求；可在 **设置 → 存储** 清外部搜索缓存。
- 查询会发往你启用的第三方服务。
- 私有仓库是否允许附带外部上下文，受集成 / AI 开关约束。原则见 [隐私](/zh-Hans/data-privacy/privacy)。
- 网页 Scope **不是**语义搜索。
