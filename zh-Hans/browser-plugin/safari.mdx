## 用来做什么

在 Safari 的 GitHub 仓库页使用同一套本机 Local API。设置页可能已有入口，**功能完整度可能落后于 Chrome**。

## 怎么配

仓库：[starcat-safari-plugin](https://github.com/starcat-app/starcat-safari-plugin)

1. Starcat 运行中
2. **设置 → 集成** 中端口与 Token
3. 按仓库 README 安装 / 信任 Safari 扩展

能力边界见 [功能说明](/zh-Hans/browser-plugin/features)。

## 注意

Safari 要在「设置 → 扩展」里明确打开。缺注入时先看 Chrome 同款排障：App 是否在跑、Token 是否一致。
