## 用来做什么

在 **GitHub 仓库页**加一层本机 Starcat 能力，少切一次桌面。v1 是增强，不是把整个 App 搬进浏览器。

## v1 有什么

| 能力 | 说明 |
|------|------|
| 相似推荐 | 只读列表（条数有上限） |
| Wiki 入口 | 跳转 / 打开 Wiki |
| 私有笔记 | 编辑本机笔记；通常限**已 Star** 仓库 |
| Health / OpenSSF | 展示本地已缓存分数；不在网页里完整重算 |
| CodeFlow / Codebase 按钮 | 若桌面端启用，提供跳转 |

**明确不做（v1）**：完整 Inbox、桌面级 AI 摘要工作流、复杂右键菜单。完整 AI 请回 App。

通信：`http://127.0.0.1:{port}/plugin/v1/...`，`Authorization: Bearer <token>`，流量留在本机。Token 在 [集成设置](/zh-Hans/settings/integrations) 管理。

## 注意

| 现象 | 处理 |
|------|------|
| GitHub 页无注入 | App 是否运行；扩展是否启用；端口 / Token 是否一致 |
| 笔记不能编 | 是否已 Star；Token 是否过期 |
| Health 不显示 | 本机是否已有缓存；回 App 打开详情触发评分 |
