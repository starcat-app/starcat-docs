## 文档是否有帮助？

每篇文档页底部通常有 Mintlify 自带的 **「Was this page helpful?」**（赞 / 踩）反馈。点选后可帮助我们改进文档结构与表述。

<Tip>
  若某页没有出现反馈控件：请确认本站未关闭遥测（`integrations.telemetry`），并在 Mintlify Dashboard → Feedback 中启用页面反馈。
</Tip>

## 产品与账号支持

| 类型 | 建议渠道 |
|------|----------|
| 安装 / 登录 / 同步 / 购买 / 许可证 | 邮件说明渠道（App Store 或 Direct）、系统版本与复现步骤 |
| 文档写错 / 缺页 | 邮件附上文档 URL + 期望表述 |
| 功能建议 | 邮件简述场景与优先级 |

**邮箱**：[dong4j@gmail.com](mailto:dong4j@gmail.com)

邮件建议包含：

1. Starcat 版本（设置 → 关于）与分发渠道  
2. macOS 版本与芯片（Apple Silicon）  
3. 问题现象、期望行为、可复现步骤  
4. 若相关：诊断导出（设置 → 诊断）— **请先自行脱敏**
