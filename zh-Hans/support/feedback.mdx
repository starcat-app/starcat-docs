## 用来做什么

文档写错、安装 / 购买卡住、想提需求时，知道该点页底赞踩还是发邮件。个人维护，不保证 SLA。

每篇文档页底部通常有 Mintlify **「Was this page helpful?」**。若没有：确认本站未关闭遥测（`integrations.telemetry`），并在 Mintlify Dashboard → Feedback 启用。

| 类型 | 建议渠道 |
|------|----------|
| 安装 / 登录 / 同步 / 购买 / 许可证 | 邮件说明渠道（App Store 或 Direct）、系统版本与复现步骤 |
| 文档写错 / 缺页 | 邮件附上文档 URL + 期望表述 |
| 功能建议 | 邮件简述场景与优先级 |
