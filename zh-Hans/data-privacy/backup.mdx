## 用途

标签、笔记、状态、智能集合规则无法从 GitHub 重新生成。换机、重装、恢复出厂前先备份。

## 怎么备份

1. 完全退出 Starcat，避免拷贝正在写入的数据库
2. 复制数据目录。Direct 常见：`~/Library/Application Support/Starcat/`。App Store 在沙盒容器内，路径不同。可在设置 → 存储 用 Finder 入口定位
3. 存到外置盘 / 加密备份

恢复：完全退出 → 把备份放到同一渠道对应路径（MAS 与 Direct 不要混用）→ 再打开 App。

<Warning>
  iCloud / CloudKit 用户数据同步尚未提供。恢复时把备份拷到同一渠道对应路径。
</Warning>

| 优先级 | 数据 |
|--------|------|
| 高 | 标签、笔记、状态、集合规则 |
| 中 | AI / RAG 会话历史 |
| 低 | README / 图片 / 摘要缓存（可重建） |

Stars 列表可重新同步，一般不必单独备份。JSON 导出见 [即将推出](/zh-Hans/share-export/data-export)。
