## 用途

数据默认留在哪台 Mac、什么时候会离开本机。完整法律文本以 [starcat.ink/privacy](https://starcat.ink/privacy) 为准。

本地优先：标签、笔记、状态只在本机；不出售个人数据、无广告追踪；不读 GitHub 密码；AI Key 进 Keychain；笔记不会拿去训练「官方模型」。

| 类型 | 例子 | 可否从 GitHub 重建 |
|------|------|--------------------|
| 仓库缓存 | 元数据、README | 可以 |
| 用户数据 | 标签、笔记、状态、集合规则 | 不可以 |
| 密钥 | GitHub Token、AI Key | Keychain |

跨设备云同步尚未上线。见 [备份](/zh-Hans/data-privacy/backup)。

BYOK 请求发往配置的 Provider。[外部搜索](/zh-Hans/search/external-search) 仅在启用时发查询。分享卡片 / 链接需主动操作。

「匿名贡献公开 Star 数据」在设置 → 通用 → 隐私与推荐，默认关闭。开启后，成功全量同步时静默上报公开仓库 ID 和可用 Star 时间，用于改进推荐。不上报私有仓、标签、笔记、浏览行为或账号身份。上报前换成随机匿名标识。失败不影响同步。首次可能弹出一次性授权，「暂不参与」即保持关闭。

匿名遥测默认关，在设置 → 诊断 开启。见 [遥测](/zh-Hans/data-privacy/telemetry)。
