## 原则摘要

Starcat 以**本地优先**为默认：

- 标签、笔记、状态等用户数据优先只在本机  
- 不出售个人数据、无广告追踪  
- 不读取 GitHub 密码  
- AI Key 存 Keychain；笔记不用于「拿去训练你们的模型」这类用途  

完整法律文本以官网为准：[starcat.ink/privacy](https://starcat.ink/privacy)。

## 数据分类

| 类型 | 例子 | 可否从 GitHub 重建 |
|------|------|--------------------|
| 仓库缓存 | 元数据、README | 可以 |
| 用户数据 | 标签、笔记、状态、集合规则 | **不可以** |
| 密钥 | GitHub Token、AI Key | Keychain |

跨设备云同步尚未上线 → [备份](/zh-Hans/data-privacy/backup)。

## AI 与第三方

- **BYOK**：请求发往你配置的 Provider → [BYOK](/zh-Hans/subscribe/byok)  
- **外部搜索**：仅在启用时把查询发给对应 Provider → [外部搜索](/zh-Hans/search/external-search)  
- **分享**：卡片导出或公开链接需你主动操作 → [分享卡片](/zh-Hans/share-export/share-cards)  

## 公开 Star 数据贡献

**设置 → 通用 → 隐私与推荐** 有「匿名贡献公开 Star 数据」，**默认关闭**。开启后，成功完成 Stars 全量同步时，Starcat 会静默上报公开仓库 ID 和可用 Star 时间，用于改进推荐。

不会上传私有仓库、标签、笔记、浏览行为或账号身份。上报前会换成随机匿名标识。失败不会影响正常同步。

首次使用时可能弹出一次性授权提示，选「暂不参与」即可保持关闭。

## 遥测

匿名遥测**默认关**，在 **设置 → 诊断** 开启。详见 [遥测](/zh-Hans/data-privacy/telemetry)。
