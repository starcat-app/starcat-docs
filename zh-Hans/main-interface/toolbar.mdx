## 用途

工具栏贴在中栏顶部，跟着当前页变：Manage 列表、探索、集合、通知时间线的按钮组合不一样。全局搜索默认是 **⌘K**，不在这条栏上。

## 常用按钮

| 按钮 | 作用 |
|------|------|
| **同步** | 拉 / 增量同步 Stars；转圈表示进行中。图标是产品统一的 `arrow.triangle.2.circlepath` |
| **筛选** | [统一筛选](/zh-Hans/search/filters) |
| **多选** | [批量操作](/zh-Hans/manage-stars/batch-operations) |
| **列表搜索** | 当前列表关键词或语义，常 **⌘F** |
| **知识库问答** | 打开 [RAG 工作台](/zh-Hans/knowledge-base/rag-workspace) |
| **外链 / Clone / AI / CodeFlow** | 多在选中仓库后出现 |
| **状态** | 同步、索引、GitHub 官方状态；异常时可打开 GitHub Status |

## 和快捷键

| 能力 | 默认 | 别搞混 |
|------|------|--------|
| Search Center | **⌘K** | 四 Scope 聚合，不是列表搜索框 |
| 列表搜索 | **⌘F** | 只过滤当前中栏 |
| 刷新 | **⌘R** | 焦点在列表或详情 |
| 仓库 AI | **⇧⌘A** | 要 Pro + AI 配置 |
| RAG | **⇧⌘K** | 要 Pro |

均可在 [快捷键](/zh-Hans/settings/shortcuts) 改。

## 注意

- 探索页的「刷新」刷的是发现缓存，不是 Stars 全量同步。
- 状态里的 GitHub 官方状态是 githubstatus.com 一类公开状态，不是你的 API 配额面板。
