## 你要解决的事

你人已经在某一份列表里，只想同步、筛选或在这份列表里找一个名字，不想先打开全局搜索。

中栏工具栏跟着当前页变。全局搜索仍是 **⌘K**。中栏快速搜索两边都有。

## 常用按钮

| 按钮 | 作用 |
|------|------|
| **同步** | 拉 / 增量同步 Stars；转圈表示进行中。图标是产品统一的 `arrow.triangle.2.circlepath` |
| **筛选** | [统一筛选](/zh-Hans/search/filters) |
| **多选** | [批量操作](/zh-Hans/manage-stars/batch-operations) |
| **快速搜索** | 从中栏展开，只查当前这一类列表（Manage、探索、通知、Undo Star 等），不是 ⌘K |
| **列表搜索** | 当前列表关键词或语义，常 **⌘F** |
| **知识库问答** | 打开 [RAG 工作台](/zh-Hans/knowledge-base/rag-workspace) |
| **外链 / Clone / AI / CodeFlow** | 多在选中仓库后出现 |
| **状态** | 同步、索引、GitHub 官方状态；异常时可打开 GitHub Status |

## 和快捷键

| 能力 | 默认 | 别搞混 |
|------|------|--------|
| Search Center | **⌘K** | 四 Scope 聚合，不是列表搜索框 |
| 列表搜索 | **⌘F** | 只过滤当前中栏 |
| 刷新 | **⌘R** | 焦点在列表或详情 |
| 仓库 AI | **⇧⌘A** | 云端要 Pro；设备端模型不要 |
| RAG | **⇧⌘K** | 要 Pro |

均可在 [快捷键](/zh-Hans/settings/shortcuts) 改。

## 同步提醒与菜单栏

Starcat 在前台时，如果 Star 是从 GitHub 网页、浏览器或其他工具加上的，「全部仓库」会显示头像提醒。点一下开始同步，列表回到顶部。

<DirectVersionBadge /> 你还想不打开主窗口就知道同步和下载有没有卡住。菜单栏里的 Starcat 图标：左键打开状态面板，可以暂停或停止任务；右键是快捷菜单。App Store 1.9.1 还没有这块状态面板。外部 Star 的头像提醒两边都有。增强诊断见 [诊断](/zh-Hans/settings/diagnostics)。

## 注意

- 探索页的「刷新」刷的是发现缓存，不是 Stars 全量同步。
- 状态里的 GitHub 官方状态是 githubstatus.com 一类公开状态，不是你的 API 配额面板。
