## 用途

主窗口布局跟 Finder / Mail 一类 macOS App 一样：左边选范围，中间扫列表，右边看当前这一项。

先认三栏，再进标签和 AI，会少很多「我在哪」的迷失。

```
┌────────────┬─────────────────────┬──────────────────────┐
│  侧边栏     │  列表 + 工具栏        │  详情面板              │
│  Sidebar   │  Repo / Activity     │  README · 笔记 · 操作 │
└────────────┴─────────────────────┴──────────────────────┘
```

| 栏 | 你在这儿干什么 | 文档 |
|----|----------------|------|
| 左 | 换 Manage / 探索 / Activity，再点子分类 | [侧边栏](/zh-Hans/main-interface/sidebar) |
| 中 | 当前分类下的仓库或通知列表，顶上是工具栏 | [仓库列表](/zh-Hans/main-interface/repo-list)、[工具栏](/zh-Hans/main-interface/toolbar) |
| 右 | 当前项的 README、标签、笔记、Health、AI | [仓库详情](/zh-Hans/main-interface/repo-detail) |

窗口变窄时，详情栏可能收起来，优先保证列表能扫。这是自适应，不是坏了。

## 三个一级区域怎么选

| 区域 | 解决什么问题 |
|------|----------------|
| **Manage** | 已经在你库里的东西：Stars、我的项目、知识库、标签、集合、Release 时间线、洞察 |
| **探索** | 还没进库的新项目：趋势、周刊、Awesome、热门、新发布 |
| **Activity** | 默认是 GitHub 通知收件箱；也有公告、Release 等本地分类 |

每天整理走 Manage。刷榜单走探索。处理 @ 和 Review 走 Activity。

## 独立窗口

需要对照 README 长聊，或做跨仓问答时，把能力从主窗口拆出去：

| 窗口 | 怎么开 | 文档 |
|------|--------|------|
| 仓库 AI | 详情浮层拆出，或 **⇧⌘A** | [AI 对话](/zh-Hans/ai-features/chat) |
| RAG 工作台 | 工具栏或 **⇧⌘K** | [RAG 工作台](/zh-Hans/knowledge-base/rag-workspace) |
| Agent 工作台 | 独立入口 | [Agent（Beta）](/zh-Hans/agent-workspace/overview) |

## 外观

**设置 → 通用**：18 种界面语言、浅/深/跟随系统、字体倍率、列表密度、减少动画。见 [通用设置](/zh-Hans/settings/general)。

## 注意

- Manage 里的列表是你的 Stars / 项目；探索列表来自 Starcat 的发现服务，不是本机收藏的镜像。
- Activity 默认落在**通知**，不是「全部动态」。见 [活动](/zh-Hans/discover/activity/activity)。
