## 用来做什么

不必打开 Starcat 也能扫一眼：常去的仓、今天该重逢的老收藏、未读 Release、最近 Stars 涨了多少。点进去仍回到 App 里对应界面，而不是随手打开 GitHub 网页。

四个 WidgetKit 小组件（系统库里的名字跟语言走）：

| 小组件 | 作用 |
|--------|------|
| **Starcat Focus** | 常用 / 置顶 /「使用中」仓库 |
| **今日重逢** | 从收藏里抽一条每日重逢 |
| **Release Watch** | 未读或近期 Release |
| **收藏趋势** | 近期收藏增长 |

## 怎么加

1. 安装 Starcat（App Store 或 Direct），扩展会一起装上
2. 至少成功登录一次，App 才会发布快照
3. 打开 macOS 小组件库，搜 **Starcat**，选尺寸

空白或过期：先打开一次 Starcat，确认已登录，等下一轮刷新，或删掉重加。

## 注意

- 点击走 `starcat://` 一类可控链接。Release 优先进 App 的时间线，不直接跳原始 GitHub Release 页。
- Focus 候选包含你在列表里 [置顶](/zh-Hans/main-interface/repo-list) 的仓。
- 小组件读的是本机快照，不是另一台 Mac 上的库。
