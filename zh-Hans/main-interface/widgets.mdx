## 有哪些

Starcat 提供四个 WidgetKit 小组件，可在 macOS 桌面 / 通知中心小组件库中添加：

| 小组件 | 作用 |
|--------|------|
| **Starcat Focus** | 常用 / 置顶 /「使用中」仓库，可点击直达 |
| **今日重逢（Rediscovery）** | 从收藏库中给出每日重逢推荐 |
| **Release Watch** | 未读或近期 Release 信号，点击进入 Starcat |
| **收藏趋势（Collection Trend）** | 一眼查看近期收藏增长 |

系统小组件库中的显示名称以本地化为准。

## 使用前提

- 已安装 Starcat（App Store 或 Direct）并带有小组件扩展  
- 至少登录过一次，以便应用发布小组件快照  
- 打开 macOS 小组件库 → 搜索 **Starcat** → 添加合适尺寸  

若小组件空白或过期：先打开一次 Starcat（刷新快照），确认已登录，等待下一次时间线刷新，或重新添加小组件。

## 深层链接

点击条目通常会打开 Starcat 中对应的仓库、Release 时间线或相关界面。Release 链接优先走应用可控的 URL，而不是直接跳到原始 GitHub Release 页。
