## 用来做什么

选中仓库后，右侧是**这一仓的工作台**：读 README、打标签、写笔记、Star / 入库 / 订阅，以及 Pro 的 Health、洞察、相似推荐、AI。列表负责扫，详情负责动手。

面板大致是：元数据头 → 操作区 → README → 标签 / 笔记 / 状态 → AI 浮层入口。

## README

WebView 渲染 GitHub Flavored Markdown，含图片、锚点。**Mermaid** 在本地画，失败则退回源码。

| 操作 | 说明 |
|------|------|
| 浏览器打开 | GitHub 仓库页 |
| Clone | 复制 HTTPS / SSH |
| 导出 Markdown | 导出当前 README |
| 翻译 | Pro，见 [README 翻译](/zh-Hans/ai-features/readme-translation) |
| 分享链接 | 在 Starcat 里定位该仓，见 [分享链接](/zh-Hans/share-export/share-links) |

GitHub README 里的视频用原生控件播：要**手动开始**；切仓或关掉详情立刻停。不支持的来源仍走浏览器。

**设置 → 通用 → 应用内打开仓库文档** 打开后，指向**本仓库**的 Markdown 链接会在独立窗口打开。默认仍用浏览器；**⌘-点击始终用浏览器**。

## Unstar

详情里取消 Star 会打 GitHub API，**不能在 Starcat 里一键撤销**。批量见 [批量操作](/zh-Hans/manage-stars/batch-operations)。

## 注意

- README 是缓存的；刚改过 GitHub 上的文件，可能要等刷新。
- 应用内文档只跟当前仓库的相对 / 同仓链接；外链仍走浏览器。
