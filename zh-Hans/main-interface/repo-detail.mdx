## 面板组成

选中仓库后，右侧详情大致包括：

1. **元数据头**：全名、描述、统计、许可证、主页链接等  
2. **操作区**：Star/Unstar、入库、订阅 Release、Wiki、相似推荐、Health 等（部分需 Pro）  
3. **README**：WebView 渲染 GFM；支持图片、锚点等常见 GitHub 排版  
4. **整理区**：[标签](/zh-Hans/manage-stars/tags)、[笔记与状态](/zh-Hans/manage-stars/notes-and-status)  
5. **AI 浮层入口**：摘要 / 对话等 → [AI 概览](/zh-Hans/ai-features/overview)

## README 常用操作

| 操作 | 说明 |
|------|------|
| 浏览器打开 | 跳转 GitHub 仓库页 |
| Clone 菜单 | 复制 HTTPS / SSH 等 |
| 导出 Markdown | 导出当前 README |
| 翻译 | Pro → [README 翻译](/zh-Hans/ai-features/readme-translation) |
| 分享链接 | 复制可在 Starcat 中定位该仓库的链接 → [分享链接](/zh-Hans/share-export/share-links) |

README 支持常见 GFM，以及 **Mermaid** 图表（本地渲染；失败时回退显示原始内容）。

GitHub README 里的视频可用原生控件播放：需手动开始，切换仓库或关闭详情页后立即停止；不支持的来源继续在浏览器打开。

**设置 → 通用** 可开启「应用内打开仓库文档」。开启后，README 中指向本仓库的 Markdown 链接会在独立窗口打开；默认仍走浏览器，⌘-点击始终打开浏览器。

## Unstar

在详情发起取消 Star 会调用 GitHub API，**不可在 Starcat 内一键撤销**。批量 Unstar 见 [批量操作](/zh-Hans/manage-stars/batch-operations)。
