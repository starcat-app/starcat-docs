## 你要解决的事

你点开一个仓库，是为了决定三件事：它是不是你要的、要不要留下笔记、要不要取消 Star。取消之前你还想知道本地笔记会不会一起没了。

右侧详情就是这个决定页。README、标签、笔记和订阅两边都有。文件下载、外部新增 Star 的提醒也是。Issues 工作台、仓库 Skill、整窗看 README 图片是 Direct 1.9.6。见对应页上的绿胶囊。

## README

WebView 渲染 GitHub Flavored Markdown，含图片、锚点。Mermaid 在本地画，失败则退回源码。

| 操作 | 说明 |
|------|------|
| 浏览器打开 | GitHub 仓库页 |
| Clone | 复制 HTTPS / SSH |
| 导出 Markdown | 导出当前 README |
| 翻译 | Pro，见 [README 翻译](/zh-Hans/ai-features/readme-translation) |
| 分享链接 | 在 Starcat 里定位该仓，见 [分享链接](/zh-Hans/share-export/share-links) |

GitHub README 里的视频用原生控件播：要手动开始；切仓或关掉详情立刻停。不支持的来源仍走浏览器。

**设置 → 通用 → 应用内打开仓库文档** 打开后，指向本仓库的 Markdown 链接会在独立窗口打开。默认仍用浏览器；**⌘-点击始终用浏览器**。

## 文件、Issue 与 Skill

| 入口 | 说明 |
|------|------|
| 文件 | 浏览文件树，预览源码、图片和 Markdown，勾选后下载到本地，含 Git LFS。Markdown 可在渲染和源码间切换，工具栏可翻译 |
| README 图片 | 点正文图片进入整窗浏览，可切换、缩放。关掉后回到原来的阅读位置 |
| Issues | [Issues 工作台](/zh-Hans/main-interface/issues)：列表、新建、总结 |
| Skill | [仓库 Skill](/zh-Hans/manage-stars/skills)：预览、翻译、安装到 Codex 或 Claude Code |
| 许可证 | 点徽章看权利、义务和协议说明。筛选见 [筛选](/zh-Hans/search/filters) |
| 所有者 | 点头像看资料卡，点 owner 或仓库名用浏览器打开 GitHub |

列表里已有笔记的仓库会显示笔记图标和状态胶囊。

## Unstar

详情里取消 Star 会打 GitHub API，不能在 Starcat 里一键撤销。确认前会列出将删除的笔记、标签、AI 内容和缓存。已经入库的仓库可以选择同时移出知识库。删除不能恢复。GitHub 上已不存在的仓库也可以完成本地取消。批量见 [批量操作](/zh-Hans/manage-stars/batch-operations)。

## 注意

- README 是缓存的；刚改过 GitHub 上的文件，可能要等刷新。
- 应用内文档只跟当前仓库的相对 / 同仓链接；外链仍走浏览器。
