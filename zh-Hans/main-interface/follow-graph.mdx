## 你要解决的事

你想顺着一个作者的关注关系，找到下一批值得看的人，不想在 GitHub 个人页一页页翻。

<DirectVersionBadge /> 关注图谱把这些关系摊在一张图上。App Store 1.9.1 还没有。

## 怎么用

1. 打开用户资料卡（详情页点所有者头像或名称，或打开 [GitHub 账户资料](/zh-Hans/main-interface/sidebar)）。
2. 进入关注者或正在关注，图谱占满窗口。
3. 点节点看头像资料卡，可关注或取消关注。
4. 需要更多关系时点「加载更多」。选中路径会高亮。

人数还在加载时，分页不会提前消失。人数和总数对不上时，刷新再试。

## 注意

<Info>
  展开没有固定的节点上限。GitHub 限流时，图谱显示本机估计的恢复时间，等限流过去再继续。
</Info>

只能看到当前登录账号有权读取的公开关系。私有或受限账号会明确提示，不会显示成空图。
