## 用途

侧栏决定当前列表是哪一批仓库或通知。先换一级区域，再点子分类，比在 All Stars 里靠筛选硬收要快。

自上而下：

1. **一级切换**：Manage / 探索 / Activity
2. **当前一级的子导航**（分组可折叠）
3. **用户区**：头像、Pro、分享、登出

分组标题行整行可点折叠；chevron 只表示状态，不是唯一热区。

## Manage

| 入口 | 什么时候用 | 文档 |
|------|------------|------|
| All Stars | 看全部已同步收藏 | - |
| 未分类 / Untagged | 还没打标签，适合每天清一轮 | [标签](/zh-Hans/manage-stars/tags) |
| 知识库 / Library | 已经入库、给 RAG 用的仓 | [知识库](/zh-Hans/knowledge-base/overview) |
| 我的项目 | 自己在做的仓，不必已 Star | [我的项目](/zh-Hans/main-interface/my-projects) |
| 我的洞察 | 看整理进度，点卡片下钻列表 | [洞察](/zh-Hans/main-interface/insights) |
| Languages | 按语言逛 | [筛选](/zh-Hans/search/filters) |
| Tags | 按标签逛；旁边「+」管理标签 | [标签](/zh-Hans/manage-stars/tags) |
| Smart Collections | 规则集合，系统 + 自定义 | [智能集合](/zh-Hans/manage-stars/smart-collections) |
| GitHub Stars Lists | GitHub 上的 List，同步过来 | [GitHub Lists](/zh-Hans/manage-stars/github-lists) |
| Release 时间线 | 已订阅 Release 的聚合 | [时间线](/zh-Hans/release/timeline) |

文案和顺序以当前 App 为准。

## 探索与 Activity

探索：发现、Awesome、趋势、热门、新发布、周刊。见 [探索概览](/zh-Hans/discover/explore/overview)。

Activity 默认是 **通知**（GitHub Inbox），另外还有公告、Release、Star 等本地分类。见 [活动](/zh-Hans/discover/activity/activity)。

## 用户区

- 当前 GitHub 用户
- 进入 Pro / 设置（也可以用菜单）
- [分享卡片](/zh-Hans/share-export/share-cards)
- 登出换号，见 [账号连接](/zh-Hans/getting-started/github-connection)

## 注意

- 点「未分类」不会自动打标签，只是把范围收窄。
- 知识库入口空，说明还没入库，不是同步失败。
- 折叠分组不会删数据。
