## 用来做什么

Stars 是「收藏待读」。**我的项目**是「我正在做 / 我有权限的仓」：个人拥有、组织成员、外部协作者，**跟有没有 Star 无关**。

适合把工作仓和收藏库分开：工作仓走我的项目，逛到的开源库继续放在 Stars 里。

## 怎么用

侧栏 **Manage → 我的项目**。

| 能力 | 说明 |
|------|------|
| 按归属浏览 | 个人拥有 / 组织 / 协作者 |
| 筛选与搜索 | 复用 Manage 列表的筛选和 ⌘F |
| 详情 | 已缓存仓的 README、标签、笔记、Health、AI |
| Star 趋势 | GitHub 允许读 stargazer 历史时可用 |

## 授权

| 来源 | 通常能看到 |
|------|------------|
| 主登录（OAuth / PAT） | 能列出的**公开**项目 |
| **GitHub App**（应用内安装） | 安装范围内的**私有**和 **Internal** |

看不到私仓时：在 App 里完成 GitHub App 授权，确认覆盖了对应组织 / 仓库，再同步一次。步骤见 [连接 GitHub](/zh-Hans/getting-started/github-connection)。

## 注意

- 私有项目**不会**出现在 Discover / 趋势这类公开发现面。
- 部分仅对公开仓开放的信号（例如部分 OpenSSF 路径）在私仓上可能没有。
- 私仓洞察里需要更高权限的指标会走 GitHub App token，见 [洞察](/zh-Hans/main-interface/insights)。
- Unstar 仍然走 GitHub API，和 Stars 列表里的行为一样。
