## 是什么

**我的项目**列出你**拥有、所属组织或外部协作**的仓库——与是否 Star 无关。

适合日常管理「自己在做的项目」（含私有 / Internal），同时把 Stars 继续当作「收藏待读」库。

## 入口

侧栏 → **Manage → 我的项目**（文案以 App 为准）。

## 能做什么

| 能力 | 说明 |
|------|------|
| 按归属浏览 | 个人拥有 / 组织成员 / 协作者 |
| 筛选与搜索 | 在可用范围内复用 Manage 列表能力 |
| 详情栏 | 本地已缓存仓库的 README、标签、笔记、Health、AI 等 |
| Star 趋势 | 在 GitHub 权限允许读取 stargazer 历史时可用 |

## 授权说明

| 来源 | 通常覆盖范围 |
|------|----------------|
| 主 GitHub 登录（OAuth / PAT） | 可列出的公开项目 |
| **GitHub App**（应用内授权） | 安装范围内授权的**私有**与 **Internal** 项目 |

私有项目不会进入 Discover / 趋势类公开发现面。

若看不到私仓：完成应用内 GitHub App 授权，确认安装覆盖正确的组织 / 仓库，再同步一次。
