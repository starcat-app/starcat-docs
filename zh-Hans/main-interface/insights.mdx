## 概览

洞察帮助你**看清整个收藏库的状态**，并在**单个仓库**上快速理解活动与健康信号。

| 界面 | 范围 | 入口 |
|------|------|------|
| **我的洞察** | 全部收藏 **或** 知识库 | 侧栏 → Manage → 我的洞察 |
| **仓库洞察** | 当前选中仓库 | 仓库详情中的洞察入口 |

## 我的洞察

可查看：

- 整理进度与分诊指标  
- 技术 / 语言 / Topic 等分布（以界面展示为准）  
- 项目状态与可能需要清理的资产  
- 可**下钻**到对应仓库列表的待办项  

在「全部收藏」与「知识库」之间切换范围；需要新鲜数据时手动刷新。

## 仓库洞察

常见区块（取决于网络、权限与缓存）：

- Star 增长与协作活动  
- 提交趋势与贡献者  
- 发布节奏；最新 Release 可查看前 3 个附件，可展开全部，并复制链接或下载到本地  
- 项目健康度、社区规范与安全信号  
- 最近 5 条已发布安全公告：风险等级、GHSA / CVE、发布日期和发布者，可打开公告详情或 GitHub 完整列表 

切换仓库或刷新时内容应保持稳定；部分 GitHub 统计接口可能短暂处于生成中并自动重试。

### 私有「我的项目」

[我的项目](/zh-Hans/main-interface/my-projects) 中的私仓，需要更高权限的指标会走 **GitHub App** token。部分仅公开仓可用的信号（例如部分 OpenSSF 路径）可能仍不可用。

## 洞察上下文（AI / RAG）

洞察生成后，可作为**可移除的只读 XML 上下文**参与：

- AI 仓库摘要  
- 仓库对话  
- [RAG 工作台](/zh-Hans/knowledge-base/rag-workspace) 回答  

当洞察不可用、自定义提示词未注入，或发生回退时，界面会给出明确状态。

全局洞察聚合事实也可作为知识库问答的共享上下文。
