## 用途

中栏列出当前侧栏分类下的仓库：Manage 里是你的仓库，探索里是榜单结果。点一行，右边打开详情。

一行里通常能看到：全名和描述摘要、语言与 Star 数、标签胶囊、Health / OpenSSF 徽章（有缓存才显示）、Manage 置顶角标、AI 摘要是否已生成。

## 置顶（仅 Manage）

右键或行内操作 **Pin / Unpin**。当前分类内按最近置顶优先。置顶也会给 [Focus 小组件](/zh-Hans/main-interface/widgets) 当候选。探索榜单没有同样的个人置顶语义。

## 工具栏

| 控件 | 作用 | 文档 |
|------|------|------|
| 筛选 | 状态 / 入库 / 语言 / Wiki / Health… | [筛选](/zh-Hans/search/filters) |
| 多选 | 底部批量栏 | [批量操作](/zh-Hans/manage-stars/batch-operations) |
| 同步 | 拉 GitHub Stars | [同步](/zh-Hans/settings/sync) |
| 列表搜索 | ⌘F 关键词或语义 | [列表搜索](/zh-Hans/search/global-search) |
| 集合齿轮 | 编辑当前 Smart Collection | [智能集合](/zh-Hans/manage-stars/smart-collections) |

选中仓库后，右侧还可能出现外链、Clone、分享、AI、CodeFlow。总览见 [工具栏](/zh-Hans/main-interface/toolbar)。

## 探索列表

- 数据来自发现 / 趋势 / 周刊服务，不是「仅你的 Stars」
- 批量更偏 Star / 入库
- 筛选维度通常更少

见 [探索概览](/zh-Hans/discover/explore/overview)。

## 注意

- 列表空：先看筛选是否过严，再点重置；不要先怀疑同步坏了。
- 筛选条件常按模块记住：从「标签 A」切回 All Stars，两边可能恢复各自上次条件。
- 行距 Comfortable / Compact 在 [通用设置](/zh-Hans/settings/general)。
