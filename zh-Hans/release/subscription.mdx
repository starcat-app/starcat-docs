## 用来做什么

订阅之后，Starcat 轮询该仓的 GitHub Release，更新 [时间线](/zh-Hans/release/timeline)，并可选发 [系统通知](/zh-Hans/release/notifications)。适合真正在用、发版会影响你的库，不要把免费 5 个名额浪费在随便 Star 过的仓上。

<Note>
  免费最多 **5** 个仓库；Pro 不限。见 [方案对比](/zh-Hans/subscribe/plan-comparison)。
</Note>

## 怎么订

1. 打开详情：目标仓需已 Star **或** 已入库
2. 点「订阅 Release」
3. 首次可能弹出系统通知权限，建议允许

| 状态 | 可订阅 |
|------|--------|
| 已 Star | ✅ |
| 未 Star 但已入库 | ✅ |
| 两者皆无 | ❌ |

未关联时历史订阅可能保留但暂停轮询 → [后台刷新](/zh-Hans/release/background-refresh)。

取消：详情或订阅列表里取消，释放免费名额。管理入口：侧栏 Release 时间线、Activity → Release 分类。

## 注意

- 没 Star 也没入库的仓订不了。
- 免费满 5 个后再订会被门控；先取消低优先级，或升级 Pro。
- 订阅不等于自动下载安装包，下载见 [资产下载](/zh-Hans/release/assets-download)。
