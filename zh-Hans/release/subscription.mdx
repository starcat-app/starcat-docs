## 做什么

订阅后，Starcat 轮询该仓 GitHub Release，更新[时间线](/zh-Hans/release/timeline)，并可选发[系统通知](/zh-Hans/release/notifications)。

<Note>
  免费最多 **5** 个仓库；Pro 不限。见 [方案对比](/zh-Hans/subscribe/plan-comparison)。
</Note>

## 订阅步骤

<Steps>
  <Step title="打开详情">目标仓需已 Star 或已入库。</Step>
  <Step title="点订阅">详情区「订阅 Release」。</Step>
  <Step title="允许通知">首次可能弹出系统权限，建议允许。</Step>
</Steps>

## 资格表

| 状态 | 可订阅 |
|------|--------|
| 已 Star | ✅ |
| 未 Star 但已入库 | ✅ |
| 两者皆无 | ❌ |

未关联时历史订阅可能保留但暂停轮询 → [后台刷新](/zh-Hans/release/background-refresh)。

## 取消

详情或订阅列表中取消，释放免费名额。

## 管理入口

- 侧栏 Release 时间线  
- Activity → Release 分类
