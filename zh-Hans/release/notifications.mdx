## 用来做什么

已订阅仓出了新 Release、轮询检测到更新时，你可能收到 macOS 横幅，以及时间线 / Activity 里的未读。通知是提醒，下载安装包仍要自己点资产。

## 打开条件

| 检查项 | 在哪里 |
|--------|--------|
| 已订阅该仓 | [订阅管理](/zh-Hans/release/subscription) |
| 未超免费 5 仓（或已是 Pro） | [方案对比](/zh-Hans/subscribe/plan-comparison) |
| 系统通知权限已允许 | 首次订阅时的对话框；可在系统设置改 |
| App 内 Release 通知开关 | **设置 → 通用 → 通知** |
| 后台轮询正常 | [后台刷新](/zh-Hans/release/background-refresh) |

通知通常含仓库名、版本号（tag）、Release 标题。点击跳到对应 Release / 时间线。

不想被打扰：关系统通知，或关 App 内 Release 开关；或取消低优先级订阅以省名额。

## 注意

- 没允许系统权限就没有横幅，时间线未读仍可能在。
- 点击系统通知往往落到通知时间线或 Release 时间线，见 [Activity](/zh-Hans/discover/activity/activity)。
