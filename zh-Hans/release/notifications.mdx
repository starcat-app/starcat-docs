## 通知从哪来

当**已订阅**仓库出现新 Release，且轮询检测到更新时，你可能收到：

1. **macOS 系统通知**（横幅 / 通知中心）  
2. **应用内未读**（时间线红点、Activity 等）  

## 打开条件清单

| 检查项 | 在哪里 |
|--------|--------|
| 已订阅该仓 | [订阅管理](/zh-Hans/release/subscription) |
| 未超免费 5 仓限额（或已是 Pro） | [方案对比](/zh-Hans/subscribe/plan-comparison) |
| 系统通知权限已允许 | 首次订阅时的系统对话框；可在系统设置里改 |
| App 内 Release 通知开关 | **设置 → 通用 → 通知** |
| 后台轮询正常 | [后台刷新](/zh-Hans/release/background-refresh) |

## 通知内容

通常含：仓库名、版本号（tag）、Release 标题。点击可跳到对应 Release / 时间线。

## 不想被打扰时

- 关系统通知，或关 App 内 Release 通知开关  
- 或取消低优先级仓库的订阅以省名额
