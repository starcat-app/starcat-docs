## 资产列表

在[时间线](/zh-Hans/release/timeline)或 Release 详情中展开资产区：

- 显示文件名与大小  
- 可下载 / 打开（交由系统处理）  
- 资产较多时可展开查看全部  

## 过滤技巧

使用时间线顶部过滤框，按关键字匹配文件名，例如只看 macOS 安装包：

```text
dmg
```

或 CPU 架构：

```text
arm64
```

无需记完整文件名。
