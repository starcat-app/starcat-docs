## 用途

发版附件（`.dmg`、checksum、各架构包）在时间线或 Release 详情的资产区浏览。Starcat 列出文件名和大小，下载 / 打开交给系统，不做静默安装。

## 怎么用

展开资产区：看文件名与大小；可下载 / 打开；资产多时可展开全部。

时间线顶部过滤框按关键字匹配文件名，不必记完整名：

```text
dmg
arm64
linux
```

GitHub Release 概念见 [GitHub Docs · Releases](https://docs.github.com/en/repositories/releasing-projects-on-github)。

## 注意

过滤只作用于当前时间线可见的文件名，不是 GitHub 全站搜索。

下载的是上游产物，Starcat 不替你验签；checksum 要自己对。
