## 用途

不用一直开着时间线，Starcat 也会按间隔检查已订阅仓有没有新 Release。刚发版想马上确认时，用时间线的「立即检查」。

## 机制（用户向）

macOS 后台任务按间隔检查（默认约数小时一级，带抖动；以当前实现为准）。使用条件请求 / ETag，降低 GitHub API 消耗。仅轮询仍有效关联的目标（已 Star 或已入库）。

免费最多 5 个订阅；名额内才会持续有用。见 [订阅管理](/zh-Hans/release/subscription)。

## 排障

| 现象 | 尝试 |
|------|------|
| 很久没有新通知 | 时间线 → 立即检查；确认订阅仍有效 |
| Rate Limit | 等待重置；减少连点立即检查 |
| 系统杀掉后台 | 是否允许 App 后台活动；打开 App 后再查一次 |
| 没有横幅 | [通知设置](/zh-Hans/release/notifications) + 系统通知权限 |
