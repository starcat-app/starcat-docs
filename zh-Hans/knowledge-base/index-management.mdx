## 用途

入库之后，RAG 还要等索引建好。覆盖率低表示很多已入库仓还不能检索。Chat 配好但 Embedding 空着时，向量侧会是空的。

## 状态看哪里

RAG 工作台顶栏或 Index 页签：知识库仓库数、索引覆盖率（关键词 / 向量等以界面为准）、当前 Embedding 提示。

向量化进度按当前 Embedding 模型的已就绪覆盖率显示。工具栏状态面板也可查看与暂停；最近一次构建不会在未完成时误标完成。

知识库卡片和分片详情会区分：分片是否仍在库里、当前模型下是否已向量化、更新时间与约略 token 数。点开待处理、失败或过期卡片，会打开知识库并定位到对应分片。

重建时 Meilisearch 关键词索引会先同步文本，不必等全部向量化就能检索。本地 FTS 对中文支持中缀匹配；点名仓库时更容易落到 README。

## 何时重建

| 情况 | 建议 |
|------|------|
| 换了 Embedding 模型 | 重建，否则空间不一致 |
| 刚批量入库很多仓 | 等自动索引或手动补齐 |
| 清过缓存后检索变空 | 重建 |
| 长期「找不到」但库非空 | 先看覆盖率与 @ 是否过窄 |

重建耗时与 API 费用随库规模上升；大库请盯进度与取消。
