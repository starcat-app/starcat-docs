## 用途

RAG 工作台左栏是问答线程列表。换题目就新建会话。导出 Markdown 可以贴进笔记软件或做归档。

## 怎么用

| 操作 | 说明 |
|------|------|
| 新建会话 | 开一条新问答线程 |
| 打开历史 | 回看过往问答 |
| 置顶 | 固定到列表前部（后置顶的通常更靠前） |
| 重命名 | 用主题名方便找回 |

切换会话时，未发送输入会按产品逻辑保留或提示，避免误丢。

可将单次回答或会话 transcript 导出为 Markdown。入口在工作台菜单或会话操作中（以界面为准）。

## 注意

会话占本地磁盘。**设置 → 存储** 可清「RAG 会话历史」。见 [存储管理](/zh-Hans/settings/storage)。

清理历史不会取消入库，也不会删标签或笔记。
