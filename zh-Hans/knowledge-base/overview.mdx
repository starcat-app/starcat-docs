## 用来做什么

知识库是你**主动入库**的精选仓库，给 RAG 工作台检索和问答用。它不是「全部 Stars 的另一个名字」。Star 了不等于能问；问的是你精选过的那一批。

## Stars vs 知识库

| | Stars | 知识库 |
|--|-------|--------|
| 来源 | GitHub 收藏同步 | 你在 Starcat 标记入库 |
| 规模 | 可达数千 | 建议精选（常见几十～两百） |
| 列表搜索 | ✅ | ✅（也可限定 knowledge） |
| 默认 RAG 范围 | ❌ | ✅ 仅已入库 |
| 典型索引 | FTS 等 | 分片 + 关键词 + 向量 |

务必记住：

- Star **不会**自动入库
- Unstar **不会**自动移出知识库
- 未 Star 但已入库：仍可问答，也可 [订阅 Release](/zh-Hans/release/subscription)

## 你需要什么

1. [Pro](/zh-Hans/subscribe/plan-comparison)
2. Chat + **Embedding** → [AI 配置](/zh-Hans/ai-features/configuration)
3. 若干已入库仓库 → [添加入库](/zh-Hans/knowledge-base/adding-repos)

缺 Embedding 时工作台可能能开，但向量检索建不起来。见 [索引管理](/zh-Hans/knowledge-base/index-management)。

## 能力地图

| 我想… | 去哪 |
|------|------|
| 把仓放进知识库 | [添加入库](/zh-Hans/knowledge-base/adding-repos) |
| 开始提问 | [RAG 工作台](/zh-Hans/knowledge-base/rag-workspace)（⇧⌘K） |
| 看引用原文 | [引用与证据](/zh-Hans/knowledge-base/citations) |
| 管理历史会话 | [会话管理](/zh-Hans/knowledge-base/session-management) |
| 索引覆盖率低 | [索引管理](/zh-Hans/knowledge-base/index-management) |

建议路径：精选 20～50 个仓（优先「正在使用」）→ 确认 Embedding 与覆盖率 → 先 @ 单仓试问 → 再做跨仓问题。

入口：侧栏 Manage → 知识库 / Library；工具栏「知识库问答」或 **⇧⌘K**；与知识库相关的 Smart Collections。

## 注意

- [语义搜索](/zh-Hans/search/semantic-search) 是列表级向量检索，不是工作台问答。
- 入库太多会拉长索引时间和 Embedding 账单；精选比「全 Star 入库」更有用。
