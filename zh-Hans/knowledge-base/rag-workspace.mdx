## 打开（Pro）

| 方式 | 说明 |
|------|------|
| 快捷键 | 默认 **⇧⌘K**（可改 → [快捷键](/zh-Hans/settings/shortcuts)） |
| 工具栏 | 「知识库问答」 |
| 其它入口 | 知识库页 / 相关 Smart Collection |

前置：

1. [Pro](/zh-Hans/subscribe/plan-comparison)  
2. Chat + Embedding 已在 [设置 → AI](/zh-Hans/settings/ai) 配好  
3. 知识库里至少有一些[已入库](/zh-Hans/knowledge-base/adding-repos)仓库  

## 三栏布局

```
┌────────────┬─────────────────────┬──────────────────┐
│ 会话列表    │ 问答流 + 执行时间线   │ 引用 / 计划 / 索引 │
│ 新建/置顶   │ Composer + @        │ Evidence / Index  │
└────────────┴─────────────────────┴──────────────────┘
```

- 左右栏可拖拽调宽，重开窗口常会恢复  
- 中栏在生成时可看到检索/规划/生成等步骤，运行中可手动折叠  

## 提问流程

<Steps>
  <Step title="写问题">
    尽量具体。例如：
    - 「我知识库里做本地优先同步的库，冲突策略有哪些？」
    - 「@foo/bar @baz/qux 这两个在嵌入式场景怎么选？」
  </Step>
  <Step title="@ 选仓（可选）">
    输入 `@` 打开知识库仓库选择器；可多选；顶部芯片可删。
    用于 only / prefer / exclude 一类范围控制（以界面语义为准）。
  </Step>
  <Step title="发送">
    观察时间线；等待流式或分段输出。
  </Step>
  <Step title="核对引用">
    点击回答中的引用芯片 → 右侧证据。见 [引用与证据](/zh-Hans/knowledge-base/citations)。
  </Step>
</Steps>

## 默认检索范围

**只检索已入库仓库**，不包含「仅 Star 未入库」。

空库时会出现引导：从 Smart Collections、Search、Explore 入库。见 [添加入库](/zh-Hans/knowledge-base/adding-repos)。

## 联网上下文

若启用 External Search 作为实时上下文：

- 成功时回答可能混入网页证据  
- 失败时卡片可能引导你打开 **设置 → 集成 → External Search**  

见 [外部搜索](/zh-Hans/search/external-search)。

## 只读承诺

工作台以问答为主：**不会**在未确认时改标签 / 笔记 / 状态。要改数据请用整理 UI 或 [CLI `--apply`](/zh-Hans/cli/usage)。

## 会话与导出

左栏管理历史；可导出 Markdown。见 [会话管理](/zh-Hans/knowledge-base/session-management)。

## 索引不健康时

顶栏覆盖率过低或提示无索引 → [索引管理](/zh-Hans/knowledge-base/index-management)。

## 洞察上下文

已生成的 [洞察](/zh-Hans/main-interface/insights)（全局聚合与单仓）可作为可移除的只读上下文参与回答。自定义提示词若未包含洞察占位符，不会静默注入。
