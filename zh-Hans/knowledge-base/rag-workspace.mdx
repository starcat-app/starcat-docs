## 用途

对着已入库的仓库问跨仓问题。单仓 README 细节用 [AI 对话](/zh-Hans/ai-features/chat)。默认不会扫「只 Star 未入库」的收藏。

## 怎么打开（Pro）

| 方式 | 说明 |
|------|------|
| 快捷键 | 默认 **⇧⌘K**（[可改](/zh-Hans/settings/shortcuts)） |
| 工具栏 | 「知识库问答」 |
| 其它 | 知识库页 / 相关 Smart Collection |

前置：[Pro](/zh-Hans/subscribe/plan-comparison)、[设置 → AI](/zh-Hans/settings/ai) 的 Chat + Embedding、至少一些[已入库](/zh-Hans/knowledge-base/adding-repos)仓库。

三栏：左会话（新建 / 置顶）、中问答流 + Composer + @、右引用 / 计划 / 索引。左右栏可拖宽，重开常会恢复。生成时可看到检索 / 规划 / 生成步骤，运行中可折叠。较长思考时界面仍可操作；规划子步骤等规划真正完成后再出现。

## 怎么问

1. 写具体问题，例如「我知识库里做本地优先同步的库，冲突策略有哪些？」
2. 可选：输入 `@` 打开仓库选择器，多选；顶部芯片可删。用于 only / prefer / exclude（以界面为准）
3. 发送，看时间线
4. 点回答里的引用芯片 → 右侧证据。见 [引用与证据](/zh-Hans/knowledge-base/citations)

空库时会引导从 Smart Collections、Search、Explore 入库。

若启用 External Search 作实时上下文：成功时可能混入网页证据；失败时卡片可能引导打开 **设置 → 集成 → External Search**。见 [外部搜索](/zh-Hans/search/external-search)。

齿轮里可改推理后端、提示词和检索策略。提示词见 [AI 配置](/zh-Hans/ai-features/configuration)。

**Direct：** 可选本机 Codex CLI 或 Claude Code CLI，沿用它们自己的登录态。工作台会检测安装 / 版本 / 路径。App Store 版没有这条路径。

已生成的 [洞察](/zh-Hans/main-interface/insights) 可作为可移除的只读上下文；自定义提示词没写洞察占位符就不会静默注入。

## 注意

- 工作台以问答为主：不会在未确认时改标签 / 笔记 / 状态。改数据用整理 UI 或 [CLI `--apply`](/zh-Hans/cli/usage)。
- 顶栏覆盖率过低 → [索引管理](/zh-Hans/knowledge-base/index-management)。
- 会话导出见 [会话管理](/zh-Hans/knowledge-base/session-management)。
