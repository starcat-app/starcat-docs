## 用来做什么

**热门**看高热度仓库；**新发布**看最近出过稳定版 Release 的项目。两者都来自 Starcat 发现项目池，不是你的 Stars 列表。发现之后仍要自己决定要不要 Star / 入库。

## 热门

侧栏 **探索 → 热门**。数据来自 Starcat 发现项目池。

- 归档和 Fork 不会进入
- 需要达到 **1,000 Stars**，或达到综合热度门槛
- 综合热度参考 Stars、Forks、Release 下载量和近期活跃度

缓存有效期 **3 小时**，与发现、新发布共享同一份项目目录。过期后重新拉共享目录并计算热门列表；失败时继续用上次成功缓存并提示可能不是最新。

## 新发布

侧栏 **探索 → 新发布**。数据来自发现项目池中的 GitHub Releases。

- 仅收录最近 **180 天**发布过稳定版本的项目
- 草稿、预发布、没有可下载内容的 Release、归档和 Fork 不会进入
- 默认按项目最近一次发布时间排序

缓存同样是 **3 小时**共享目录；过期后重新拉项目及 Release；失败时保留上次成功缓存。

## 注意

发现好项目后：可选 Star → 打标签 / 写一句笔记 → 长期用的再 [入库](/zh-Hans/knowledge-base/adding-repos)。热门 ≠ 适合你的栈；新发布 ≠ 已经稳定到可以上生产。
