## 用来做什么

侧栏 **探索 → Awesome** 按主题清单发现仓库，而不是再刷一遍已经 Star 过的列表。适合「我想看看 awesome-go / awesome-rust 里还漏了什么」。

## 怎么选来源

第一次点进 Awesome 会打开「选择 Awesome 来源」。之后也可从 Awesome 页再打开「管理 Awesome 来源」。

| 来源 | 说明 |
|------|------|
| Starcat 精选 | 来自探索服务的公开 Awesome 目录，勾选后点完成写入 |
| 自定义 | 粘贴公开 GitHub 仓库地址（例如 `owner/awesome-xxx`）；校验成功后立即启用 |

自定义来源必须是**公开**仓库。已归档或不可用的来源无法添加。来源、README 和解析结果只保存在当前 GitHub 账号的本地数据库。

自定义列表会在后台增量解析，进度显示在来源卡片上。解析未完成时仍可先看已就绪的条目。

## 怎么浏览

选中一个来源后，中栏列出该 Awesome README 里的仓库。点选后右侧打开详情，可继续 Star、打标签、[入库](/zh-Hans/knowledge-base/adding-repos) 或 [订阅 Release](/zh-Hans/release/subscription)。

工具栏可主动刷新当前来源。来源目录与条目有本地缓存；网络短暂不可用时继续显示上次成功数据。

## 注意

- 自定义地址必须能被 GitHub 公开访问；私有 awesome 仓加不进去。
- 解析是增量的，卡片上的进度不等于已经扫完 README 里每一个链接。
- Awesome 发现流和你的 Stars 列表是两套数据，Star 之后记得回 Manage 打标。
