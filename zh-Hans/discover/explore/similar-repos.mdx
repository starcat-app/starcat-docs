## 用途

当前仓库可以带出替代实现或同领域项目，不必再自己搜 topic。桌面端在详情操作区打开；插件在 GitHub 仓库页给只读列表。

## 怎么用（桌面 · Pro）

在仓库详情操作区打开 相似仓库 / 推荐。

- 需要网络访问推荐服务
- Direct 版走自研推荐链路读取离线训练结果；现有入口和缓存行为保持不变
- 非 Pro 会遇到付费墙

见 [方案对比](/zh-Hans/subscribe/plan-comparison)。

## 浏览器插件

GitHub 仓库页可展示只读推荐列表（通常有条数上限）。需要本机 App + [集成设置](/zh-Hans/settings/integrations)。见 [插件功能](/zh-Hans/browser-plugin/features)。

## 注意

推荐是「可能相关」，不是依赖审计。Star 之前仍要读 README 和许可证。

服务不可达时列表会空或过期，不能当成「没有相似项目」。
