## 五种探索模式

| 模式 | 你在找什么 | 专页 |
|------|------------|------|
| **发现** | 综合推荐流；可按 topic / platform 筛 | 本页下方 |

### 数据来源

GitHub Search、仓库资料和 Release 数据。

### 入选规则

- Starcat 综合收录高关注度、近 30 天活跃，以及近一年出现的新项目。
- 推荐会综合考虑近期活跃度、主题相关性和平台匹配度。
- 项目池会定期更新，并不代表 GitHub 全站的全部仓库。

### 缓存说明

- **缓存有效期**：3 小时，与热门、新发布共享同一份项目目录缓存。
- **更新方式**：有效期内优先读取本地缓存；过期后重新获取最新项目目录。
- **离线处理**：更新失败时继续使用上次成功缓存，并提示内容可能不是最新。

## 发现好项目之后

建议流水线：

1. 打开详情读 README  
2. 可选：Star  
3. 打标签或写一句笔记  
4. 长期要用 → [入库](/zh-Hans/knowledge-base/adding-repos)  
5. 要追版本 → [订阅 Release](/zh-Hans/release/subscription)（注意免费 5 仓限额）  

批量处理见 [批量操作](/zh-Hans/manage-stars/batch-operations)。
