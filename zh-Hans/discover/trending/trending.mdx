## 用来做什么

侧栏 **探索 → 趋势** 看 GitHub **日榜 / 周榜 / 月榜**里短期关注度变化。适合每天扫一眼「今天在涨什么」，**不等同于** [热门](/zh-Hans/discover/explore/hot-and-new) 那种长期高热度。

## 数据与规则

来源：GitHub Trending，并通过 GitHub API 补全仓库资料。展示日榜、周榜和月榜中的项目。

缓存：日榜 **1 小时**、周榜 **6 小时**、月榜 **24 小时**。过期后先显示已有榜单，同时在后台更新；手动刷新会立即请求最新数据。失败时保留当前缓存，不会清空已有榜单。

可按语言等条件查看（控件以 App 为准）。打开详情、Star、入库。

## 注意

趋势是短期噪声友好型榜单。上榜不等于适合入库；先读 README 再决定。服务仓库（外部）：[starcat-trending-api](https://github.com/starcat-app/starcat-trending-api)。
