## 系统要求

| 要求 | 说明 |
|------|------|
| **操作系统** | macOS 15 Sequoia 或更高 |
| **芯片** | Apple Silicon（M 系列） |
| **网络** | 同步 GitHub、探索、在线购买等需要联网 |
| **GitHub** | 需要 GitHub 账号以同步 Stars |

目前仅提供 macOS 客户端，无 Windows / Linux 桌面版。CLI 可在多平台安装，但数据与权限仍由本机（或已配对的）Starcat App 提供，见 [CLI 安装](/zh-Hans/cli/installation)。

## 下载渠道

### Mac App Store

- 链接：[Starcat for GitHub](https://apps.apple.com/cn/app/starcat-for-github/id6788809803?mt=12)
- 自动更新；运行在 App Store **沙盒** 中
- Pro 走 StoreKit（Apple ID）

### Direct（官网）

- 链接：[starcat.ink](https://starcat.ink)
- 下载 DMG，拖入「应用程序」
- 更新由 **Sparkle** 检查
- Pro 走官网结账 + License（见 [许可证](/zh-Hans/subscribe/license)）

<Warning>
  App Store 版与 Direct 版的**本地数据目录相互独立**。换渠道等于换一套本地库，请先按 [备份与恢复](/zh-Hans/data-privacy/backup) 处理，不要直接混拷数据库文件。
</Warning>

## 安装步骤

<Steps>
  <Step title="下载">从 App Store 或官网获取最新版。</Step>
  <Step title="安装">
    - App Store：自动装入 Applications
    - Direct：打开 DMG，将 Starcat 拖到 Applications
  </Step>
  <Step title="首次打开">
    若被 Gatekeeper 拦截：系统设置 → 隐私与安全性 → 仍要打开。
  </Step>
  <Step title="首次引导">
    全屏欢迎仅首次出现。之后可在 **设置 → 通用** 重看首次引导（会重置 Getting Started 清单进度）。
  </Step>
</Steps>

## 更新

| 渠道 | 方式 |
|------|------|
| App Store | 启动或重新激活时自动检测新版本；也可从 **操作** 菜单或菜单栏点「检查更新」，再前往 Mac App Store 升级。Starcat 不替你下载商店包。 |
| Direct | 启动时由 **Sparkle** 检查；也可在设置或 **操作** 菜单里手动检查并安装 |
