## 目标

第一次打开 Starcat，完成：**登录 → 同步 Stars → 浏览并整理一个仓库**。

## 三步上手

<Steps>
  <Step title="连接 GitHub">
    使用「GitHub 登录」或 PAT。权限与多账号说明见 [GitHub 账号连接](/zh-Hans/getting-started/github-connection)。
  </Step>
  <Step title="主动点击同步">
    登录后，点击列表工具栏的 **同步** 按钮，拉取 Stars。
    <Warning>
      界面上的 Getting Started 清单里，「同步」一步通常要你**亲手点同步**才会勾选完成；登录本身不等于已同步。
    </Warning>
    - 进度体现在同步按钮上
    - Star 很多时可能需要数分钟；同步过程中已拉到的仓库可先浏览
    - 若近期刚同步过，启动时可能跳过自动同步（以 App 策略为准），仍建议首次手动点一次
  </Step>
  <Step title="浏览与整理">
    侧栏进入 **Manage → All Stars**（文案以 App 为准）：
    1. 点击一个仓库 → 右侧阅读 README
    2. 在详情里添加标签或笔记
    3. 需要时点心形加入[知识库](/zh-Hans/knowledge-base/adding-repos)
  </Step>
</Steps>

## Getting Started 清单

登录后主界面可能出现可折叠清单（约十余步），例如：同步、选中仓库、打开 GitHub 主页、入库、整理、搜索、试用 AI、打开 RAG、分享卡、Unstar 等。

| 特性 | 说明 |
|------|------|
| 推进方式 | 由**真实操作**驱动，不是点「下一步」 |
| 关闭 | 可折叠或关闭 |
| 重看 | **设置 → 通用 → 重看首次引导**（同时重置清单进度） |

首次欢迎含功能截图。部分控件带黄色胶囊提示（同步、搜索、AI 等），避免与系统提示叠层。

## 第一天建议捷径

| 你想… | 怎么做 |
|------|--------|
| 全局找仓库 / 搜 GitHub / 搜网页 | 默认 **⌘K** 打开 [Search Center](/zh-Hans/search/search-center) |
| 过滤当前列表 | 列表搜索框（默认常为 **⌘F**，可改）+ [筛选](/zh-Hans/search/filters) |
| 打开仓库 AI | 默认 **⇧⌘A**（需 [Pro](/zh-Hans/subscribe/plan-comparison) + [AI 配置](/zh-Hans/ai-features/configuration)） |
| 打开 RAG 工作台 | 默认 **⇧⌘K** 或工具栏「知识库问答」 |
| 看新版本 | [Release 订阅](/zh-Hans/release/subscription)（免费最多 5 个仓库） |

快捷键均可在 [快捷键设置](/zh-Hans/settings/shortcuts) 修改。
