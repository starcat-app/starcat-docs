## 用途

第一次打开 Starcat，只要完成三件事：登录 GitHub、点同步拉 Stars、打开一个仓库做点整理。后面的标签体系、知识库和 AI 都可以等库里有数据再配。

登录只建立会话。Getting Started 清单里的「同步」一步，通常要你亲手点工具栏同步才会勾上。

## 三步上手

<Steps>
  <Step title="连接 GitHub">
    用「GitHub 登录」或 PAT。App Store 走系统浏览器授权；Direct 还可选 Device Flow / PAT。权限与多账号见 [GitHub 账号连接](/zh-Hans/getting-started/github-connection)。
  </Step>
  <Step title="点同步">
    登录后，点中栏工具栏的 **同步**（统一的旋转箭头图标）。
    <Warning>
      不要等它「自己变有数据」。没点同步，列表经常是空的。
    </Warning>
    - 进度在同步按钮上转
    - Star 很多时可能要几分钟；已经拉下来的仓库可以边下边看
    - 近期刚同步过，启动时可能跳过自动同步，第一次仍建议手动点一次
  </Step>
  <Step title="打开一个仓库整理">
    侧栏 **Manage → All Stars**：
    1. 点一行，右侧读 README
    2. 加一个标签或写一句笔记
    3. 长期要用的，点心形加入 [知识库](/zh-Hans/knowledge-base/adding-repos)
  </Step>
</Steps>

## Getting Started 清单

登录后主窗口可能出现可折叠清单（十来步），例如：同步、选中仓库、打开 GitHub、入库、整理、搜索、试用 AI、打开 RAG、分享卡、Unstar。

| 行为 | 说明 |
|------|------|
| 怎么推进 | 靠真实操作勾选，不是点「下一步」 |
| 关掉 | 可以折叠或关闭，不挡使用 |
| 再看一遍 | **设置 → 通用 → 重看首次引导**（同时重置清单进度） |

## 第一天常用操作

| 你想… | 怎么做 |
|------|--------|
| 全局找仓库 / 搜 GitHub / 搜网页 | **⌘K** [Search Center](/zh-Hans/search/search-center) |
| 过滤当前列表 | **⌘F** + [筛选](/zh-Hans/search/filters) |
| 打开当前仓库 AI | **⇧⌘A**（需 [Pro](/zh-Hans/subscribe/plan-comparison) 和 [AI 配置](/zh-Hans/ai-features/configuration)） |
| 打开 RAG 工作台 | **⇧⌘K** 或工具栏「知识库问答」 |
| 盯新版本 | [Release 订阅](/zh-Hans/release/subscription)（免费最多 5 个仓库） |

快捷键可在 [快捷键](/zh-Hans/settings/shortcuts) 改。

## 注意

- 同步受 GitHub API 速率限制。大号第一次全量会久一些，失败先看 [FAQ · 同步](/zh-Hans/faq/sync)。
- 还没配 AI 也能整理标签和笔记；Pro 不是上手的前置条件。
- 私有「我的项目」还要额外授权 GitHub App，见 [我的项目](/zh-Hans/main-interface/my-projects)。
