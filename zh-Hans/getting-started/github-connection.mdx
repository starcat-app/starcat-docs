## 用途

Starcat 用你的 GitHub 身份拉 Stars、读公开仓库元数据，并在你明确操作时 Unstar。它不会要你的 GitHub 密码。凭证进 macOS Keychain。

登录只建立会话。仓库列表要靠 [快速开始](/zh-Hans/getting-started/quickstart) 里那一下同步。

### GitHub 登录（推荐）

1. 点「使用 GitHub 登录」
2. 系统浏览器打开 GitHub 授权页
3. 授权后回到 Starcat

App Store 构建走 `ASWebAuthenticationSession`，不能用会拉起外部浏览器的 Device Flow，也不能用 PAT 当主登录（界面会藏掉，执行层也会拒绝）。

### Direct：Device Flow 与 PAT

Direct 额外提供 Device Flow（适合浏览器回调不顺的网络）和 PAT：

<Steps>
  <Step title="创建 Token">
    GitHub [Developer settings → Personal access tokens](https://github.com/settings/tokens)。
  </Step>
  <Step title="权限">
    - **Classic**：通常 `read:user`、`public_repo`
    - **Fine-grained**：至少能读用户资料和公开仓库 / Stars 元数据
  </Step>
  <Step title="粘贴">
    登录页展开「其他登录方式」，粘贴 Token。
  </Step>
</Steps>

同一活跃会话只用一种凭证。换方式前先登出。

## Starcat 要哪些权限

| 权限 | 用途 |
|------|------|
| `read:user` | 用户名、头像 |
| `public_repo` | Stars 列表和公开仓库信息 |

日常读 README 不会去扫你的私有业务仓。  
**取消 Star** 会调 GitHub Unstar API，只在你从详情或批量操作里明确触发时发生。

通知收件箱还需要通知相关授权；缺权限时 Activity 会提示重新授权，见 [活动](/zh-Hans/discover/activity/activity)。

## GitHub App（我的项目）

看 [我的项目](/zh-Hans/main-interface/my-projects) 里的私有 / Internal 仓库，要再做一次 **GitHub App** 安装（按组织 / 仓库范围）。公开项目列表仍可用主 OAuth / PAT。看不到私仓时，在 App 里把 GitHub App 装完再同步。

## 多账号

- 同一时间只有一个活跃 GitHub 账号
- 切换：侧栏头像 → 登出 → 换号登录
- 各账号本地数据隔离；切回原账号后标签笔记还在

工作号和个人号如果要彻底分开，用不同的 macOS 用户或接受登出切换，不要把两个 Token 叠在同一会话里。

## 注意

- 不要把 PAT 发到聊天或提交进 git
- 401 时按提示重新登录或换 Token
- 公司网络拦回调时，Direct 优先试 PAT 或 Device Flow
- Token 失效不会自动删你的本地标签；只是暂时拉不到远端
