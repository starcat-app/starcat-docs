## 用途

把「未分类里这一语言的 30 个仓」一次打上标签，或把「正在使用」一次性入库，比逐个点详情快。先收窄范围再多选，不要在 All Stars 里裸勾几百个。

## 怎么做

1. 侧栏选分类，再用 [筛选](/zh-Hans/search/filters) 或 ⌘F 收窄
2. 工具栏 **多选**，勾仓库
3. 底部栏选动作并确认
4. 结束后通常退出多选并 Toast；Esc 取消

## Manage 里有哪些动作

| 动作 | 行为 | 注意 |
|------|------|------|
| 标签 | 追加，不删旧标签 | 免费最多 20 个标签 |
| 加入 / 移出知识库 | 改入库 | [入库](/zh-Hans/knowledge-base/adding-repos) |
| Unstar | 调 GitHub API | 不能在 App 里一键撤销；多仓会二次确认 |
| 移到 Stars List | 若已同步 List | [GitHub Lists](/zh-Hans/manage-stars/github-lists) |

探索里更常见 Star / Unstar、入库。见 [探索概览](/zh-Hans/discover/explore/overview)。

## 注意

- 批量 Unstar 是真的对 GitHub 取消收藏。
- 免费标签满了，批量打标会失败或被门控，先删不用的标签或升级 Pro。
