## 用来做什么

GitHub 自己的 [Stars Lists](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars) 是账号上的分组。Starcat 把 List **同步到侧栏**，方便在本机点开看，不必为了分组去开网页。

它不是 Starcat 标签的云端版。List 存在 GitHub；标签存在本机。

## 在 Starcat 里能做什么

| 能力 | 说明 |
|------|------|
| 同步查看 | GitHub 上建或改的 List 会出现在侧栏 |
| 打开列表 | 点 List 名称看里面的仓 |
| 批量移动 | 多选时可能有「移到 List」 |

结构以 GitHub 为准。不要在 Starcat 里发明一套「假 List」。

## 和标签怎么分工

| | Stars List | Starcat 标签 |
|--|------------|--------------|
| 存哪 | GitHub | 本机 |
| 跨设备 | 跟 GitHub 账号走 | 本机（云同步[尚未上线](/zh-Hans/data-privacy/backup)） |
| 形态 | 分组 | 颜色、图标、精细分类 |
| 别人能不能看见 | 看 List 公开 / 私有 | 只有这台 Mac |

需要和网页一致的分组用 List；个人精细分类用 [标签](/zh-Hans/manage-stars/tags)。
