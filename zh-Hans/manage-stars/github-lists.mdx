## 你要解决的事

你已经在 GitHub 网页上分好了组，换到 Starcat 之后不想再把同一批仓库手工分一次。

侧栏里的 GitHub Stars Lists 就是那些分组同步过来的结果。它跟本机 [标签](/zh-Hans/manage-stars/tags) 不是同一套：List 在 GitHub 上，标签只在这台 Mac。

## 在 Starcat 里能做什么

| 能力 | 说明 |
|------|------|
| 同步查看 | GitHub 上建或改的 List 会出现在侧栏 |
| 打开列表 | 点 List 名称看里面的仓 |
| 批量移动 | 多选时可能有「移到 List」 |

结构以 GitHub 为准。

## 和标签怎么分工

| | Stars List | Starcat 标签 |
|--|------------|--------------|
| 存哪 | GitHub | 本机 |
| 跨设备 | 跟 GitHub 账号走 | 本机（云同步[尚未上线](/zh-Hans/data-privacy/backup)） |
| 形态 | 分组 | 颜色、图标、精细分类 |
| 别人能不能看见 | 看 List 公开 / 私有 | 只有这台 Mac |

需要和网页一致的分组用 List；个人精细分类用 [标签](/zh-Hans/manage-stars/tags)。
