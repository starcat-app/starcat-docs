## 标签是什么

标签是 Starcat 里最核心的本地分类方式：颜色、图标、名称都由你定义，**只存在本机**（跨设备云同步尚未上线，见 [备份](/zh-Hans/data-privacy/backup)）。

<Note>
  免费版最多创建 **20** 个标签；Pro 不限数量。见 [方案对比](/zh-Hans/subscribe/plan-comparison)。
</Note>

## 创建标签

<Steps>
  <Step title="打开管理入口">
    侧栏 Tags 分组旁点「+」，或进入标签管理面板。
  </Step>
  <Step title="新建">
    设置：
    - **名称**
    - **颜色**（预设色板）
    - **图标**（SF Symbol 集合）
  </Step>
  <Step title="保存">
    标签出现在侧栏，可立即用于打标。
  </Step>
</Steps>

达到免费上限时，创建会被权益门控拦截，并提示升级 Pro。

## 编辑与删除

| 操作 | 典型路径 |
|------|----------|
| 重命名 | 右键标签 → 重命名 |
| 改颜色 / 图标 | 右键 → 编辑 |
| 删除 | 右键 → 删除 |

删除标签**不会**删除仓库，只移除关联。

## 给仓库打标签

### 单个

1. 打开 [仓库详情](/zh-Hans/main-interface/repo-detail)  
2. 点击标签区域  
3. 搜索并选择标签（可多选，视控件而定）  
4. 即时生效  

### 批量

1. 列表进入[多选](/zh-Hans/manage-stars/batch-operations)  
2. 勾选仓库 → 底部栏「标签」  
3. 选择标签并应用  

批量打标一般为**追加**，不会清掉已有标签。

## 按标签浏览与筛选

- 侧栏点某个标签 → 列表只显示带该标签的仓库  
- 工具栏筛选也可按标签收窄 → [筛选](/zh-Hans/search/filters)  

## AI 标签推荐（Pro）

详情 AI 能力可推荐 3–8 个标签；**确认后才写入**。见 [AI 标签推荐](/zh-Hans/ai-features/tag-recommendation)、[Auto Tidy](/zh-Hans/ai-features/auto-tidy)。

## 实践建议

| 建议 | 原因 |
|------|------|
| 控制在数十个以内 | 过多标签会降低筛选效率 |
| 用一致命名 | 如 `frontend/react`、`ops/k8s` |
| 与 Stars List 分工 | List 偏 GitHub 侧分组；标签偏个人精细分类 → [GitHub Lists](/zh-Hans/manage-stars/github-lists) |
