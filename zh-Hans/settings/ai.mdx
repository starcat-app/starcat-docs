## 用来做什么

**设置 → AI** 是 AI 的总闸。逐步操作见 [AI 配置](/zh-Hans/ai-features/configuration)。Chat 配好但 Embedding 空着，语义和 RAG 仍会挂。

## 区块

| 区块 | 做什么 |
|------|--------|
| Provider 列表 | 增删改 BYOK，Key 进 Keychain |
| 已发现模型 | 刷新列表、调参数 |
| 默认任务映射 | 摘要 / 标签 / 对话 / Embedding / 翻译 |
| Auto Tidy | [自动整理](/zh-Hans/ai-features/auto-tidy) |
| AI 索引 | 语义向量；绿 / 橙 / 红结果 → [语义搜索](/zh-Hans/search/semantic-search) |
| RAG 相关 | 检索 / Rerank、可选 Meilisearch / Qdrant |
| 输出语言 | 跟随界面或单独指定 |
| AI 用量 | 本地请求数、Token、延迟、失败；不保存 Prompt 正文 |

打开 **AI 索引** 可看上次预拉时间和计数；可开始、暂停、恢复。取消 embedding 不会被当成网络不可用。外部 Meilisearch / Qdrant 的「测试并保存」：成功绿勾、需重建橙、失败红叉。它们不是 [设置 → 服务](/zh-Hans/settings/services) 里的 Go 后端。

使用前：Pro 是否激活、Chat 测试是否通过、Embedding 是否已配、再到详情 ⇧⌘A 真调一次。

## 注意

用量统计不保存 Prompt。换 Embedding 后按界面重建索引。
