## 入口

**设置 → 集成**

## Agent Runtime

Starcat Direct 可在这里检测并配置 Codex App Server 与 DeepSeek Harness。进入 Agent
工作台选择 Runtime 前，请先按[外部 Runtime 配置指南](/zh-Hans/agent-workspace/runtime-setup)
完成安装和验证。

## Local API Key

供本机插件与本地 HTTP API 鉴权。请：

- 定期轮换（若界面提供）  
- 不要提交到公开 git  
- 仅在受信本机使用  

## 浏览器插件

| 项 | 说明 |
|----|------|
| 启用 | 打开插件本地服务 |
| 端口 / Token | 扩展请求需一致 |
| 前提 | **Starcat 必须在运行** |

请求形态：`http://127.0.0.1:{port}/plugin/v1/...`，`Authorization: Bearer <token>`。

详见 [Chrome](/zh-Hans/browser-plugin/chrome)、[功能](/zh-Hans/browser-plugin/features)、[Safari](/zh-Hans/browser-plugin/safari)。

## External Search

配置网页搜索与 AI 联网上下文 Provider。步骤见 [外部搜索](/zh-Hans/search/external-search)。

导航里的 [外部搜索设置](/zh-Hans/settings/external-search) 页指向此处。

## 桌面启动器

Alfred、uTools、Raycast 配套项目在独立 GitHub 仓库。安装见 [桌面启动器](/zh-Hans/integrations/desktop-launchers)。

## Direct：CodebaseMemory 与 CodeFlow

**CodeFlow** 是公开仓库的 3D 代码图谱（Pro），从列表 / 详情工具栏打开。私仓没有这个入口。

Direct 版不再内置大体积可执行文件。设置页可自动检测当前官方安装，也可手动选择可执行文件或输出目录。找不到兼容版本时，按页面提示安装或重新选择路径。图谱启动复用账户级共享服务，避免「已安装仍提示未找到」或端口超时。

**CodebaseMemory** 同样走本机官方安装检测。App Store 版受 Sandbox 限制，不能启动用户安装的这类可执行文件。
