## 用途

在 **设置 → 扩展与连接 → MCP** 中，你可以启用 [CLI](/zh-Hans/cli/installation) 和 MCP 客户端对 Starcat 的访问。服务需要 [Pro](/zh-Hans/subscribe/plan-comparison)。读取默认开放。修改笔记、执行决策等操作需要打开 **允许写入**。支持预览的 CLI 命令用 `--apply` 执行。

## 怎么用

1. 打开 **启用服务**
2. 确认端口（常见 5555，避免冲突）
3. 客户端需要执行写操作时，打开 **允许写入**
4. 本机使用终端配对命令。若要连接另一台设备，打开 **允许其他设备连接**，复制 **从其他设备配对** 的命令，在那台设备上执行。

```bash
starcat pair "starcat-pair://connect?..."
starcat doctor
```

URI 约 5 分钟有效，只能使用一次。请在 App 内确认设备。CLI 将设备 Token 存入操作系统的凭据存储。见 [CLI 使用](/zh-Hans/cli/usage)。

## 本机与局域网地址

在采用纯 HTTP 监听的 Starcat 版本中，无论 **允许其他设备连接** 是否开启，本机 MCP 地址都是 `http://127.0.0.1:5555/mcp`。开启后，同一端口也可通过网络地址访问。请使用 MCP 设置页显示的地址。其他设备可以使用能解析的 `.local` 主机名，直接发 HTTP 请求时也可以使用 Mac 当前的局域网 IPv4 地址。

跨设备配对需要纯 HTTP 的 App 版本和 CLI v3。升级后运行 `starcat doctor`。如果原主机和端口能通过 HTTP 验证已有设备凭据，CLI 会自动更新地址。主机或端口变更后，请重新复制配对命令。升级后重启正在运行的 `starcat mcp` 进程。

设置页可复制给 Agent 的完整配置提示词，并在安装前检查 CLI 版本，必要时先更新。已配对设备会显示配对日期，用来区分新旧机器。

Agent 可以查仓库、通知、Release、知识库和模型。写入标签、笔记、Star / Unstar 仍走确认和审计。见 [CLI 使用](/zh-Hans/cli/usage)。

## 注意

- 权限与审计由 App 执行。CLI 不打开 SQLite。
