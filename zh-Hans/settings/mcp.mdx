## 用途

设置 → MCP 让本机 [CLI](/zh-Hans/cli/installation) 通过 MCP 调 App 能力（打标、改状态等）。需要 [Pro](/zh-Hans/subscribe/plan-comparison)。写操作默认 dry-run，必须 `--apply` 才落库。

## 怎么用

1. 启用 MCP Service
2. 确认端口（常见 5555，避免冲突）
3. 按需打开：读私有笔记、本地写入、批量写入、替换式写入
4. 复制配对命令，在终端执行：

```bash
starcat pair "starcat-pair://connect?..."
starcat doctor
```

URI 约 5 分钟有效、单次兑换；必须在 App 内确认设备。长期凭据进钥匙串。完整说明：[CLI 使用](/zh-Hans/cli/usage)。

设置页可复制 Claude / Codex 等 MCP 配置片段，把 `starcat mcp` 注册为 MCP server。见 [Skill](/zh-Hans/cli/skill)。

## 注意

- 权限与审计由 App 执行。CLI 不打开 SQLite。
- 远程连接要求 TLS 与证书指纹（见 CLI 安全模型）。
