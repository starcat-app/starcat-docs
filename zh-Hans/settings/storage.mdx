## 入口

**设置 → 存储**

## 缓存类型（示例）

| 类型 | 说明 |
|------|------|
| README / 图片 | 详情渲染缓存，可重建 |
| AI 对话历史 | 单仓 AI 浮层历史 |
| RAG 会话历史 | 知识库问答历史 |
| 外部搜索缓存 | 网页搜索与 AI 上下文缓存 |
| AI 摘要缓存 | 生成过的摘要 |

可单行清除或全部清除。清 README 后，下次打开详情会重新下载。

## Finder 入口

行旁文件夹按钮可打开对应目录（沙盒允许时）。App Store 与 Direct 路径不同。

## 危险区

### 恢复出厂设置

删除本地用户数据与缓存等（以确认文案为准）。**不可逆**。

操作前请先 [手动备份](/zh-Hans/data-privacy/backup)。云同步与 JSON 导出尚未上线，不要假设能从云端拉回。

### 仅清数据保留设置

若提供「删除本地数据库但保留设置」，同样先备份。
