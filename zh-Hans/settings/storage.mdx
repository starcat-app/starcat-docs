## 用来做什么

**设置 → 存储** 看缓存占了多少、按行清掉可重建的东西。危险区会删用户数据。云同步和 JSON 导出都还没上，清之前先 [备份](/zh-Hans/data-privacy/backup)。

## 怎么用

| 类型 | 说明 |
|------|------|
| README / 图片 | 详情渲染，可重建 |
| AI 对话历史 | 单仓浮层 |
| RAG 会话历史 | 知识库问答 |
| 外部搜索缓存 | 网页搜索与 AI 上下文 |
| AI 摘要缓存 | 生成过的摘要 |
| Issue 评论与事件 | Activity 会话 |
| Issue 评论草稿 | 未提交的手写或 AI 回复 |

可单行或全部清除。清 README 后下次打开会重新下载。行旁文件夹按钮打开对应目录（沙盒允许时）。App Store 与 Direct 路径不同。

**恢复出厂**删除本地用户数据与缓存（以确认文案为准），**不可逆**。若有「删除本地数据库但保留设置」，同样先备份。

## 注意

清 RAG 会话不会取消入库。清摘要只是下次再花 token。
