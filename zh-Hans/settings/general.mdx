## 用途

语言、主题、字号、通知，以及 README 是否在 App 里打开。「匿名贡献公开 Star 数据」默认关闭。清缓存和恢复出厂在 [存储](/zh-Hans/settings/storage)。

## 怎么用

| 项 | 说明 |
|----|------|
| 界面语言 | 18 种语言（完整列表见选择器） |
| 主题 | 跟随系统 / 浅 / 深 |
| 字体倍率 | 小 / 标准 / 大 / 超大；影响列表、时间线、部分正文 |
| 列表密度 | Comfortable / Compact |
| 减少动画 | 无障碍 |

通知总开关、Release 通知等还要系统设置允许 Starcat。见 [Release 通知](/zh-Hans/release/notifications)。「活动」里「显示 Issue 事件」会在评论之间插入加标签、关闭、commit 引用。默认只显示评论。见 [Activity](/zh-Hans/discover/activity/activity)。

「应用内打开仓库文档」开启后，README 里指向本仓库的 Markdown 链接会在独立窗口打开。默认仍走浏览器，⌘-点击始终打开浏览器。见 [仓库详情](/zh-Hans/main-interface/repo-detail)。

「匿名贡献公开 Star 数据」默认关闭。见 [隐私](/zh-Hans/data-privacy/privacy)。

| 重置 | 效果 |
|------|------|
| 重看首次引导 | 再显示欢迎；重置 Getting Started 进度 |
| 重置列表偏好 | 清排序 / 筛选 / 密度 |
| 重置所有设置 | 设置回默认；通常不删标签笔记（以确认框为准） |

## 注意

重置所有设置会恢复默认，通常保留标签和笔记。恢复出厂在存储页，不可逆。
