## 入口

**设置 → 通用**

## 显示

| 项 | 说明 |
|----|------|
| 界面语言 | **18 种语言**，含英语、简体 / 繁体中文、日语、韩语及主要欧亚语种（完整列表见设置内选择器） |
| 主题 | 跟随系统 / 浅 / 深 |
| 字体倍率 | 小 / 标准 / 大 / 超大 |
| 列表密度 | Comfortable / Compact |
| 减少动画 | 无障碍 |

字体倍率会影响列表、时间线、部分正文可读性。

## 通知与活动

启用通知总开关、Release 通知等。还需系统设置允许 Starcat。见 [Release 通知](/zh-Hans/release/notifications)。

「活动」区块可打开「显示 Issue 事件」：评论之间插入加标签、关闭、commit 引用和关联 PR。默认只显示评论。见 [活动](/zh-Hans/discover/activity/activity)。

## 详情行为

「应用内打开仓库文档」开启后，README 里指向本仓库的 Markdown 链接会在独立窗口打开。默认仍走浏览器，⌘-点击始终打开浏览器。见 [仓库详情](/zh-Hans/main-interface/repo-detail)。

## 隐私与推荐

「匿名贡献公开 Star 数据」默认关闭。见 [隐私](/zh-Hans/data-privacy/privacy)。

## 重置

| 操作 | 效果 |
|------|------|
| 重看首次引导 | 再显示欢迎；重置 Getting Started 进度 |
| 重置列表偏好 | 清排序/筛选/密度等 |
| 重置所有设置 | 设置回默认；**通常不删**标签笔记（以确认框为准） |

清数据请用 [存储管理](/zh-Hans/settings/storage)，不要和重置设置搞混。
