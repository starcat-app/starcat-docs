## 用来做什么

把全局搜索、列表搜索、AI、RAG 绑到你习惯的键上。旧文档若写「⌘F 打开全局搜索」已过时：默认 **⌘K** 是 Search Center，**⌘F** 是当前列表。

## 默认值（常见）

| 动作 | 默认 |
|------|------|
| Search Center | **⌘K** |
| 列表搜索框聚焦 | **⌘F** |
| 刷新当前内容 | **⌘R** |
| 仓库 AI 浮层 | **⇧⌘A** |
| RAG 工作台 | **⇧⌘K** |

以设置页为准。可用总开关与单项开关禁用，不必清空已录制键位。仅在你改过之后，输入框才出现「恢复默认」。

通常需要至少一个修饰键 + 字母 / 数字。与已占用组合冲突时会被拒绝。
