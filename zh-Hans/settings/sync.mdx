## 用来做什么

这里只描述 **GitHub Stars** 拉到本机。标签 / 笔记的 iCloud 同步**尚未上线**。换机请 [手动备份](/zh-Hans/data-privacy/backup)。

## 怎么用

列表工具栏同步：首次全量，之后增量 / ETag。Getting Started 要求你主动点一次，见 [快速开始](/zh-Hans/getting-started/quickstart)。

GitHub API 有 Rate Limit。触发后会退避并显示重置倒计时。见 [FAQ · 同步](/zh-Hans/faq/sync)。

系统允许时可用后台任务做定时检查（开关以 App 为准）。

<Warning>
  CloudKit / iCloud 用户数据同步尚未提供。JSON 导入导出亦为 [即将推出](/zh-Hans/share-export/data-export)。
</Warning>

## 注意

不要把 Stars 同步理解成「标签也上云」。Stars 可重建；标签不能。
