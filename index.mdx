## 五分钟功能导览

按日常路径走一遍，比从目录扫更高效：

<Steps>
  <Step title="装好并连上 GitHub">
    [安装](/getting-started/installation) → [连接 GitHub](/getting-started/github-connection) → 点同步拉取 Stars
  </Step>
  <Step title="三栏主界面">
    侧栏筛选 → 中间列表 → 右侧 README / 笔记。[主界面总览](/main-interface/overview)
  </Step>
  <Step title="整理与找回">
    [标签](/manage-stars/tags)、[笔记与状态](/manage-stars/notes-and-status)、[⌘K Search Center](/search/search-center)
  </Step>
  <Step title="进阶：AI 与知识库">
    [AI 总览](/ai-features/overview)（Pro）→ 心形入库 → [RAG 工作台](/knowledge-base/overview)
  </Step>
  <Step title="追踪与发现">
    [Release 订阅](/release/subscription) · [探索](/discover/explore/overview)
  </Step>
</Steps>
