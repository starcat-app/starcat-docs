## Release 时间线

时间线视图统一展示你所有订阅仓库的 Release 更新。

## 视图特性

- **按时间排序** — 最新发布在上
- **20 条分页** — 上拉加载更多
- **已读/未读** — 新 Release 高亮显示，阅读后标记已读
- **已读状态同步** — 阅读状态持久化

## Release 详情

点击 Release 展开详情：

### Markdown 渲染

Release Body 以 GitHub Flavored Markdown 渲染，保持与 GitHub 一致的排版。

### 资产列表

展示 Release 附带的下载资产：

- 默认显示前 3 个资产
- 超过 3 个可展开查看全部
- 每个资产显示文件名和大小

### 发布日期

底部信息行显示发布日期。

## 字号联动

时间线内容字号跟随界面字体倍率设置，确保阅读舒适。
