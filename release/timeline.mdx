## What it is for

One timeline for Releases from every subscribed repo, instead of polling each GitHub Releases page. Opens as a panel / sheet (follow the app). Entry: Manage sidebar **Release timeline**.

## How to use it

- Releases from all subscribed repos, newest first
- **Unread** highlight; mark one or all read
- Expand for GFM body and assets
- About **20 rows per page**, load more on scroll
- Body type size follows the UI font scale in [General](/settings/general)

**Check now** at the top runs one poll immediately. Use it right after an upstream cut. Default interval: [Background refresh](/release/background-refresh).

The top filter matches asset filenames (`dmg`, `arm64`, `linux`). See [Assets](/release/assets-download).

## Notes

- The timeline is **subscribed** repos only, not every Star’s Releases.
- Check now hits the GitHub API. Rapid clicks can hit rate limits.
