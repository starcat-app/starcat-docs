## Release 资产下载

订阅仓库发布新版本后，你可以浏览和下载 Release 资产。

## 智能资产过滤

自动按平台和文件类型分类资产：

- **按平台**：macOS、iOS、Linux、Windows
- **按文件类型**：dmg、pkg、zip、tar.gz、AppImage 等

## 下载操作

在 Release 详情页的资产列表中：

### 一键复制

点击资产旁的「复制」图标，复制下载链接到剪贴板。

### 直接下载

点击「下载」按钮：
1. 弹出保存对话框（NSSavePanel）
2. 选择保存位置
3. 开始下载，显示进度
4. 下载完成后通知

> 下载功能需要网络权限，大文件下载可能需要一些时间。
