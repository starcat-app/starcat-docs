## What it is for

Release attachments (`.dmg`, checksums, per-arch packages) live in the timeline or Release detail asset list. Starcat shows name and size. Download / open is handed to the system. Nothing is installed silently.

## How to use it

Expand assets: names and sizes; download / open; expand all when there are many.

The timeline filter matches filename fragments. You do not need the full name:

```text
dmg
arm64
linux
```

GitHub’s own concept: [GitHub Docs · Releases](https://docs.github.com/en/repositories/releasing-projects-on-github).

## Notes

- The filter applies to **filenames visible on this timeline**, not all of GitHub.
- You download upstream artifacts. Starcat does not verify signatures; check checksums yourself.
