## Asset list

In the [timeline](/release/timeline) or Release detail, expand the assets section:

- File name and size  
- Download / open (handled by the system)  
- Expand to see all assets when the list is long  

## Filter tips

Use the timeline top filter box to match file names—for macOS installers only:

```text
dmg
```

Or CPU architecture:

```text
arm64
```

No need to remember full file names.
