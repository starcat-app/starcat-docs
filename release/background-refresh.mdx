## 后台刷新

Starcat 在后台自动检查订阅仓库的新 Release 版本。

## 刷新机制

### 后台调度器

使用 macOS 的 NSBackgroundActivityScheduler 实现节能的后台刷新：

- 系统自动选择最佳时机执行
- 遵守 macOS 的电源管理策略
- 不影响前台应用的性能

### 刷新频率

- 默认间隔：每小时检查一次
- 系统可根据电池状态调整频率
- 手动刷新可随时触发

## 刷新范围

后台刷新只扫描以下仓库：

- 已 Star 的仓库
- 已加入知识库的仓库（即使未 Star）

> 仅仅订阅但既未 Star 也未入库的仓库不参与后台轮询。

## 轮询优化

- **ETag 条件请求**：减少 API 调用
- **Rate Limit 感知**：触发限制时自动退避
- **增量检测**：只拉取变化的页

## 手动刷新

工具栏的同步按钮也支持手动触发 Release 检查。
