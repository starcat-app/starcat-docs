## Where notifications come from

When a **subscribed** repo gets a new Release and polling detects it, you may get:

1. **macOS system notification** (banner / Notification Center)  
2. **In-app unread** (timeline badge, Activity, etc.)  

## Checklist before they show

| Check | Where |
|-------|-------|
| Subscribed to the repo | [Subscriptions](/release/subscription) |
| Within free **5**-repo limit (or on Pro) | [Plan comparison](/subscribe/plan-comparison) |
| System notification permission allowed | System dialog on first subscribe; change in System Settings |
| In-app Release notification toggle | **Settings → General → Notifications** |
| Background polling healthy | [Background refresh](/release/background-refresh) |

## Notification content

Usually includes repo name, version (tag), and Release title. Tap to open the Release / timeline.

## When you want fewer alerts

- Turn off system notifications, or the in-app Release notification toggle  
- Or unsubscribe low-priority repos to save free slots
