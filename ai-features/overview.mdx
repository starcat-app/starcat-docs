## What it is for

Starcat AI helps you **read, classify, and ask**—it does not silently rewrite your data. Tags and notes land only after you confirm. Use it when you have starred too many repos to read every README from scratch.

## Requirements

1. Activate [Pro](/subscribe/purchase) → [Plans](/subscribe/plan-comparison)
2. Configure a provider in **Settings → AI** ([BYOK](/subscribe/byok), [setup](/ai-features/configuration))
3. Map defaults: Chat (summary / chat / tags) and **Embedding** (semantic / RAG)

A missing Embedding mapping is the usual reason Pro still cannot do semantic search or RAG.

## Conservative policy

| Scene | Rule |
|-------|------|
| Tag suggestions | Written only after confirm |
| AI notes | Saved only after you accept the draft |
| Agent | Data changes need explicit authorization |
| Auto Tidy | Runs only the actions and triggers you enabled |

## Suggested order

1. [Configure AI](/ai-features/configuration) and test the connection
2. Detail → ⇧⌘A → one summary or one question
3. For semantic search: map Embedding → build the index → list semantic mode
4. Cross-repo Q&A: ingest a curated set → [RAG workspace](/knowledge-base/rag-workspace)
5. Turn on [Auto Tidy](/ai-features/auto-tidy) only after output looks stable
