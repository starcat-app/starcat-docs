## Purpose

The overlay answers questions about the selected repository’s README. Comparing many ingested repos belongs in the [RAG workspace](/knowledge-base/rag-workspace).

## How to open it

| Method | Detail |
|--------|--------|
| Shortcut | Default **⇧⌘A** ([editable](/settings/shortcuts)) |
| Detail overlay | Open the AI panel with a repo selected |
| Detached window | Split out of the overlay to read README side by side |

Requires [Pro](/subscribe/plan-comparison) and a Chat model → [AI configuration](/ai-features/configuration).

Typical overlay: summary actions, a Chat tab, and sometimes tag suggestions. Tab copy follows the app.

## Good questions

- “Summarize in three bullets what this library solves”
- “What are the quick-start steps according to the README?”
- “What are obvious limits or non-goals?”

The UI stays usable during long thinking; you can expand the full text afterward. Failures toast at the bottom-right.

If AI live web context is on, answers may cite web sources. Configure that in **Settings → Integrations**. See [External search](/search/external-search).

## Notes

- The model sees this repo (plus live web if you enabled it). It does not scan every Star.
- Still verify licenses, security advisories, and the latest Release yourself.
