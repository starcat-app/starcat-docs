## AI 助手对话 (Pro)

在仓库详情页打开 AI 助手浮层，你可以与当前仓库进行对话式交互。

## 打开方式

- **详情页入口**：仓库详情面板右上角的 AI 按钮
- **浮层窗口**：玻璃态浮层，支持两档尺寸切换
- **独立窗口**：可选择在独立窗口中打开

## 对话能力

### 代码理解

询问关于仓库代码的问题：

- "这个项目的核心架构是什么？"
- "如何开始贡献代码？"
- "主要的 API 入口在哪里？"

### 上下文来源

AI 对话可以从多个来源获取上下文：

- README 内容
- 仓库元数据
- 外部搜索（网络资料）
- 代码上下文（Pro，基于 RepoContextPacker）

### 流式 Think

对话过程中展示 AI 的推理过程（如果有的话），完成后自动折叠。

## 对话历史

- 按仓库维度管理对话历史
- 历史持久化到本地 SQLite
- 支持多 Session，可切换历史对话
- 存储设置可选择 JSON 或 SQLite 后端

## 分享

对话摘要可生成公开分享链接（通过 Sharing API），分享到社交平台或发送给朋友。
