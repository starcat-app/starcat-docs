## How to open

| Method | Notes |
|--------|-------|
| Shortcut | Default **⇧⌘A** ([customizable](/settings/shortcuts)) |
| Detail panel | Open the AI panel after selecting a repository |
| Detached window | Detach from the panel to read alongside README |

Requires [Pro](/subscribe/plan-comparison) + a configured Chat model → [AI configuration](/ai-features/configuration).

## Typical panel layout

- **Summary** actions → [AI summary](/ai-features/summary)  
- **Chat** tab: ask about the **current repository**  
- May include tag recommendation entry points → [Tag recommendations](/ai-features/tag-recommendation)  

Exact tab labels follow the app UI.

## Good questions to ask

- “Summarize in three bullets what problem this repo solves”  
- “What are the quick-start steps (based on README)?”  
- “What are obvious limits or non-goals?”  

For comparisons across multiple ingested repos, use the [RAG workspace](/knowledge-base/rag-workspace) instead of stretching the single-repo panel.

Long thinking stays usable; expand the full text when it finishes. Failures show a toast in the lower-right corner.

## External context

If AI external search context is enabled, answers may include web sources. Configure under **Settings → Integrations**. See [External search](/search/external-search).
