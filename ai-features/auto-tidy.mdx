## Purpose

**Settings → AI → Auto Tidy** runs the actions you checked after sync or on a schedule, so you do not have to open ⇧⌘A on every new Star. Tag writes still wait for confirm.

## How to configure it

| Item | Meaning |
|------|---------|
| Master switch | Stops all automatic tidy immediately |
| Triggers | Delay after launch, after sync, schedule, and similar |
| Actions | Summary, tag suggestions, and whatever the UI lists |
| Run now | One manual pass to test the setup |

Suggested order: confirm overlay output on one repo → enable only the actions you need → a narrow trigger (for example after sync) for a day → then consider a schedule.

## Notes

- A large library plus a schedule raises the provider bill
- Tag writes still need [confirm](/ai-features/tag-recommendation) and the free 20-tag cap
- Requires Pro and a working provider
- Turning the master switch off should stop further batches; an in-flight pass may still finish
