## What it is

Background tidy under **Settings → AI → Auto Tidy**: at times you allow, run summary, tag recommendations, and other actions on repositories.

## Typical settings

| Item | Notes |
|------|-------|
| Master toggle | Stop all auto-tidy immediately |
| Triggers | Delay after launch, after sync, scheduled, etc. |
| Actions | Summary, tag recommendations, etc. (per UI checkboxes) |
| Run now | Manual one-off run to test configuration |

## Suggested rollout

1. Confirm model output quality in the single-repo panel first  
2. Enable only actions you actually want  
3. Start with a narrow trigger (e.g. after sync only) and observe for a day  
4. Then consider scheduled runs  

## Risks and limits

- Large libraries + schedules → higher Provider bills  
- Tag writes still follow [confirm policy](/ai-features/tag-recommendation) and the free **20**-tag cap  
- Requires Pro and a working Provider
