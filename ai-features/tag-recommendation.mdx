## Purpose

Suggest tags from the README and related context (often 3-8, sometimes with confidence) so you can map them onto existing names.

Nothing is written until you confirm. See [AI overview](/ai-features/overview).

## How to use it

- Tag suggestions in the detail AI overlay
- [Auto Tidy](/ai-features/auto-tidy) batch suggestions (still gated by confirm / which actions you enabled)

Free accounts cap at 20 tags. If you are full: delete unused tags, or upgrade [Pro](/subscribe/plan-comparison). See [Tags](/manage-stars/tags).

## Notes

- Prefer mapping onto tags you already use.
- Review suggestions and drop extras. Auto Tidy batch can create many one-off tags.
- Hitting the cap blocks writes even if the model suggested something.
