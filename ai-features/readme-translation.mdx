## README 翻译 (Pro)

一键将仓库的 README 翻译为你选择的语言。

## 功能特性

- **保留 HTML 结构** — 翻译后的内容保持原 README 的排版
- **保留代码块** — 代码块不被翻译
- **保留链接** — 内部链接和外部链接完整保留
- **缓存机制** — 翻译结果按 `(repo_id, target_language)` 缓存

## 使用方式

在仓库详情面板中：
1. 点击「翻译」按钮
2. 选择目标语言（默认跟随系统语言）
3. 等待翻译完成

## 支持的语言

翻译输出语言默认跟随你的 Display Language 设置。你也可以手动选择其他语言。

## 翻译缓存

- 翻译结果本地缓存
- 源 README 变更后提示用户重新翻译
- 缓存不占用额外空间

## 翻译质量

翻译质量取决于 AI Provider 的能力，建议使用 Claude 或 GPT-4 系列模型。
