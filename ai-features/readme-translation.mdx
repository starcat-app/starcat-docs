## What it is for

When you do not want to dump a long English README into a browser translator, translate in detail: segment-by-segment or full-text replace. Good for reading. Code blocks and tables may be less tidy than the original.

## How to use it

The **Translate** control in the local-repo README toolbar.

| Scene | Usually available |
|-------|-------------------|
| Manage / Explore local detail | Yes |
| Some Activity / remote previews | Maybe not |

| Mode | Behavior |
|------|----------|
| **Segment** (default) | Side-by-side / bilingual by paragraph |
| **Full text** | Replaces visible README text, keeping structure where possible |

Wait for README load → Translate → pick language and mode → switch original / translation. Requires Pro and a translation model in [AI configuration](/ai-features/configuration). Target language can follow the UI. Paragraphs already in the target language are skipped. Failures toast at the bottom-right.

Translation is faster than early versions: smaller first request, incremental display, up to 4-way concurrency, per-segment cache, and resume for unfinished paragraphs.

## Notes

- Very long READMEs cost more time and tokens
- Code blocks / tables may layout worse than the original
- Mermaid and complex diagrams may stay closer to the original when translation is poor
- This is a reading aid, not ship-quality localization
