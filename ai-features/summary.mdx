## AI 摘要 (Pro)

AI 摘要是 Starcat 的核心 AI 功能之一，自动为仓库生成结构化的中文摘要。

## 摘要内容

AI 摘要通常包含：

- **项目简介** — 一句话说明项目是什么
- **核心功能** — 主要功能点
- **技术栈** — 使用的技术和语言
- **适用场景** — 什么情况下应该使用
- **学习建议** — 如何开始学习
- **注意事项** — 已知限制或问题

## 生成方式

### 手动生成

在仓库详情面板中，点击「生成摘要」按钮。

### 后台自动生成

在 AI 设置中开启「自动后台整理」后，系统会在以下时机自动生成摘要：

- 首次同步完成后
- 每日定时
- Star 新仓库后

## 摘要缓存

- 摘要生成后缓存到本地
- 通过 `source_hash` 判断 README 是否变更
- README 更新后，旧的摘要标记为过期，可重新生成

## 摘要分享

生成的摘要可以公开分享：

- 生成分享链接
- 分享到社交平台
- 嵌入博客或文档
