## Entry point

The **Generate with AI** control in the header of the detail **Private notes** area.

Requires Pro + a Chat model. For the notes area itself, see [Notes & status](/manage-stars/notes-and-status).

## Flow

<Steps>
  <Step title="Generate or refine">Create a learning note from the current README, or improve an existing draft. Progress is shown while generating.</Step>
  <Step title="Edit and preview">Edit Markdown with preview; you can copy the draft. Unconfirmed text does not overwrite existing notes.</Step>
  <Step title="Confirm save">Writes to private notes and shows save status.</Step>
</Steps>

## Storage and privacy

- Notes stay on device only; not uploaded to GitHub  
- Generation sends necessary context to your configured AI Provider (BYOK)  
- See [Privacy](/data-privacy/privacy), [BYOK](/subscribe/byok)
