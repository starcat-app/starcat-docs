## Purpose

Generate a private study-note draft from the README, for example why you starred the repo and how you plan to use it. Existing body text is not overwritten until you confirm. Notes stay on this Mac; GitHub collaborators never see them.

## How to use it

Entry: **Generate with AI** at the top of **Private notes** in detail. Requires Pro and a Chat model. The notes pane itself: [Notes and status](/manage-stars/notes-and-status).

1. Generate or refine: from the README, or improve an existing draft; a progress indicator runs
2. Edit Markdown and preview; you can copy the draft. Unconfirmed text does not replace the body
3. Confirm save into private notes and watch the save status

## Notes

- Stored on this Mac only; never uploaded to GitHub.
- Generation sends the needed context to your configured AI provider (BYOK). See [Privacy](/data-privacy/privacy) and [BYOK](/subscribe/byok).
- Unconfirmed drafts are not list-searchable.
