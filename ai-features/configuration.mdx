## What it is for

Without a working model, Pro is a switch with nothing behind it. This page gets **Settings → AI** to the point where summaries run, semantic search works, and RAG can answer. Chat and Embedding are separate mappings.

## How to set it up

1. **Add a provider**: OpenAI-compatible, DeepSeek, OpenRouter, Gemini, Ollama, LM Studio, and others (follow the list). Fill the API key and a Base URL for self-hosted endpoints.
2. **Discover models**: refresh discovered models; tweak temperature inline if needed.
3. **Default task mapping** (names follow the UI): summary, tags, chat; **Embedding** (semantic / RAG); translation.
4. **Test**: test the connection, then run a real ⇧⌘A call from detail.

Keys go in the macOS Keychain. More: [BYOK](/subscribe/byok).

## Embedding matters

With no usable Embedding:

- [Semantic search](/search/semantic-search) is unavailable
- [RAG index](/knowledge-base/index-management) cannot build vectors

Chat configured and Embedding empty is the usual “I have Pro but no semantic / RAG” case.

## RAG prompts

In [RAG workspace](/knowledge-base/rag-workspace) settings you can edit Q&A, planning, compression, and title templates:

- Compare and **copy** the read-only defaults
- Custom templates list supported placeholders; unlisted ones are not injected silently
- Starcat **does not** rewrite saved custom prompts

If summary / tags / translation expose custom prompts, try them on one repo before [Auto Tidy](/ai-features/auto-tidy).

Output language follows the UI by default, or you can set it separately. See [AI settings](/settings/ai).

## Notes

- The App Store build cannot launch your local CLIs. Local inference (Ollama and similar) must already be running.
- Changing the Embedding model can misalign old vectors; rebuild when the UI says so.
