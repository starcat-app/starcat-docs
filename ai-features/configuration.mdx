## AI 配置

在 设置 → AI 中配置 AI 服务提供商。

## 添加 Provider

<Steps>
  <Step title="打开 AI 设置">
    前往 设置 → AI 标签。
  </Step>
  <Step title="添加 Provider">
    点击「+」按钮，选择 Provider 类型：

    | Provider | 说明 |
    |----------|------|
    | **OpenAI-compatible** | 兼容 OpenAI API 格式的服务 |
    | **OpenAI** | 官方 OpenAI API |
    | **DeepSeek** | 国产大模型 |
    | **Google Gemini** | Google 的 Gemini 模型 |
    | **OpenRouter** | 聚合多个模型的路由服务 |
    | **Ollama** | 本地运行的开源模型 |
  </Step>
  <Step title="填写配置">
    - **API Base URL** — API 端点地址
    - **API Key** — 你的 API 密钥
    - **Model** — 要使用的模型名称
  </Step>
  <Step title="测试连接">
    点击「测试」按钮验证配置是否正确。
  </Step>
</Steps>

## 安全说明

- API Key 通过 **AES-GCM 加密**后存储在 macOS Keychain 中
- Starcat 不会将你的 API Key 发送到第三方
- 删除 Provider 时需要二次确认

## 模型选择建议

| 场景 | 推荐模型 |
|------|----------|
| AI 摘要 | Claude Sonnet / GPT-4o-mini |
| AI 对话 | Claude Sonnet / GPT-4o |
| 标签推荐 | Claude Haiku / GPT-4o-mini |
| 语义搜索 | text-embedding-3-small |

> 使用更轻量的模型可以节省 API 费用。BYOK 用户按自己的配额自行平衡。

## BYOK 模式说明

BYOK（Bring Your Own Key）用户：

- 用自己的 API Key，AI 请求直接到你配置的 Provider
- 不经过 Starcat 服务器
- API 费用由你的 Provider 账户承担
