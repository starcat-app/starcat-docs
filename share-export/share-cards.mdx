## Purpose

Sidebar user area Share opens the card editor: a personal stats image (dashboard / terminal styles, follow the app). The output is a PNG, not an HTML/MD repo list and not a deep link to one repository.

## How to use them

1. Pick layout and colors
2. Preview stats and layout
3. Save PNG, copy, or share to X (follow the buttons)

To point another Mac that already has Starcat at one repo, use [Share links](/share-export/share-links). For a list snapshot, use [Export files](/share-export/export-files).

| | Share card | File export |
|--|------------|-------------|
| Output | Image | HTML / Markdown |
| Entry | Share sheet | [Export files](/share-export/export-files) |

## Notes

Nothing leaves this Mac until you export. See [Privacy](/data-privacy/privacy). Numbers come from local stats; they will not match after a move without backup.
