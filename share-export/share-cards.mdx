## 分享卡片

Starcat 提供多种风格的可分享卡片，展示你的 GitHub Stars 统计数据。

## 生成分享卡

1. 点击侧边栏用户卡片旁的「分享」按钮
2. 进入分享卡编辑器
3. 选择卡片样式
4. 预览效果
5. 导出或分享

## 卡片样式

Starcat 内置多种视觉风格：

- **数据看板** — 统计信息一目了然
- **终端像素风** — 复古终端风格
- **冒险样式** — 游戏化展示
- **其他样式** — 持续更新中

## 分享方式

- **生成链接** — 通过 Sharing API 生成公开分享链接
- **导出图片** — 导出为 PNG 图片
- **复制到剪贴板** — 直接粘贴到社交平台

## 暗色适配

所有卡片样式均支持明暗主题，自动跟随系统设置。
