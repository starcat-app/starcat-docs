## What it is for

A readable snapshot for a coworker or a notes app. It does **not** replace the unshipped full-library JSON backup. Moving Macs still starts with a [manual folder backup](/data-privacy/backup).

## What is shipped

| Scope | Formats |
|-------|---------|
| Starred | HTML / Markdown |
| Knowledge base | HTML / Markdown |

Knowledge-base export can include local notes, tags, status, README, Health, and cached summaries as a read-only snapshot (follow the actual file).

1. Open Share / Export
2. Pick Starred or knowledge base
3. Pick HTML or Markdown
4. Choose a save location

Also: single-repo README → detail README toolbar → Export Markdown. RAG sessions → workspace `.md` → [Sessions](/knowledge-base/session-management).

Full JSON: [Data export](/share-export/data-export) (coming soon).

## Notes

HTML/MD is a snapshot. Importing it will not rebuild your tag system. Do not treat it as a full migration.
