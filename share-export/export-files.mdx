## 已支持

在分享相关界面中选择范围与格式：

| 范围 | 格式 |
|------|------|
| Starred | HTML / Markdown |
| 知识库 | HTML / Markdown |

知识库导出可包含本地笔记、标签、状态、README、Health、摘要缓存等只读快照（以实际文件为准）。

## 步骤（典型）

1. 打开分享 / 导出入口  
2. 选择 Starred 或知识库  
3. 选择 HTML 或 Markdown  
4. 选保存位置  

## 其他导出

| 来源 | 方式 |
|------|------|
| 单仓 README | 详情 README 工具栏 → 导出 Markdown |
| RAG 会话 | 工作台导出 `.md` → [会话管理](/knowledge-base/session-management) |

## 尚未支持

整库 JSON 备份/迁移见 [数据导出](/share-export/data-export)（即将推出）。换机请先 [手动备份目录](/data-privacy/backup)。
