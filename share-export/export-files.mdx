## Supported today

In the share / export UI, pick scope and format:

| Scope | Format |
|-------|--------|
| Starred | HTML / Markdown |
| Knowledge base | HTML / Markdown |

Knowledge-base export may include local notes, tags, status, README, Health, summary cache, and other read-only snapshots (as in the actual file).

## Typical steps

1. Open share / export  
2. Choose Starred or knowledge base  
3. Pick HTML or Markdown  
4. Choose save location  

## Other exports

| Source | How |
|--------|-----|
| Single-repo README | Detail README toolbar → Export Markdown |
| RAG session | Workspace export `.md` → [Session management](/knowledge-base/session-management) |

## Not supported yet

Full-library JSON backup / migration: [Data export](/share-export/data-export) (coming soon). For device moves, [back up the directory manually](/data-privacy/backup) first.
