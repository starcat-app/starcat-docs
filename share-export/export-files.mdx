## 文件导出

将你的 Stars 列表导出为单文件，方便分享或归档。

## 支持的格式

| 格式 | 说明 |
|------|------|
| **Markdown** | `.md` 文件，适合在 GitHub、博客等平台展示 |
| **HTML** | `.html` 文件，可在浏览器中直接打开 |

## 导出范围

- **Starred 列表** — 导出 GitHub Stars List 分组
- **知识库** — 导出知识库仓库列表

## 使用方式

1. 打开分享卡编辑器
2. 选择「导出 Markdown」或「导出 HTML」
3. 选择保存位置
4. 文件自动生成并保存

## 导出内容

导出的文件包含：
- 仓库名称和链接
- 描述
- 语言
- Star 数
- 标签（如果有）
