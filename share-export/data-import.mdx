## 数据导入

Starcat 支持从其他 Star 管理工具导入数据，方便你迁移到 Starcat。

## 支持的格式

| 来源 | 格式 | 说明 |
|------|------|------|
| **OhMyStar** | JSON | macOS Star 管理工具 |
| **Astral** | JSON | 另一款 Star 管理工具 |

> 导入功能目前仍在开发中，敬请期待。如急需使用，请联系支持。

## 导入流程（计划）

1. 在旧工具中导出 JSON 文件
2. 打开 Starcat 设置 → 数据管理
3. 选择「导入」
4. 选择 JSON 文件
5. Starcat 解析并导入标签、笔记等用户数据

## 迁移建议

如果你正在从其他工具迁移：

- **保留旧工具**直到确认数据完整
- 先体验 Starcat 的基本功能
- 通过 GitHub Stars 同步获取仓库数据（数据不会丢失）
- 手动重新创建最重要的一些标签
