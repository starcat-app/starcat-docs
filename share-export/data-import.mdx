## How to migrate today

1. Sign in with GitHub and sync Stars (the repo list is not lost)
2. Rebuild important tags / notes by hand, or keep old export files until JSON import ships
3. If this Mac already has Starcat data, [back up](/data-privacy/backup) before you move

## Move from the App Store build to Direct

The first time Direct opens, it can copy this Mac's App Store repositories, notes, and caches, or you can skip and start empty. Apple subscriptions are not copied. After you answer, or if this Mac already has data, Starcat does not ask for that same access again.

JSON import is still unavailable. The step above only copies an App Store install already on this Mac.
