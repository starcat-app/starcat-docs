## What you get

Starcat ships four WidgetKit widgets you can add from the macOS desktop / Notification Center widget gallery:

| Widget | Purpose |
|--------|---------|
| **Starcat Focus** | Frequently used / pinned / “using” repositories with deep links |
| **Rediscovery** | A daily rediscovery pick from your library |
| **Release Watch** | Unread or recent Release signals with deep links into Starcat |
| **Collection Trend** | Recent starring / collection growth at a glance |

Exact titles follow localized widget display names in the system gallery.

## Requirements

- Starcat installed (App Store or Direct) with the widget extension  
- Signed in at least once so the app can publish a widget snapshot  
- macOS widget gallery → search **Starcat** → add the size you want  

If a widget looks empty or stale: open Starcat once (to refresh the snapshot), confirm you are signed in, then wait for the next timeline refresh or re-add the widget.

## Deep links

Tapping a row usually opens Starcat at the matching repository, Release timeline, or related surface. Release deep links prefer App-controlled URLs rather than raw GitHub Release pages.
