## Purpose

Glance without opening Starcat: repos you actually use, a daily rediscovery from Stars, unread Releases, and recent collection growth. Taps return to the matching surface inside the app.

Four WidgetKit widgets (system names follow the UI language):

| Widget | Job |
|--------|-----|
| **Starcat Focus** | Frequent / pinned / "using" repos |
| **Rediscovery** | One daily pick from your Stars |
| **Release Watch** | Unread or recent Releases |
| **Collection Trend** | Recent Stars growth |

## How to add them

1. Install Starcat (App Store or Direct); the widget extension ships with it
2. Sign in at least once so the app can publish snapshots
3. Open the macOS widget gallery, search **Starcat**, pick a size

Blank or stale: open Starcat once, confirm you are signed in, wait for the next timeline refresh, or remove and add the widget again.

## Notes

- Taps use controlled `starcat://` links. Release items prefer the in-app timeline, not the raw GitHub Release page.
- Focus candidates include repos you [pin](/main-interface/repo-list) in the list.
- Widgets read this Mac’s snapshot, not another machine’s library.
