## Purpose

My Projects lists owned, organization-member, and outside-collaborator repos. Starring does not matter.

Keep work repos here. Open-source libraries you collect stay in Stars.

## How to use it

Sidebar **Manage → My Projects**.

|------------|--------|
| Browse by affiliation | Owned / organization / collaborator |
| Filter and search | Same Manage filters and ⌘F |
| Detail | Cached README, tags, notes, Health, AI |
| Star trend | When GitHub allows stargazer history |

## Authorization

| Source | Typical coverage |
|--------|------------------|
| Main sign-in (OAuth / PAT) | **Public** projects you can list |
| **GitHub App** (in-app install) | **Private** and **Internal** in the installation scope |

If private repos are missing: finish GitHub App authorization in the app, confirm the org / repo coverage, then sync. See [Connect GitHub](/getting-started/github-connection).

## Notes

- Private projects do not appear in public Discover / Trending surfaces.
- Some public-only signals (certain OpenSSF paths) may stay unavailable on private repos.
- Insights metrics that need elevated access use the GitHub App token. See [Insights](/main-interface/insights).
- Unstar still calls the GitHub API, same as in the Stars list.
