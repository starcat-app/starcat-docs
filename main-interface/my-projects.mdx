## What it is

**My Projects** lists repositories you **own, belong to via an organization, or collaborate on**—independent of whether you have Starred them.

Use it when you need day-to-day project access (including private / Internal repos) while still keeping Stars as a separate “saved for later” library.

## Entry

Sidebar → **Manage → My Projects** (label follows the app).

## What you can do

| Capability | Notes |
|------------|-------|
| Browse by affiliation | Owner / organization member / collaborator |
| Filters & search | Same list tooling as Manage Stars where available |
| Detail pane | README, tags, notes, Health, AI, and more for repos already cached locally |
| Star trends | Available when GitHub permissions allow stargazer history |

## Authorization

| Source | Typical coverage |
|--------|------------------|
| Main GitHub sign-in (OAuth / PAT) | Public projects you can list |
| **GitHub App** (in-app authorization) | Authorized **private** and **Internal** projects within the App’s installation scope |

Private projects never enter Discover / Trending-style public discovery surfaces.

If private projects are missing: open the in-app GitHub App authorization flow, confirm the installation covers the right orgs / repos, then sync again.
