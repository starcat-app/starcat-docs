## 结构

侧栏自上而下通常是：

1. **一级切换**：Manage / 探索 / Activity  
2. **当前一级下的子导航**（分组可折叠）  
3. **用户区**：头像、账号、Pro 状态、分享与登出  

分组标题行一般**整行可点**折叠/展开，chevron 只表示状态。

## Manage 常见子入口

| 入口 | 说明 | 延伸阅读 |
|------|------|----------|
| All Stars | 全部已同步 Stars | — |
| 未分类 / Untagged | 尚无标签的仓库 | [标签](/manage-stars/tags) |
| 知识库 / Library | 已入库仓库 | [知识库](/knowledge-base/overview) |
| Languages | 按语言浏览 | [筛选](/search/filters) |
| Tags | 按标签浏览；旁路「+」管理标签 | [标签](/manage-stars/tags) |
| Smart Collections | 系统 + 自定义规则集合 | [智能集合](/manage-stars/smart-collections) |
| GitHub Stars Lists | 同步自 GitHub 的 List | [GitHub Lists](/manage-stars/github-lists) |
| Release 时间线 | 订阅 Release 聚合视图 | [时间线](/release/timeline) |

具体文案与排序以当前版 App 为准。

## 探索

五个模式：发现、趋势、热门、新发布、周刊。见 [探索概览](/discover/explore/overview)。

## Activity

动态分类（全部、公告、Release、Star、关注等）。见 [Activity](/discover/activity/activity)。

- 查看当前 GitHub 用户
