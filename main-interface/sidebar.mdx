## 侧边栏概览

侧边栏是 Starcat 的主要导航入口，所有数据分类都在这里。

## 导航结构

### 用户卡片

顶部显示你的 GitHub 头像、用户名和统计信息：

- **Stars 总数** — 你收藏的仓库总量
- **标签数** — 已创建的标签数量
- **知识库** — 已加入知识库的仓库数量

点击头像弹出账户菜单：登出、切换账号。

<Note>分享按钮位于用户卡片左侧，可将你的 Stars 统计生成分享卡片。</Note>

### 数据分类

#### All Repos
展示所有已 Star 的仓库列表。

#### Tags
按标签分组浏览。每个标签旁显示该标签下的仓库数量。

#### Untagged
未添加任何标签的仓库，帮助你逐步整理。

#### Languages
按编程语言聚合仓库，显示每种语言的仓库数量。

#### Starred
基于 GitHub Stars List 的分组视图，同步你在 GitHub 上创建的分组。

#### 知识库
已加入本地知识库的仓库集合，支持 RAG 检索与问答。

### 探索入口

侧边栏底部提供探索发现入口：

- **Explore** — 发现/热门/新发布/趋势四个模块
- **Weekly** — 多来源技术周刊聚合
- **Activity** — Release 动态与订阅更新

## 侧边栏操作

- **折叠分组**：点击分组标题展开/折叠
- **右键菜单**：标签等条目支持右键操作（重命名、删除等）
