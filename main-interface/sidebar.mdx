## Structure

The sidebar is typically organized top to bottom as:

1. **Top-level switch**: Manage / Discover / Activity  
2. **Sub-navigation under the current top level** (groups can collapse)  
3. **User area**: avatar, account, Pro status, share, and sign out  

Group header rows are generally **clickable on the full row** to collapse or expand; the chevron only reflects state.

## Common Manage sub-entries

| Entry | Description | Further reading |
|-------|-------------|-----------------|
| All Stars | All synced Stars | — |
| Untagged | Repos without tags yet | [Tags](/manage-stars/tags) |
| Library / Knowledge base | Ingested repos | [Knowledge base](/knowledge-base/overview) |
| My Projects | Owned / org / collaborator repos (not only Stars) | [My Projects](/main-interface/my-projects) |
| My Insights | Library-wide organization and drill-downs | [Insights](/main-interface/insights) |
| Languages | Browse by language | [Filters](/search/filters) |
| Tags | Browse by tag; “+” shortcut to manage tags | [Tags](/manage-stars/tags) |
| Smart Collections | System + custom rule-based collections | [Smart collections](/manage-stars/smart-collections) |
| GitHub Stars Lists | Lists synced from GitHub | [GitHub Lists](/manage-stars/github-lists) |
| Release timeline | Aggregated view of subscribed Releases | [Timeline](/release/timeline) |

Exact labels and ordering follow the current app version.

## Discover

Explore modes: Discover, Awesome, Trending, Hot, New releases, and Weekly. See [Discover overview](/discover/explore/overview).

## Activity

Activity is primarily **Notifications** (GitHub Inbox), plus local feeds such as Announcements, Release, and Star. See [Activity](/discover/activity/activity).

## User area

- View the current GitHub user
- Open Pro / settings-related entries (or open Settings from the menu)
- [Share cards](/share-export/share-cards)
- Sign out and switch accounts (see [GitHub connection](/getting-started/github-connection))
