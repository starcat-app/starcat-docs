## Purpose

The sidebar picks which set of repositories or notifications the list shows. Switch the top-level area first, then a subcategory. That is faster than tightening filters on All Stars.

Top to bottom:

1. **Top-level switch**: Manage / Explore / Activity
2. **Sub-navigation** under the current area (groups collapse)
3. **User area**: avatar, Pro, share, sign out

Group headers are clickable on the full row; the chevron is not the only hit target.

## Manage

| Entry | When to use it | Docs |
|-------|----------------|------|
| All Stars | Every synced Star | - |
| Untagged | Daily inbox for repos still missing tags | [Tags](/manage-stars/tags) |
| Library | Ingested repos for RAG | [Knowledge base](/knowledge-base/overview) |
| My Projects | Repos you work on, starred or not | [My Projects](/main-interface/my-projects) |
| My Insights | Organization progress, drill into lists | [Insights](/main-interface/insights) |
| Languages | Browse by language | [Filters](/search/filters) |
| Tags | Browse by tag; "+" manages tags | [Tags](/manage-stars/tags) |
| Smart Collections | Rule-based sets, system + custom | [Smart collections](/manage-stars/smart-collections) |
| GitHub Stars Lists | Lists synced from GitHub | [GitHub Lists](/manage-stars/github-lists) |
| Release timeline | Aggregated subscribed releases | [Timeline](/release/timeline) |

Labels and order follow the current app.

## Explore and Activity

Explore: Discover, Awesome, Trending, Hot, New releases, Weekly. See [Explore overview](/discover/explore/overview).

Activity opens on **Notifications** (GitHub Inbox), plus announcements, Release, Star, and other local categories. See [Activity](/discover/activity/activity).

## User area

- Current GitHub user
- Pro / Settings (or the app menu)
- [Share cards](/share-export/share-cards)
- Sign out and switch accounts: [Connect GitHub](/getting-started/github-connection)

## Notes

- Untagged does not auto-tag; it only narrows the list.
- An empty Library means nothing is ingested yet, not that sync failed.
- Collapsing a group does not delete data.
