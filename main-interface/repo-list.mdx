## 列表在做什么

中栏展示**当前侧栏选中分类**下的仓库行（Manage）或榜单结果（探索）。

一行里通常能看到：

- 仓库全名与描述摘要  
- 语言、Star 数等  
- 标签胶囊（若有）  
- Health / OpenSSF 等徽章（若已有缓存）  

点击一行 → 右侧打开 [仓库详情](/main-interface/repo-detail)。

## Manage 工具栏

| 控件 | 作用 | 文档 |
|------|------|------|
| 统一筛选 | 状态 / 入库 / 语言 / Wiki / Health… | [筛选](/search/filters) |
| 多选 | 底部批量栏 | [批量操作](/manage-stars/batch-operations) |
| Stars 同步 | 与 GitHub 同步 | [同步设置](/settings/sync) |
| 列表搜索 | 关键词（常 **⌘F**）或语义 | [列表搜索](/search/global-search) |
| 集合齿轮 | 编辑 Smart Collection | [智能集合](/manage-stars/smart-collections) |

选中仓库后，trailing 区还可能出现外链、Clone、分享、AI 等。总览见 [工具栏](/main-interface/toolbar)。

## 探索列表差异

- 数据来自发现/趋势/周刊等 API，不是「仅你的 Stars」  
- 批量动作更偏 Star / 入库  
- 筛选维度通常更少  

见 [探索概览](/discover/explore/overview)。

## 排序与密度

- 排序字段与方向：工具栏或列表偏好  
- 行距：Comfortable / Compact → [通用设置](/settings/general)  
- 筛选条件常按模块记忆  

若列表「怎么都空」：检查筛选是否过严，或点重置筛选。
