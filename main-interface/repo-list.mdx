## Purpose

The middle column lists repositories for the current sidebar category: your repos in Manage, ranked results in Explore. Click a row to open detail.

A row typically shows: full name and description snippet, language and Stars, tag pills, Health / OpenSSF badges when cached, a pin badge in Manage, and whether an AI summary exists.

## Pinning (Manage only)

**Pin / Unpin** from the context menu or row action. Within the current category, most recently pinned sorts first. Pins also feed the [Focus widget](/main-interface/widgets). Explore boards do not use the same personal pin semantics.

## Toolbar

| Control | Job | Docs |
|---------|-----|------|
| Filters | Status / ingest / language / Wiki / Health… | [Filters](/search/filters) |
| Multi-select | Bottom batch bar | [Batch operations](/manage-stars/batch-operations) |

| List search | ⌘F keyword or semantic | [List search](/search/global-search) |
| Collection gear | Edit the current Smart Collection | [Smart collections](/manage-stars/smart-collections) |

With a repo selected, trailing actions may include external link, Clone, share, AI, CodeFlow. See [Toolbar](/main-interface/toolbar).

## Explore lists

- Data comes from discovery / trending / weekly services, not "only your Stars"
- Batch actions lean toward Star / ingest
- Fewer filter dimensions

See [Explore overview](/discover/explore/overview).

## Notes

- Empty list: reset filters before assuming sync is broken.
- Filter state often persists per module: Tag A and All Stars may restore different last-used conditions.
- Row density Comfortable / Compact lives in [General settings](/settings/general).
