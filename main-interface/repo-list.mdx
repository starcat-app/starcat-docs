## 仓库列表

中间区域展示当前分类下的仓库卡片，每张卡片包含仓库名称、描述、语言、Star 数等关键信息。

## 排序

工具栏的排序按钮支持多种排序方式：

| 排序方式 | 说明 |
|----------|------|
| 默认 | 按 Star 时间倒序（最新收藏在前） |
| Stars | 按 GitHub Star 数降序 |
| 更新日期 | 按仓库最近更新时间 |
| 创建日期 | 按仓库创建时间 |
| 名称 | 按仓库名称字母排序 |
| OpenSSF 评分 | 按安全评分降序（Pro） |

> 排序偏好按模块独立保存，下次打开自动恢复。

## 列表密度

支持两种显示密度：

- **Comfortable** — 宽松间距，适合浏览
- **Compact** — 紧凑间距，适合大量数据

在设置中切换，或通过菜单栏 `View → List Density` 快速切换。

## 多选模式

点击仓库卡片左侧的复选框进入多选模式：

1. 勾选需要操作的仓库
2. 底部出现浮动操作栏
3. 支持批量操作：打标签、加入知识库、Star/Unstar

## 筛选

工具栏提供丰富的筛选条件。详见 [筛选与过滤](/search/filters)。

## 面包屑导航

列表顶部显示当前导航路径，如 `Manage → JavaScript`，点击面包屑可快速返回上级。
