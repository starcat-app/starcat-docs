## What the list does

The center column shows repository rows for the **sidebar category you selected** (Manage) or ranked results (Discover).

Each row usually shows:

- Full repo name and description snippet  
- Language, Star count, and similar metadata  
- Tag pills (when present)  
- Health / OpenSSF badges (when cached)  
- **Pin badge** (top-left) when the repository is pinned in Manage  

Click a row → the right pane opens [Repository detail](/main-interface/repo-detail).

## Pinning (Manage)

In Manage lists you can **Pin / Unpin** a repository (context menu or row action). Pinned repos sort by **most recently pinned** within the current category. Pinning also helps [desktop Focus widgets](/main-interface/widgets) pick frequently used repos.

## Manage toolbar

| Control | Purpose | Docs |
|---------|---------|------|
| Unified filter | Status / ingest / language / Wiki / Health… | [Filters](/search/filters) |
| Multi-select | Bottom batch bar | [Batch operations](/manage-stars/batch-operations) |
| Stars sync | Sync with GitHub | [Sync settings](/settings/sync) |
| List search | Keywords (often **⌘F**) or semantic | [List search](/search/global-search) |
| Collection gear | Edit a Smart Collection | [Smart collections](/manage-stars/smart-collections) |

After selecting a repo, the trailing area may also show external links, Clone, Share, AI, and more. See [Toolbar](/main-interface/toolbar) for an overview.

## Discover list differences

- Data comes from Discover / Trending / Weekly APIs—not “only your Stars”  
- Batch actions lean toward Star / ingest  
- Fewer filter dimensions  

See [Discover overview](/discover/explore/overview).

## Sort and density

- Sort field and direction: toolbar or list preferences  
- Row spacing: Comfortable / Compact → [General settings](/settings/general)  
- Filter conditions are often remembered per module  

If the list stays empty: check whether filters are too strict, or reset filters.
