## The job

You open a repository to decide three things: whether it is the one you wanted, whether to keep a note, and whether to unstar it. Before unstar, you also want to know if the local note disappears with it.

The right pane is that decision. README, tags, notes, and subscriptions exist on both builds. So do file download and the alert for a Star added outside the app. The Issues workspace, repository Skills, and the full-window README image viewer are Direct 1.9.6. Those pages carry the green capsule.

## README

A WebView renders GitHub Flavored Markdown, including images and anchors. Mermaid renders locally and falls back to source on failure.

| Action | Detail |
|--------|--------|
| Open in browser | GitHub repository page |
| Clone | Copy HTTPS / SSH |
| Export Markdown | Current README |
| Translate | Pro. See [README translation](/ai-features/readme-translation) |
| Share link | Open this repo inside Starcat. See [Share links](/share-export/share-links) |

Videos in GitHub READMEs play with native controls. Playback is manual; it stops when you switch repos or close detail. Unsupported sources still open in the browser.

**Settings → General → Open repository docs in the app** opens Markdown links that point at this repository in a separate window. The default is still the browser; **⌘-click always uses the browser**.

## Files, issues, and skills

| Entry | What it does |
|-------|----------------|
| Files | Browse the tree, preview source, images, and Markdown, then download the selection, including Git LFS. Markdown switches between rendered and source, and the toolbar can translate |
| README images | Click an image for the full-window viewer. Step through and zoom. Closing returns to the previous reading position |
| Issues | [Issues workspace](/main-interface/issues): list, create, summarize |
| Skills | [Repository skills](/manage-stars/skills): preview, translate, install into Codex or Claude Code |
| License | The badge opens rights, obligations, and the license text. Filtering: [Filters](/search/filters) |
| Owner | The avatar opens the profile card. The owner or repository name opens GitHub in the browser |

A repository with a saved note shows a note icon and a status capsule in the list.

## Unstar

Unstarring from detail calls the GitHub API and cannot be undone in one tap inside Starcat. The confirm step lists notes, tags, AI content, and caches that will be deleted. A repository already in the knowledge base can be removed from it in the same step. Deletion cannot be undone. A repository GitHub has already removed can still be cleared locally. Batch: [Batch operations](/manage-stars/batch-operations).

## Notes

- README is cached; a file you just changed on GitHub may need a refresh.
- In-app docs only follow same-repo links. External URLs still use the browser.
