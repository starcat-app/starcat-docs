## 详情面板

点击左侧列表中的仓库，右侧展示仓库详细信息。

## 信息头部

顶部卡片展示仓库核心元数据：

- **仓库名称** — 格式 `owner/repo`
- **描述** — 仓库简介
- **语言** — 主要编程语言（带颜色标识）
- **Stars / Forks / Watchers** — GitHub 统计
- **Topics** — 仓库主题标签
- **License** — 开源协议
- **创建/更新时间**

## README 渲染

详情面板主体区域渲染仓库的 README.md 文件：

- **完整 GFM 支持** — GitHub Flavored Markdown 全面兼容
- **图片预览** — 点击图片放大查看，滚动自动关闭
- **代码高亮** — 语法高亮显示
- **阅读工具条** — 字号调整、回到顶部

### 阅读工具条

hover 时显示在 README 右上角的半透明工具条：

- 字号 +/- 按钮
- 重置字号
- 回到顶部

> 未操作时工具条保持 45% 透明度，避免干扰阅读。

## 快捷操作

信息头部提供以下快捷入口：

| 按钮 | 功能 |
|------|------|
| **复制 Clone URL** | 复制 HTTPS/SSH 克隆地址 |
| **GitHub 跳转** | Issues / Pulls / Releases / Homepage |
| **Star/Unstar** | 收藏/取消收藏 |
| **知识库** | 加入/移出知识库 |
| **AI 对话** | 打开 AI 助手浮层 |

## AI 摘要

Pro 用户可在详情面板查看该仓库的 AI 摘要。详见 [AI 摘要](/ai-features/summary)。

## 笔记与状态

详情面板底部提供：

- **私有笔记** — 自由编辑，自动保存（800ms 防抖）
- **阅读状态** — 未读 / 在读 / 在用 / 废弃
