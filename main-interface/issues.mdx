## The job

You want to finish the issues in this one repository, draft a reply, or file a new one, without jumping to the browser for every thread.

<DirectVersionBadge /> The Issues workspace is that repository's own list and conversation. The cross-repository inbox stays in [Activity](/discover/activity/activity), which App Store 1.9.1 already has.

## How to use it

<Steps>
  <Step title="Open Issues for this repository">
    Enter from repository details. Search, filter by state, and page. After a filter change, the detail follows the visible list.
  </Step>
  <Step title="Create one">
    Start from a template if you want. AI can draft the body. Paste images. Drafts are saved per repository and are still there when you come back.
  </Step>
  <Step title="Read and reply">
    The detail reuses the comment timeline, translation, and AI comments. See the conversation section on the Activity page.
  </Step>
  <Step title="Read the summary">
    Open the summary panel and read the Markdown as it is generated. Collapsing the panel or switching issues does not stop generation. Open it again to continue.
  </Step>
</Steps>

A successful summary stays on this Mac. Reopen the same issue after a restart and it plays back, with the last summary time on the panel. Generate again only when you want a new one.

## Watch-outs

- Marking a notification done does not close the issue. Close and reopen are separate actions.
- The summary is a reading aid. A comment is sent only from the draft you confirm.
