## Purpose

Lay out one person's followers and following on one graph and walk the path, instead of paging through a GitHub profile.

## How to use it

1. Open a profile card (the owner avatar or name on repository details, or [GitHub account profile](/main-interface/sidebar)).
2. Enter followers or following. The graph fills the window.
3. Select a node for the avatar card. Follow or unfollow from there.
4. Choose **Load more** when you want more relations. The selected path stays highlighted.

Paging stays available while counts are still loading. If the loaded count and the total disagree, refresh and try again.

## Watch-outs

<Info>
  Expansion has no fixed node cap. When GitHub rate-limits the account, the graph shows a local recovery time. Continue after that window.
</Info>

You only see public relations the signed-in account can read. Restricted accounts say so. They do not appear as an empty graph.
