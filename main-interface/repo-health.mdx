## Purpose

Before you dive into source or file an issue, check whether the repo is still maintained and what quality / security signals look like. Repo Health is a reading aid, not a security audit.

Requires [Pro](/subscribe/plan-comparison). Non-Pro taps open the paywall.

## Where to look

- Health badge on list rows
- Badge in detail metadata → **Repo Health** panel

Typical four axes (0-100; labels follow the app):

- **Maintenance**: commit / Release activity
- **Popularity**: Stars and community heat
- **Quality**: docs and engineering signals
- **Security**: including OpenSSF alignment

Open **Scoring rules** and refresh manually when needed.

## OpenSSF

Detail can show an OpenSSF Scorecard badge: hover or click for a summary / radar; full checks open a sheet.

<Frame caption="OpenSSF Scorecard">

Data depends on network and cache. A fetch error is not a score of zero.

## Filters and the browser extension

Toolbar filters can limit the list to repos that already have Health / OpenSSF cache. See [Filters](/search/filters).

The browser extension shows locally cached read-only scores; it does not recompute a full Scorecard on github.com. See [Extension features](/browser-plugin/features).

## Notes

- Some OpenSSF paths are unavailable on private repos. See [My Projects](/main-interface/my-projects).
- Directory-style GitHub Issue Forms count as community standards, not as "missing".
