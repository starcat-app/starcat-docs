## 主窗口布局

Starcat 采用经典的 **三栏布局**，灵感来自 macOS 原生应用（如 Mail、Notes）：

```
┌──────────────┬────────────────────┬──────────────────────────┐
│              │                    │                          │
│   侧边栏     │     仓库列表       │      详情面板            │
│   Sidebar    │    Repo List       │     Detail Panel         │
│              │                    │                          │
│  · All Repos │  排序 · 搜索 · 筛选│   README · 元数据        │
│  · Tags      │                    │   AI 摘要 · 笔记         │
│  · Languages │   仓库卡片列表     │   标签管理 · 操作        │
│  · Starred   │                    │                          │
│  · 知识库    │                    │                          │
│              │                    │                          │
└──────────────┴────────────────────┴──────────────────────────┘
```

### 侧边栏 (Sidebar)

左侧导航面板，包含你的所有数据分类入口。详见 [侧边栏](/main-interface/sidebar)。

### 仓库列表 (Repo List)

中间区域，展示当前分类下的仓库卡片。支持排序、筛选、搜索。详见 [仓库列表](/main-interface/repo-list)。

### 详情面板 (Detail Panel)

右侧区域，展示选中仓库的详细信息：README、元数据、AI 摘要、笔记等。详见 [仓库详情](/main-interface/repo-detail)。

## 工具栏

窗口顶部的工具栏提供快捷操作入口。详见 [工具栏](/main-interface/toolbar)。

## 界面特性

### Liquid Glass 设计

Starcat 采用 macOS 26 的 Liquid Glass 设计语言，提供半透明玻璃材质、流畅动画和深度层次感。

### 明暗主题

自动跟随系统主题切换，也支持手动选择明暗模式。

### 字体倍率

在设置中调整界面字号倍率，适配不同的显示偏好。

## 独立窗口

Starcat 的部分功能可以在独立窗口中打开：

- **AI 对话** — 仓库 AI 助手浮动窗口
- **Agent 工作台** — 独立的多步骤 AI 任务工作台
- **知识库 RAG 工作台** — 独立的 RAG 问答窗口
