## What it is for

The main window is the daily Stars workspace, not an admin console. Layout matches Finder / Mail: **pick a scope on the left, scan the list in the middle, inspect the selection on the right**.

Learn the three columns before tags and AI, and you will spend less time wondering where you are.

```
┌────────────┬─────────────────────┬──────────────────────┐
│  Sidebar   │  List + toolbar     │  Detail panel        │
│            │  Repo / Activity    │  README · notes      │
└────────────┴─────────────────────┴──────────────────────┘
```

| Column | Job | Docs |
|--------|-----|------|
| Left | Switch Manage / Explore / Activity, then a subcategory | [Sidebar](/main-interface/sidebar) |
| Center | Repos or notifications for the current category; page toolbar on top | [Repository list](/main-interface/repo-list), [Toolbar](/main-interface/toolbar) |
| Right | README, tags, notes, Health, AI for the selection | [Repository detail](/main-interface/repo-detail) |

When the window narrows, the detail column may collapse so the list stays usable. That is adaptive layout, not a bug.

## Three top-level areas

| Area | Job |
|------|-----|
| **Manage** | What you already have: Stars, My Projects, knowledge base, tags, collections, Release timeline, Insights |
| **Explore** | What is not in your library yet: Trending, Weekly, Awesome, Hot, New releases |
| **Activity** | GitHub notification inbox by default, plus announcements, Release, and other local feeds |

Daily triage lives in Manage. Rankings live in Explore. Mentions and reviews live in Activity.

## Detached windows

When you need README beside a long chat, or cross-repo Q&A, pull the tool out of the main window:

| Window | How to open | Docs |
|--------|-------------|------|
| Repo AI | Detach the overlay, or **⇧⌘A** | [AI chat](/ai-features/chat) |
| RAG workspace | Toolbar or **⇧⌘K** | [RAG workspace](/knowledge-base/rag-workspace) |
| Agent workspace | Dedicated entry | [Agent (Beta)](/agent-workspace/overview) |

## Appearance

**Settings → General**: 18 UI languages, Light / Dark / System, font scale, list density, reduce motion. See [General settings](/settings/general).

## Notes

- Manage lists are your Stars / projects. Explore lists come from Starcat discovery services, not a mirror of local Stars.
- Activity opens on **Notifications**, not “everything”. See [Activity](/discover/activity/activity).
