## 位置

主窗口**中栏顶部**，随当前页面（Manage 列表、探索、集合等）变换可用按钮。

## 高频按钮

| 按钮 | 说明 |
|------|------|
| **同步** | 拉取 / 增量同步 GitHub Stars；旋转表示进行中 |
| **筛选** | [统一筛选](/search/filters) |
| **多选** | [批量操作](/manage-stars/batch-operations) |
| **列表搜索** | 当前列表关键词 / 语义；默认常 **⌘F** |
| **知识库问答** | 打开 [RAG 工作台](/knowledge-base/rag-workspace) |
| **外链 / Clone / AI** | 多在「已选中仓库」时出现 |

刷新类 icon-only 控件使用产品统一的同步图标样式（非随意 `arrow.clockwise`）。

## 与全局快捷键的关系

| 能力 | 默认快捷键 | 说明 |
|------|------------|------|
| Search Center | **⌘K** | 四 Scope 聚合搜索，不一定等于列表搜索框 |
| 列表搜索聚焦 | **⌘F** | SmartSearchField |
| 仓库 AI | **⇧⌘A** | 需 Pro + AI 配置 |
| RAG 工作台 | **⇧⌘K** | 需 Pro |

均可在 [快捷键](/settings/shortcuts) 修改。不要把 ⌘K 与 ⌘F 混为一谈。
