## The job

You are already in one list and only want to sync, filter, or find a name in that list, without opening global search first.

The middle-column toolbar changes with the page. Global search stays **⌘K**. Quick search in the middle column exists on both builds.

## Frequent buttons

| Button | Job |
|--------|-----|
| **Sync** | Fetch / incrementally sync Stars; spins while running. Uses the product sync icon `arrow.triangle.2.circlepath` |
| **Filter** | [Unified filters](/search/filters) |
| **Multi-select** | [Batch operations](/manage-stars/batch-operations) |
| **Quick search** | Expands in the middle column and searches only the current list (Manage, Explore, notifications, Undo Star, and similar). This is not ⌘K |
| **List search** | Keyword or semantic search for the **current** list; often **⌘F** |
| **Knowledge Q&A** | Opens [RAG workspace](/knowledge-base/rag-workspace) |
| **Link / Clone / AI / CodeFlow** | Usually after a repo is selected |
| **Status** | Sync, indexing, and official GitHub status; opens GitHub Status when something is wrong |

## vs shortcuts

| Action | Default | Do not confuse with |
|--------|---------|---------------------|
| Search Center | **⌘K** | Four-scope search, not the list search field |
| List search | **⌘F** | Filters the current middle list only |
| Refresh | **⌘R** | List or detail, depending on focus |
| Repo AI | **⇧⌘A** | Cloud needs Pro; the on-device model does not |
| RAG | **⇧⌘K** | Needs Pro |

All of these are editable in [Shortcuts](/settings/shortcuts).

## Sync alerts and the menu bar

While Starcat is in front, a Star added from the GitHub website, a browser, or another tool shows an avatar alert on All repositories. Click it to sync. The list returns to the top.

<DirectVersionBadge /> You also want to see whether sync or a download is stuck without opening the main window. Left-click the Starcat menu-bar icon for that status panel. You can pause or stop a task there. Right-click opens the shortcut menu. App Store 1.9.1 does not have this panel yet. The external-Star avatar alert exists on both. Enhanced diagnostics: [Diagnostics](/settings/diagnostics).

## Notes

- Refresh on Explore pages refreshes discovery cache, not a full Stars sync.
- Official GitHub status is public githubstatus.com-style status, not your API quota panel.
