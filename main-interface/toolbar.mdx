## 工具栏概览

主窗口顶部的工具栏提供快速访问常用功能：

```
[同步状态] [面包屑] ... [搜索] [筛选] [排序] [Pro/状态]
```

## 同步按钮

左侧显示同步状态，点击可手动触发同步：

- **idle** — 静止状态
- **spinning** — 同步进行中（带旋转动画）
- **上次同步时间** — hover 显示

## 全局搜索

工具栏中间的搜索框，按 `Cmd+F` 快速聚焦。详见 [全局搜索](/search/global-search)。

## 筛选入口

工具栏右侧的筛选按钮，展开多维度筛选菜单。详见 [筛选与过滤](/search/filters)。

## 排序入口

筛选按钮旁的排序按钮，当前排序方式以图标表示。

## 克隆地址

选中仓库后，工具栏显示复制 Clone URL 入口。

## Pro 状态

最右侧显示 Pro 订阅状态图标。点击查看详情或升级。
