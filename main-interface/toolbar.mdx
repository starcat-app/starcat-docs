## Purpose

The toolbar sits on top of the middle column and changes with the page: Manage list, Explore, collections, and the notification timeline expose different controls. Global search is **⌘K** by default, not on this bar.

## Frequent buttons

| Button | Job |
|--------|-----|
| **Sync** | Fetch / incrementally sync Stars; spins while running. Uses the product sync icon `arrow.triangle.2.circlepath` |
| **Filter** | [Unified filters](/search/filters) |
| **Multi-select** | [Batch operations](/manage-stars/batch-operations) |
| **List search** | Keyword or semantic search for the **current** list; often **⌘F** |
| **Knowledge Q&A** | Opens [RAG workspace](/knowledge-base/rag-workspace) |
| **Link / Clone / AI / CodeFlow** | Usually after a repo is selected |
| **Status** | Sync, indexing, and official GitHub status; opens GitHub Status when something is wrong |

## vs shortcuts

| Action | Default | Do not confuse with |
|--------|---------|---------------------|
| Search Center | **⌘K** | Four-scope search, not the list search field |
| List search | **⌘F** | Filters the current middle list only |
| Refresh | **⌘R** | List or detail, depending on focus |
| Repo AI | **⇧⌘A** | Needs Pro + AI setup |
| RAG | **⇧⌘K** | Needs Pro |

All of these are editable in [Shortcuts](/settings/shortcuts).

## Notes

- Refresh on Explore pages refreshes discovery cache, not a full Stars sync.
- Official GitHub status is public githubstatus.com-style status, not your API quota panel.
