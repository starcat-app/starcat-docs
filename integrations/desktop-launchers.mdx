## Overview

Starcat provides open companion projects so you can search **local Stars / repositories** and **GitHub** without leaving your launcher of choice:

| Launcher | Project |
|----------|---------|
| **Alfred** | [starcat-alfred-workflow](https://github.com/starcat-app/starcat-alfred-workflow) |
| **uTools** | [starcat-utools-plugin](https://github.com/starcat-app/starcat-utools-plugin) |
| **Raycast** | [starcat-raycast-extension](https://github.com/starcat-app/starcat-raycast-extension) |

These are separate repositories from the main Starcat app. Install from each project’s README.

## Typical capabilities

Exact commands differ by launcher, but the product intent is the same:

1. Query Starcat’s local library on this Mac  
2. Fall back to or combine with GitHub search when useful  
3. Open a hit in Starcat (often via `starcat://…` deep links)  

## Prerequisites

- Starcat running (or recently used) so local search data / pairing is available when the extension requires it  
- Follow each project’s setup for permissions, keywords, and macOS privacy prompts
