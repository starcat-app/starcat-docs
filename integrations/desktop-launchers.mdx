## Purpose

Search local Stars / repos and GitHub from Alfred, uTools, or Raycast, then open hits with `starcat://`. Each launcher is a separate repo. Install from that project's README.

## Companion projects

| Launcher | Project |
|----------|---------|
| Alfred | [starcat-alfred-workflow](https://github.com/starcat-app/starcat-alfred-workflow) |
| uTools | [starcat-utools-plugin](https://github.com/starcat-app/starcat-utools-plugin) |
| Raycast | [starcat-raycast-extension](https://github.com/starcat-app/starcat-raycast-extension) |

Typical jobs: search the local library, fall back to GitHub when needed, open hits in Starcat.

Keep Starcat running or recently used so local search / pairing works. Finish permissions, keywords, and macOS privacy prompts in each project's README.

## Notes

The App Store sandbox cannot launch arbitrary user CLIs. Launcher extensions are separate processes but still need the app's Local API / deep links. URL shapes: [Share links](/share-export/share-links).
