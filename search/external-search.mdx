## 外部搜索

Starcat 支持接入外部搜索 Provider，在应用内直接搜索网络上的技术内容。

## 支持的 Provider

| Provider | 说明 | 需要 API Key |
|----------|------|-------------|
| **AnySearch** | 默认搜索引擎，无需 Key | 否 |
| **Tavily** | AI 优化的搜索 API | 是 |
| **Exa** | 语义搜索 API | 是 |
| **Brave LLM Context** | Brave 搜索的 AI 上下文 | 是 |

## 配置外部搜索

1. 前往 设置 → 外部搜索
2. 启用需要的 Provider
3. 输入 API Key（如需要）
4. 点击「测试」验证连接
5. 设置默认 Provider

## 在搜索中使用

在 Search Center 切换到「Web」标签，即可使用外部搜索。搜索结果会显示 Provider 图标，来自不同 Provider 的结果可区分。

## AI 外部上下文

AI 助手对话中，外部搜索可以作为附加上下文源：

- 开启后，AI 回答时会搜索相关网络内容
- 可在 AI 设置中控制是否启用
- 搜索内容会缓存到本地，减少重复 API 调用

## 缓存

外部搜索结果缓存到本地：

- 搜索缓存：6 小时 TTL
- AI 上下文缓存：24 小时 TTL
- 可在存储管理中清除缓存
