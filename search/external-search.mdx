## What it is for

Third-party web search plugs into Starcat in two places:

1. [Search Center](/search/search-center) **Web** scope
2. **Live web context** for AI / RAG when those switches allow it

AnySearch, Tavily, and similar are providers, not a separate product.

## How to configure it

| Provider | Notes |
|----------|-------|
| AnySearch | Common default; whether a key is required follows the app |
| Tavily | API key |
| Exa | API key |
| Brave LLM Context | API key |

1. **Settings → Integrations → External Search**
2. Enable a provider, fill the key if needed, save
3. Test the connection
4. Pick defaults for web search / AI context (follow the UI)

Also see [Integrations](/settings/integrations).

In Search Center: ⌘K → **Web** → type a query → results include source sites.

## Notes

- Results are cached locally to cut repeat billing / requests. Clear the cache in **Settings → Storage**.
- Queries go to the third-party service you enabled.
- Whether private repos may attach live web context is gated by integration / AI switches. See [Privacy](/data-privacy/privacy).
- Web scope is **not** semantic search.
