## What they are for

The sidebar picks a **category**. Filters pick **hard constraints inside that category**. Daily triage: open Untagged or a Smart Collection, narrow with the funnel, then [batch](/manage-stars/batch-operations). Faster than checking rows on raw All Stars.

## How to use them

Manage (and some list pages) expose a unified filter menu (funnel; copy follows the app):

1. Pick a sidebar scope
2. Open filters and check dimensions
3. Optionally ⌘F or batch

## Dimensions

| Dimension | Meaning | More |
|-----------|---------|------|
| **Status** | unread / read / using | [Notes and status](/manage-stars/notes-and-status) |
| **Starred / not starred** | Toolbar may also have a shortcut | — |
| **Knowledge base** | Ingested / not ingested | [Knowledge base](/knowledge-base/overview) |
| **Language** | Multi-select; can pair with interest languages | [List preferences](/settings/list-preferences) |
| **Tags** | Narrow by tag | [Tags](/manage-stars/tags) |
| **Wiki** | Repos with a wiki signal | Wiki entry in detail |
| **Health** | Cached health score | [Repo Health](/main-interface/repo-health) |
| **OpenSSF** | Cached security score | Same |
| **Hide archived** | Drop archived repos | — |
| **Hide forks** | Drop forks | — |

Not every page shows every dimension. Explore lists usually expose fewer.

## Combining layers

Multiple conditions are generally **AND**. Example: language = Swift **and** status = using **and** not ingested.

| Layer | Job |
|-------|-----|
| Sidebar category | Outer scope |
| Filters | Structured constraints |
| List search (⌘F) | Keywords / semantic on top |

When all three apply, the list is already a subset. See [List search](/search/global-search).

## Reset

- **Reset** at the bottom of the menu clears the current filters
- Conditions are often remembered **per module**: switching Tag A → All Stars may restore each last state
- If it feels stuck: [General](/settings/general) → reset list preferences

To keep the same rule in the sidebar every day, use a [smart collection](/manage-stars/smart-collections). The filter menu is not a bookmark.
