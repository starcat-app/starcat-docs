## Purpose

When you know the job and not the repository name, describe it in a sentence. Starcat looks for GitHub repositories you have not starred and returns a reason plus evidence.

## How to use it

1. Open [Search Center](/search/search-center) (default **⌘K**).
2. Choose **Smart discovery** and write the need.
3. Results arrive progressively. Ask it to keep looking if the first set is thin.
4. Filter the source bar to one kind: keyword, semantic, GitHub, web, or smart discovery. Each source has its own count, and the same repository is not listed twice.

Built-in rules hide unsuitable results. Ordinary search and smart discovery share those rules.

## Watch-outs

<Warning>
  Smart discovery uses the same entitlement as semantic search. The on-device model is free. A cloud provider requires [Pro](/subscribe/plan-comparison) and a configured chat model. See [AI setup](/ai-features/configuration).
</Warning>

This looks for public repositories you have not starred. Search starred repositories with the Local scope or **⌘F**.
