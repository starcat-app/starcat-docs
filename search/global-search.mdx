## Purpose

Starcat has two search entries:

| Entry | Default shortcut | Job |
|-------|------------------|-----|
| **Search Center** | **⌘K** | Standalone panel: local Stars, GitHub, and the web |
| **List search** | **⌘F** | Filter only the current Manage / Explore list |

Shortcuts are editable in [Shortcuts](/settings/shortcuts). Dedicated page: [Search Center](/search/search-center).

## Keyword list search

Focus the middle search field. Local FTS5 usually covers name, owner, description, topics, and **saved** private notes.

- Multi-word matching
- Relevance ranking (BM25-style)
- Combines with [toolbar filters](/search/filters)
- Knowledge-base content supports Chinese infix matching

Unsaved note drafts are not indexed.

## Semantic list search (Pro)

Switch to **Semantic** and describe the library in natural language. Requirements:

1. [Pro](/subscribe/plan-comparison)
2. Embedding configured in [Settings → AI](/settings/ai)
3. Build / refresh the AI index when the UI asks

Scope can be starred / knowledge / all (follow the app). See [Semantic search](/search/semantic-search).

## Which entry

| Situation | Use |
|-----------|-----|
| Shrink Untagged right now | ⌘F + filters |
| Search local + GitHub + web together | ⌘K |
| "Is there a local RAG library?" | List semantic, or the [RAG workspace](/knowledge-base/rag-workspace) |

## Notes

- ⌘F never searches Stars outside the current list.
- Semantic search uses the embedding index. Web search uses External Search providers.
