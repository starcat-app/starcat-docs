## 全局搜索

按 `Cmd+F` 打开全局搜索框，输入关键词即可搜索你的所有 Stars。

## 搜索范围

全局搜索覆盖以下字段：

- 仓库名称 (name)
- 所有者 (owner)
- 描述 (description)
- Topics 标签
- 私有笔记内容

## FTS5 全文搜索

Starcat 使用 SQLite 的 FTS5 全文搜索引擎，支持：

- **前缀匹配** — 输入 "react" 匹配 "react", "reactive", "reactivity"
- **BM25 排序** — 结果按相关性排序
- **多词搜索** — 空格分隔的关键词 AND 组合

## 搜索技巧

| 技巧 | 写法 | 说明 |
|------|------|------|
| 精确匹配 | `"machine learning"` | 匹配完整短语 |
| 多关键词 | `react ui` | 同时包含两个词 |
| 按 owner | `owner:facebook` | 搜索特定作者 |
| 按语言 | `language:swift` | 搜索特定语言 |

## 搜索历史

搜索框自动保存最近的搜索记录，点击历史项可快速重用。

## 搜索结果

- 搜索结果按 **BM25 相关性** 排序
- 点击结果跳转到仓库详情
- 支持在搜索结果中直接操作（打标签、入库等）
