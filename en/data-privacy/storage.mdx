## Local SQLite

| Data type | Rebuildable? |
|-----------|--------------|
| Repo metadata / README cache | Yes |
| Tags / notes / status / collections | **No** |
| AI / RAG history | Back up if you need it |
| AI summary cache | Regeneratable |

Stack: GRDB.swift + FTS5; schema upgrades through versioned migrations — production users should not delete the database.

## Keychain

- GitHub OAuth / PAT  
- AI provider API keys  
- Local integration secrets  

## App Store vs Direct

Separate containers and directories — **data does not transfer automatically**. See [Installation](/en/getting-started/installation).

## Account isolation

Local data is isolated per GitHub account; switching accounts does not automatically wipe another account's data.

## Cloud sync

Not shipped yet. See [Backup](/en/data-privacy/backup).
