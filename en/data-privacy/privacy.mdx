## Principles (summary)

Starcat defaults to **local-first**:

- Tags, notes, status, and other user data stay on your Mac first  
- No selling personal data; no ad tracking  
- Starcat does not read your GitHub password  
- AI keys live in Keychain; notes are not used to “train our models”  

Full legal text: [starcat.ink/privacy](https://starcat.ink/privacy).

## Data categories

| Type | Examples | Rebuildable from GitHub? |
|------|----------|--------------------------|
| Repo cache | Metadata, README | Yes |
| User data | Tags, notes, status, collection rules | **No** |
| Secrets | GitHub token, AI keys | Keychain |

Cross-device cloud sync is not shipped → [Backup](/en/data-privacy/backup).

## AI and third parties

- **BYOK**: requests go to your configured provider → [BYOK](/en/subscribe/byok)  
- **External search**: queries go to enabled providers only → [External search](/en/search/external-search)  
- **Sharing**: share cards or public links only when you choose → [Share cards](/en/share-export/share-cards)  

## Telemetry

Anonymous telemetry is **off by default**; enable under **Settings → Diagnostics**. See [Telemetry](/en/data-privacy/telemetry).
