## Concept

Dynamically include repos by **rules**: when data changes, membership updates automatically. Good for standing views like Untagged, low maintenance, or Using.

<Note>
  Free tier: up to **4** **custom** collections; Pro: unlimited. Built-in system collections generally do not count toward the limit.
</Note>

## Entry

Sidebar **Manage → Smart Collections**:

- Overview of system + custom collections  
- Click a name to open the matching list  
- Gear opens the rule editor  

## System collections (examples)

Names follow the app; common perspectives include:

- In knowledge base / Stars not ingested  
- Needs review, low maintenance, high value  
- Untagged, **Using**, recently active  

Use system collections as daily triage entry points, then [batch operations](/en/manage-stars/batch-operations).

## Create a custom collection

<Steps>
  <Step title="New">Tap “+”.</Step>
  <Step title="Add conditions">Language, tags, status, Star count, last updated, ingest state, and more; AND / OR.</Step>
  <Step title="Name and save">Appears in the sidebar.</Step>
</Steps>

At the limit, entitlement gating blocks creation → [Plan comparison](/en/subscribe/plan-comparison).

## Edit / delete

Changing rules, renaming, or deleting a collection **does not** delete repositories.
