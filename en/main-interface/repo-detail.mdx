## Panel layout

When you select a repo, the right detail pane roughly includes:

1. **Metadata header**: full name, description, stats, license, homepage link, and more  
2. **Actions**: Star/Unstar, ingest, subscribe to Release, Wiki, similar repos, Health, and more (some require Pro)  
3. **README**: WebView-rendered GFM; supports images, anchors, and common GitHub layout  
4. **Organization**: [Tags](/en/manage-stars/tags), [Notes and status](/en/manage-stars/notes-and-status)  
5. **AI overlay entry**: summary / chat, and more → [AI overview](/en/ai-features/overview)

## Common README actions

| Action | Description |
|--------|-------------|
| Open in browser | Jump to the GitHub repo page |
| Clone menu | Copy HTTPS / SSH, and more |
| Export Markdown | Export the current README |
| Translate | Pro → [README translation](/en/ai-features/readme-translation) |

## Unstar

Unstarring from detail calls the GitHub API and **cannot be undone with one tap inside Starcat**. Batch Unstar: [Batch operations](/en/manage-stars/batch-operations).
