## Structure

The sidebar is typically organized top to bottom as:

1. **Top-level switch**: Manage / Discover / Activity  
2. **Sub-navigation under the current top level** (groups can collapse)  
3. **User area**: avatar, account, Pro status, share, and sign out  

Group header rows are generally **clickable on the full row** to collapse or expand; the chevron only reflects state.

## Common Manage sub-entries

| Entry | Description | Further reading |
|-------|-------------|-----------------|
| All Stars | All synced Stars | — |
| Untagged | Repos without tags yet | [Tags](/en/manage-stars/tags) |
| Library / Knowledge base | Ingested repos | [Knowledge base](/en/knowledge-base/overview) |
| Languages | Browse by language | [Filters](/en/search/filters) |
| Tags | Browse by tag; “+” shortcut to manage tags | [Tags](/en/manage-stars/tags) |
| Smart Collections | System + custom rule-based collections | [Smart collections](/en/manage-stars/smart-collections) |
| GitHub Stars Lists | Lists synced from GitHub | [GitHub Lists](/en/manage-stars/github-lists) |
| Release timeline | Aggregated view of subscribed Releases | [Timeline](/en/release/timeline) |

Exact labels and ordering follow the current app version.

## Discover

Five modes: Discover, Trending, Hot, New releases, and Weekly. See [Discover overview](/en/discover/explore/overview).

## Activity

Activity categories (All, Announcements, Release, Star, Following, and more). See [Activity](/en/discover/activity/activity).

## User area

- View the current GitHub user
- Open Pro / settings-related entries (or open Settings from the menu)
- [Share cards](/en/share-export/share-cards)
- Sign out and switch accounts (see [GitHub connection](/en/getting-started/github-connection))
