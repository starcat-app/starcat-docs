## Location

Top of the **center column** in the main window. Available buttons change with the current page (Manage list, Discover, collections, and more).

## High-frequency buttons

| Button | Description |
|--------|-------------|
| **Sync** | Fetch / incrementally sync GitHub Stars; spins while in progress |
| **Filter** | [Unified filters](/en/search/filters) |
| **Multi-select** | [Batch operations](/en/manage-stars/batch-operations) |
| **List search** | Keywords / semantic search for the current list; default often **⌘F** |
| **Knowledge base Q&A** | Open [RAG workspace](/en/knowledge-base/rag-workspace) |
| **External link / Clone / AI** | Usually appear when a repo is selected |

Refresh-style icon-only controls use the product’s unified sync icon style (not arbitrary `arrow.clockwise`).

## vs global shortcuts

| Capability | Default shortcut | Notes |
|------------|------------------|-------|
| Search Center | **⌘K** | Four-scope aggregated search—not always the same as the list search field |
| Focus list search | **⌘F** | SmartSearchField |
| Repo AI | **⇧⌘A** | Requires Pro + AI configuration |
| RAG workspace | **⇧⌘K** | Requires Pro |

All can be changed in [Shortcuts](/en/settings/shortcuts). Do not confuse ⌘K with ⌘F.
