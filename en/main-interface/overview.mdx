## Layout

Starcat’s main window is a classic **three-column** macOS workspace:

| Column | Role |
|--------|------|
| **Left** | Navigation: Manage, Discover, Releases, Knowledge, settings entry points |
| **Center** | Repository list for the current filter / collection |
| **Right** | Detail: metadata, README, notes, tags, health, AI entry points |

## Everyday flow

1. Pick a sidebar section (e.g. All Stars, a tag, Untagged)
2. Scan / search the list (⌘F for list search; ⌘K for Search Center)
3. Select a repo and read the README; add tags or status as needed
