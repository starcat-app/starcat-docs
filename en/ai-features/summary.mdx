## Purpose

Before reading a long README end to end, get a structured outline (background, features, use cases, caveats, etc.; exact structure varies with the prompt).

## Entry points

1. Detail AI panel → Summary (**⇧⌘A**)  
2. [Auto Tidy](/en/ai-features/auto-tidy) batch generation  

## Cache

Summaries are stored in local cache to avoid repeat token use. Clear summary cache under **Settings → Storage**. See [Storage management](/en/settings/storage).

Regenerating calls the model again (cost and quota depend on your Provider).

## Quality notes

- Summaries do not replace reading the license, security advisories, or latest Release  
- Very short or image-only READMEs produce weaker summaries  
- Requires Pro + an available Chat model
