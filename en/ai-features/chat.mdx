## How to open

| Method | Notes |
|--------|-------|
| Shortcut | Default **⇧⌘A** ([customizable](/en/settings/shortcuts)) |
| Detail panel | Open the AI panel after selecting a repository |
| Detached window | Detach from the panel to read alongside README |

Requires [Pro](/en/subscribe/plan-comparison) + a configured Chat model → [AI configuration](/en/ai-features/configuration).

## Typical panel layout

- **Summary** actions → [AI summary](/en/ai-features/summary)  
- **Chat** tab: ask about the **current repository**  
- May include tag recommendation entry points → [Tag recommendations](/en/ai-features/tag-recommendation)  

Exact tab labels follow the app UI.

## Good questions to ask

- “Summarize in three bullets what problem this repo solves”  
- “What are the quick-start steps (based on README)?”  
- “What are obvious limits or non-goals?”  

For comparisons across multiple ingested repos, use the [RAG workspace](/en/knowledge-base/rag-workspace) instead of stretching the single-repo panel.

## External context

If AI external search context is enabled, answers may include web sources. Configure under **Settings → Integrations**. See [External search](/en/search/external-search).
