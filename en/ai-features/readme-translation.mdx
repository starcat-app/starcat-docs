## Entry point

The **Translate** button in the local repository detail README toolbar.

| Scenario | Usually available? |
|----------|-------------------|
| Manage / Explore local detail | Yes |
| Some Activity / external previews | Maybe not |

## Steps

<Steps>
  <Step title="Open detail">Wait for README to finish loading.</Step>
  <Step title="Translate">Pick target language; default can follow UI language.</Step>
  <Step title="Read side by side">Switch between translation and original (per app UI).</Step>
</Steps>

Requires Pro and a translation model in [AI configuration](/en/ai-features/configuration).

## Notes

- Very long READMEs cost more time and tokens  
- Code blocks / tables may layout worse than the original  
- Whether translation is cached depends on app behavior
