## Prerequisites

1. Activate [Pro](/en/subscribe/purchase) → see the entitlement table in [Plan comparison](/en/subscribe/plan-comparison)  
2. Configure a Provider under **Settings → AI** ([BYOK](/en/subscribe/byok), [step-by-step setup](/en/ai-features/configuration))  
3. Pick default models for each task: Chat (summary / chat / tags) and **Embedding** (semantic search / RAG)  

Missing Embedding is the most common reason you have Pro but still cannot use semantic search or RAG.

## Capability map

| Feature | Typical entry | Docs |
|---------|---------------|------|
| AI summary | Detail panel **⇧⌘A** | [Summary](/en/ai-features/summary) |
| AI chat | Same panel; can detach to a separate window | [Chat](/en/ai-features/chat) |
| Tag recommendations | Panel / Auto Tidy | [Tag recommendations](/en/ai-features/tag-recommendation) |
| README translation | README toolbar | [Translation](/en/ai-features/readme-translation) |
| AI personal notes | **Generate with AI** in the notes area | [Personal notes](/en/ai-features/personal-notes) |
| Semantic search | List semantic mode | [Semantic search](/en/search/semantic-search) |
| RAG Q&A | **⇧⌘K** | [Knowledge base](/en/knowledge-base/overview) |
| Auto Tidy | Settings → AI | [Auto Tidy](/en/ai-features/auto-tidy) |
| Agent workspace | Separate window | [Agent Beta](/en/agent-workspace/overview) |

Notes:

- The **web** scope in [Search Center](/en/search/search-center) does not require Pro  
- If AI attaches live web context, Pro and toggle rules still apply → [External search](/en/search/external-search)  

## Conservative policy

| Scenario | Rule |
|----------|------|
| Tag recommendations | Written only after you confirm |
| AI notes | Saved only after you confirm the draft |
| Agent | Data changes require explicit authorization |
| Auto Tidy | Runs only the actions and triggers you enable |

## Recommended onboarding order

<Steps>
  <Step title="Configure models">[AI configuration](/en/ai-features/configuration) → test connection.</Step>
  <Step title="Try one repo">Detail → ⇧⌘A → summary or ask one question.</Step>
  <Step title="When you need semantic search">Add Embedding → build index → list semantic mode.</Step>
  <Step title="When you need cross-repo Q&A">Curate ingest → [RAG workspace](/en/knowledge-base/rag-workspace).</Step>
  <Step title="Then automate">After output quality looks good, enable [Auto Tidy](/en/ai-features/auto-tidy).</Step>
</Steps>
