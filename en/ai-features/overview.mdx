## Overview

Starcat AI is **Pro**-gated and **BYOK**-friendly: you bring provider keys; Starcat orchestrates summaries, chat, translation, semantic search, and more.

## Capability map

| Feature | Notes |
|---------|-------|
| Repository summary | Cached README-oriented summaries |
| Tag suggestions | Suggestions only—**confirm before write** |
| Chat | Repo-scoped assistant |
| README translation | In-detail translation |
| Semantic search | Embedding-backed retrieval |
| Personal notes / Auto Tidy | Assisted cleanup; confirm writes |
| RAG | Separate knowledge-base workspace |

## Conservative policy

AI **suggests**; you **confirm** before tags/notes land in your library. That keeps Stars trustworthy.

## Setup

1. Unlock Pro ([plans](/en/subscribe/plan-comparison))
2. Settings → AI → configure provider / model
3. Try summary or chat on a selected repository
