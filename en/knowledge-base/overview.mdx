## What it is

The **RAG workspace** answers questions against repositories you **ingest** into the knowledge base—not against every Star automatically.

- Local-first indexing and retrieval
- Streaming answers with **citations / evidence**
- Sessions, groups, pins, history, drafts
- Hybrid retrieval (vectors, keywords, metadata, optional external / live GitHub context)

## Prerequisites

- **Pro** entitlement
- BYOK (or configured AI) under Settings → AI
- At least one ingested repository (heart / ingest from Stars)

## Mental model

| Concept | Meaning |
|---------|---------|
| Stars | Your GitHub starred list |
| Knowledge base | Explicitly ingested subset used for RAG |
| RAG workspace | Dedicated window / tab for grounded chat |
