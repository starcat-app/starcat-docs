## Five Explore modes

| Mode | What you’re looking for | Dedicated page |
|------|-------------------------|----------------|
| **Discover** | Curated recommendation feed; filter by topic / platform | This page |
| **Trending** | Recent momentum | [Trending](/en/discover/trending/trending) |
| **Hot** | High-heat repositories | [Hot and new](/en/discover/explore/hot-and-new) |
| **New releases** | New or freshly released projects | Same as above |
| **Weekly** | Editor-curated weekly entries | [Weekly](/en/discover/weekly/weekly) |

Data comes from Starcat discovery / trending / weekly services—not a mirror of your local Stars.

## After you find something good

Suggested pipeline:

1. Open detail and read the README  
2. Optional: Star  
3. Tag or jot a short note  
4. Long-term use → [Ingest](/en/knowledge-base/adding-repos)  
5. Track versions → [Subscribe to Release](/en/release/subscription) (free **5**-repo limit)  

Batch work: [Batch operations](/en/manage-stars/batch-operations).
