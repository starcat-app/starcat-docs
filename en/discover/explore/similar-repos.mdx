## Desktop (Pro)

In the repository detail actions area, open **Similar repos / Recommendations**.

- Requires network access to the recommendation service  
- Find alternative implementations or projects in the same space  
- Non-Pro hits the paywall  

See [Plan comparison](/en/subscribe/plan-comparison).

## Browser extension

GitHub repo pages can show a read-only recommendation list (usually with a count cap). Requires the local app + [Integrations settings](/en/settings/integrations). See [Extension features](/en/browser-plugin/features).
