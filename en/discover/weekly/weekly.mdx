## Data sources

Aggregates repository entries from multiple weeklies / digests, including:

- Ruan Yifeng’s Tech Enthusiast Weekly  
- ZRead  
- Hacker News  
- HelloGitHub  
- Verified AI intelligence  

Browse by source or language (options follow the UI).

## Selection rules

- A project appears only after at least one **enabled** source includes it.
- The same project may come from multiple sources; **editor-pinned** items rank first.

## Cache

- **TTL**: **6 hours**.
- **Refresh**: Use local cache while valid; after expiry, show existing content and silently refresh in the background; a manual refresh requests the latest data immediately.
- **Offline**: On update failure, keep the last successful cache so browsing is not interrupted.

## How to use it

Treat weeklies as weekly input: scan entries → Star → tag → ingest picks → [Subscribe to Release](/en/release/subscription) when needed.
