## Restore purchase

After replacing your Mac or reinstalling macOS, restore Pro through the channel you bought from.

## App Store users

1. Sign in with the **same Apple ID** on the new device  
2. Install [Starcat for GitHub](https://apps.apple.com/cn/app/starcat-for-github/id6788809803?mt=12)  
3. Open **Settings → Pro**  
4. Tap **Restore purchase**  
5. Use Pro features once entitlements are restored  

## Direct users

1. Install the Direct build from [starcat.ink](https://starcat.ink)  
2. Open **Settings → Pro → License**  
3. Sign in / enter your license as prompted  
4. If seats are full: unbind on the old device first, then activate on the new one  

See [License management](/en/subscribe/license) for details.

## FAQ

<AccordionGroup>
  <Accordion title="Will tags and notes survive a device switch?">
    User data (tags, notes, status, etc.) is stored locally for now. Before switching Macs, back up the Application Support directory manually, or wait for future cross-device sync. See [Backup and restore](/en/data-privacy/backup).
    Your Stars list can always be re-synced from GitHub — no backup needed.
  </Accordion>
  <Accordion title="Can Lifetime move to a new device?">
    Yes. Direct Lifetime supports up to 2 Macs for personal use; unbind an old device if you exceed that. App Store Lifetime follows Apple account and device rules — use **Restore purchase** first.
  </Accordion>
  <Accordion title="Do App Store and Direct purchases transfer?">
    No automatic transfer. Restore through the matching channel: App Store → Restore purchase; Direct → License.
  </Accordion>
</AccordionGroup>
