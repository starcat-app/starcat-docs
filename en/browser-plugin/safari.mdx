## Status

The Safari extension and Chrome Companion **share the same local API** model. Settings may already expose an entry; **feature completeness may lag Chrome** — follow the current extension version.

Repo: [starcat-safari-plugin](https://github.com/starcat-app/starcat-safari-plugin)

## Setup

Same as Chrome:

1. Starcat running  
2. Port and token under **Settings → Integrations**  
3. Install / trust the Safari extension per repo README  

Capability boundaries: [Features](/en/browser-plugin/features).
