## Entry

**Settings → Storage**

## Cache types (examples)

| Type | Description |
|------|-------------|
| README / images | Detail rendering cache; rebuildable |
| AI chat history | Per-repo AI overlay history |
| RAG session history | Knowledge-base Q&A history |
| External search cache | Web search and AI context cache |
| AI summary cache | Generated summaries |

Clear one row or everything. After clearing README cache, the next detail open re-downloads content.

## Finder shortcuts

The folder button beside a row opens the matching directory when the sandbox allows. App Store and Direct use different paths.

## Danger zone

### Factory reset

Deletes local user data, caches, and more (confirm the dialog). **Irreversible.**

Back up first: [Manual backup](/en/data-privacy/backup). Cloud sync and JSON export are not shipped — do not assume you can pull data back from the cloud.

### Clear data but keep settings

If **Delete local database but keep settings** is offered, back up first as well.
