## Scope of this page

This page covers **GitHub Stars** and local cache sync only. iCloud sync for tags and notes is **not available yet**.

## Manual sync

Click the sync button on the list toolbar:

- First run: full fetch  
- Later: incremental / ETag strategy to minimize unchanged data  

Getting Started expects you to tap sync yourself — see [Quickstart](/en/getting-started/quickstart).

## Rate limit

The GitHub API has rate limits. When hit, Starcat backs off and shows a reset countdown. Troubleshooting: [FAQ · Sync](/en/faq/sync).

## Background sync

When the system allows, scheduled checks may run in the background (toggle follows the app).

## Cross-device user data (coming soon)

<Warning>
