## Entry

**Settings → AI**

This page is the settings-side overview; step-by-step setup is in [AI configuration](/en/ai-features/configuration).

## Sections

| Section | Purpose |
|---------|---------|
| Provider list | Add, edit, or remove BYOK providers; keys go to Keychain |
| Discovered models | Refresh model lists and tune parameters |
| Default task mapping | Pick models for summary, tags, chat, embedding, translation, etc. |
| Auto Tidy | Background tidy toggle and triggers → [Auto Tidy](/en/ai-features/auto-tidy) |
| AI index | Semantic vector build / refresh → [Semantic search](/en/search/semantic-search) |
| RAG-related | Retrieval / rerank / self-hosted backend and other advanced items (when shown) |
| Output language | Follow UI language or set separately |

## Pre-flight checklist

1. Is Pro active? → [Plan comparison](/en/subscribe/plan-comparison)  
2. Does the Chat model pass **Test connection**?  
3. Is Embedding configured? (RAG / semantic search depend on it)  
4. Then try a real call in repo detail with **⇧⌘A**
