## Entry

**Settings → General**

## Display

| Item | Description |
|------|-------------|
| Interface language | English / 简体中文 |
| Theme | Follow system / Light / Dark |
| Font scale | Small / Standard / Large / Extra large |
| List density | Comfortable / Compact |
| Reduce motion | Accessibility |

Font scale affects list readability, timelines, and some body text.

## Notifications

Enable the master notification switch, Release notifications, and related options. macOS must also allow Starcat in System Settings. See [Release notifications](/en/release/notifications).

## Reset

| Action | Effect |
|--------|--------|
| Replay first-run guide | Shows welcome again; resets Getting Started progress |
| Reset list preferences | Clears sort / filter / density preferences |
| Reset all settings | Restores defaults; **usually does not** delete tags and notes (confirm in the dialog) |

To wipe data, use [Storage](/en/settings/storage) — do not confuse it with reset settings.
