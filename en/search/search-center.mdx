## Open it

- Default **⌘K**
- Global search entry beside the list
- Menu item “Open global search” (wording follows the app)

## Four scopes

| Scope | Searches | Notes |
|-------|----------|-------|
| **All** | Multi-source aggregation | When you’re unsure where results live |
| **Local** | Your Stars / local library | FTS; same engine as list search |
| **GitHub** | GitHub Search API | Ingest badge; Star / ingest actions |
| **Web** | External Search | Setup below |

**Web search** is available to all users (providers may need a key). **Semantic search** remains Pro and lives mainly in list semantic mode—don’t confuse it with the Web scope.

## GitHub scope filters (examples)

Language, topic, minimum stars, created/pushed dates, sort order, and more. Exact controls follow the panel.

Good for discovering repos you haven’t starred yet, then ingesting or starring in one step.

## Web scope

Uses providers enabled under **Settings → Integrations → External Search**:

- AnySearch / Tavily / Exa / Brave LLM Context, etc.  
- Domain, content type, freshness, allow/block lists, and more  

See [External search](/en/search/external-search) and [Integrations settings](/en/settings/integrations).

## Actions on results

- Open local detail or the system browser  
- Add to knowledge base / Star (depends on result type and sign-in)  
- Jump from GitHub results straight into your organize flow

## Troubleshooting

| Symptom | What to try |
|---------|-------------|
| ⌘K does nothing | Check [Keyboard shortcuts](/en/settings/shortcuts) for remapping or conflicts |
| GitHub scope empty | Check sign-in and rate limit → [FAQ · Sync](/en/faq/sync) |
| Web scope fails | Check keys / test under [Integrations → External Search](/en/settings/integrations) |
| Local miss words from notes | Confirm notes are saved; try [list search](/en/search/global-search) |
