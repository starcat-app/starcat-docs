## Coverage

English currently focuses on:

- Getting started (welcome, install, quickstart, GitHub)
- Main interface overview

The **full** topic set (tags, Release timeline, CLI, plugins, settings, FAQ detail, etc.) is maintained in **简体中文**. Use the language switcher, or open any Chinese URL directly (paths without the `/en` prefix).
