## Coverage

English documentation now covers the same topic set as Simplified Chinese, including Getting Started, Main interface, Manage Stars, Search, AI, Discover, Releases, Pro, Share, Browser plugins, Settings, Data & privacy, FAQ, CLI, RAG workspace, and Agent workspace (Beta).

Use the **language switcher** in the header to move between `zh-Hans` and `en`. Paths for English pages use the `/en/...` prefix.

## Still prefer Chinese?
