## What it is for

**Settings → MCP** lets the local [CLI](/cli/installation) call App capabilities over MCP (tag, status, and similar). Needs [Pro](/subscribe/plan-comparison). Writes default to dry-run; `--apply` actually persists.

## How to use it

1. Enable MCP Service
2. Confirm the port (often **5555**; avoid clashes)
3. Allow as needed: read private notes, local writes, batch writes, replace writes
4. Copy the pair command and run it:

```bash
starcat pair "starcat-pair://connect?..."
starcat doctor
```

The URI lasts about **5 minutes** and is single-use. You must **confirm the device** in the app. Long-lived credentials go in the Keychain. Full flow: [CLI usage](/cli/usage).

The settings page can copy Claude / Codex MCP snippets that register `starcat mcp`. See [Skill](/cli/skill).

## Notes

- The app enforces permission and audit. The CLI does not open the database.
- Remote connections need TLS and cert pinning (CLI security model).
