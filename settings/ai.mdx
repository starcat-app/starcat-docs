## 入口

**设置 → AI**

本页是设置侧总览；逐步配置见 [AI 配置](/ai-features/configuration)。

## 区块说明

| 区块 | 做什么 |
|------|--------|
| Provider 列表 | 增删改 BYOK Provider，Key 进 Keychain |
| 已发现模型 | 刷新模型列表、调参数 |
| 默认任务映射 | 摘要/标签/对话/Embedding/翻译各用哪个模型 |
| Auto Tidy | 后台整理开关与触发 → [自动整理](/ai-features/auto-tidy) |
| AI 索引 | 语义向量构建/更新 → [语义搜索](/search/semantic-search) |
| RAG 相关 | 检索/Rerank/自托管后端等高级项（有则显示） |
| 输出语言 | 跟随界面或单独指定 |

## 使用前检查清单

1. Pro 是否激活 → [方案对比](/subscribe/plan-comparison)  
2. Chat 模型能否测试通过  
3. Embedding 是否已配（RAG/语义强依赖）  
4. 再到详情 ⇧⌘A 做一次真实调用
