## Sections

| Block | Job |
|-------|-----|
| Providers | BYOK CRUD; keys in Keychain |
| Discovered models | Refresh, tweak params |
| Default task mapping | Summary / tags / chat / Embedding / translation |
| Auto Tidy | [Auto Tidy](/ai-features/auto-tidy) |
| AI index | Semantic vectors; green / amber / red → [Semantic search](/search/semantic-search) |
| RAG | Retrieve / rerank; optional Meilisearch / Qdrant |
| Output language | Follow UI or override |
| Usage | Local request counts, tokens, latency, failures; no prompt bodies |

AI index shows last prefetch time and counts; start, pause, resume. Cancelling embedding is not treated as "network down". External Meilisearch / Qdrant test-and-save: green / amber rebuild / red fail. Those are not the Go backends in [Settings → Services](/settings/services).

Before use: Pro active, Chat test ok, Embedding mapped, then one real ⇧⌘A call.

## Notes

Usage stats do not store prompts. Rebuild after changing Embedding when the UI says so.
