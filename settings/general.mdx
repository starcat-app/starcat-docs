## 通用设置

在 设置 → 通用中配置 Starcat 的基础偏好。

## Display Language

设置界面显示语言。支持的语言：

- English
- 简体中文

> 切换语言后应用需要重新加载界面。

## 主题 (Appearance)

| 选项 | 说明 |
|------|------|
| **跟随系统** | 自动切换明暗主题 |
| **浅色** | 始终使用浅色模式 |
| **深色** | 始终使用深色模式 |

## 界面字体倍率

调整整个应用的字体大小：

- 小 (0.85x)
- 标准 (1.0x)
- 大 (1.15x)
- 超大 (1.3x)

> README 正文、列表行高等均会联动缩放。

## 列表密度

控制仓库列表的间距：

- **Comfortable** — 宽松间距
- **Compact** — 紧凑间距

## 无障碍

### 关闭应用内动画

对动画敏感的用户可以关闭应用内动效。

## 重置

- **重置 Onboarding** — 重新显示首次使用引导
- **重置列表偏好** — 清除排序、筛选、密度等偏好
- **重置所有设置** — 恢复设置到默认值（不影响数据）
