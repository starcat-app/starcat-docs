## Entry

**Settings → General**

## Display

| Item | Description |
|------|-------------|
| Interface language | **18 languages**, including English, Simplified / Traditional Chinese, Japanese, Korean, and major European / Asian locales (full list in the picker) |
| Theme | Follow system / Light / Dark |
| Font scale | Small / Standard / Large / Extra large |
| List density | Comfortable / Compact |
| Reduce motion | Accessibility |

Font scale affects list readability, timelines, and some body text.

## Notifications

Enable the master notification switch, Release notifications, and related options. macOS must also allow Starcat in System Settings. See [Release notifications](/release/notifications).

## Reset

| Action | Effect |
|--------|--------|
| Replay first-run guide | Shows welcome again; resets Getting Started progress |
| Reset list preferences | Clears sort / filter / density preferences |
| Reset all settings | Restores defaults; **usually does not** delete tags and notes (confirm in the dialog) |

To wipe data, use [Storage](/settings/storage) — do not confuse it with reset settings.
