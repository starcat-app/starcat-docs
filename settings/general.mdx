## The job

You want the language, theme, and notifications to match how you work, and you want the "does this upload anything" switch to be obvious.

General settings are those everyday preferences. Anonymous public Star contribution is off by default. Cache clearing and factory reset are on [Storage](/settings/storage).

## How to use it

| Item | Detail |
|------|--------|
| UI language | 18 languages (see the picker) |
| Theme | System / light / dark |
| Font scale | Small / standard / large / extra; affects lists, timeline, some body text |
| List density | Comfortable / Compact |
| Reduce motion | Accessibility |

Release banners also need system permission. See [Release notifications](/release/notifications). Show Issue events inserts label / close / commit-ref rows between comments. Default is comments only. See [Activity](/discover/activity/activity).

Open repository docs in-app sends same-repo Markdown links to a separate window. Default is the browser. ⌘-click always uses the browser. See [Repository detail](/main-interface/repo-detail).

Anonymously contribute public Star data is off by default. See [Privacy](/data-privacy/privacy).

| Reset | Effect |
|-------|--------|
| Replay onboarding | Welcome again; reset Getting Started |
| Reset list preferences | Sort / filter / density |
| Reset all settings | Defaults; usually keeps tags and notes (follow the confirm sheet) |

## Direct Beta updates <DirectBadge />

You want to try a build that is not in the store yet, without pulling the store app onto that channel.

On Direct, open **Settings → General → Updates** and turn on **Include Beta updates**. The switch is off by default. The App Store build does not show this block. Its updates stay in the store.

Beta versions may include unfinished or unstable features. Turning the switch off keeps the installed version and waits for a newer stable build; it does not downgrade the app. Existing update preferences carry over when upgrading.

<DirectBadge /> You also want the people behind the repositories you starred on the screen when you step away, instead of a stock screensaver. Direct can install that avatar wall, then update or remove it in Settings. The App Store build does not offer this.

## Notes

Reset all settings restores defaults and usually keeps tags and notes. Factory reset is on Storage and is irreversible.
