## 入口

**设置 → 通用**

## 显示

| 项 | 说明 |
|----|------|
| 界面语言 | English / 简体中文 |
| 主题 | 跟随系统 / 浅 / 深 |
| 字体倍率 | 小 / 标准 / 大 / 超大 |
| 列表密度 | Comfortable / Compact |
| 减少动画 | 无障碍 |

字体倍率会影响列表、时间线、部分正文可读性。

## 通知

启用通知总开关、Release 通知等。还需系统设置允许 Starcat。见 [Release 通知](/release/notifications)。

## 重置

| 操作 | 效果 |
|------|------|
| 重看首次引导 | 再显示欢迎；重置 Getting Started 进度 |
| 重置列表偏好 | 清排序/筛选/密度等 |
| 重置所有设置 | 设置回默认；**通常不删**标签笔记（以确认框为准） |

清数据请用 [存储管理](/settings/storage)，不要和重置设置搞混。
