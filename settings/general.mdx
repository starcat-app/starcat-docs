## What it is for

**Settings → General** is the daily shell: language, theme, type size, notifications, and whether README docs open in-app. Clearing data belongs in [Storage](/settings/storage), not “Reset settings”.

## How to use it

| Item | Detail |
|------|--------|
| UI language | **18 languages** (see the picker) |
| Theme | System / light / dark |
| Font scale | Small / standard / large / extra; affects lists, timeline, some body text |
| List density | Comfortable / Compact |
| Reduce motion | Accessibility |

Release banners also need system permission. See [Release notifications](/release/notifications). **Show Issue events** inserts label / close / commit-ref rows between comments. Default is comments only. See [Activity](/discover/activity/activity).

**Open repository docs in-app** sends same-repo Markdown links to a separate window. Default is the browser. ⌘-click always uses the browser. See [Repository detail](/main-interface/repo-detail).

**Anonymously contribute public Star data** is **off by default**. See [Privacy](/data-privacy/privacy).

| Reset | Effect |
|-------|--------|
| Replay onboarding | Welcome again; reset Getting Started |
| Reset list preferences | Sort / filter / density |
| Reset all settings | Defaults; **usually keeps** tags and notes (follow the confirm sheet) |

## Notes

Reset settings is not factory reset. Factory reset lives on Storage and is irreversible.
