## 同步设置

管理 Starcat 的数据同步行为。

## GitHub Stars 同步

### 手动同步

点击工具栏的同步按钮，立即触发全量 Stars 同步。

### 增量同步

Starcat 使用智能增量同步策略：

- 首次同步：全量拉取所有 Stars
- 后续同步：ETag 缓存 + 增量检查
- 跳过未变化的页

### Rate Limit 处理

- 自动解析 GitHub API Rate Limit 响应头
- 触发限制时主动退避到 reset 时间
- 退避期间显示倒计时

### 后台同步

Starcat 支持后台定时同步（需要 macOS 后台任务权限）。

## CloudKit 同步 (Pro)

Pro 用户可将用户数据同步到 iCloud：

- **同步内容**：标签、笔记、状态、智能集合规则
- **不同步**：仓库缓存数据（README、AI 摘要等，这些可重建）
- **冲突解决**：基于时间戳的合并策略
- **删除保护**：CloudKit 保留 tombstone 记录

> CloudKit 同步需要 iCloud 账号和网络连接。
