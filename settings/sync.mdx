## What it is for

This page is **GitHub Stars → this Mac** only. iCloud sync for tags / notes is **not shipped**. Moving Macs means a [manual backup](/data-privacy/backup).

## How to use it

Toolbar sync: full pull the first time, then incremental / ETag. Getting Started asks you to tap it once. See [Quickstart](/getting-started/quickstart).

GitHub rate limits trigger backoff and a reset countdown. See [FAQ · Sync](/faq/sync).

Background checks may run when the OS allows (follow the app switch).

<Warning>
  CloudKit / iCloud user-data sync is not available. JSON import/export is also [coming soon](/share-export/data-export).
</Warning>

## Notes

Stars sync is not “tags go to the cloud”. Stars rebuild; tags do not.
