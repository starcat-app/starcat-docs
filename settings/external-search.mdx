## 外部搜索设置

在 设置 → 外部搜索中配置第三方搜索服务。

## Provider 管理

### 添加 Provider

点击「+」添加搜索 Provider：

1. 选择 Provider 类型（AnySearch / Tavily / Exa / Brave）
2. 输入 API Key
3. 点击「测试」验证
4. 保存

### 设置默认 Provider

勾选某个 Provider 旁的「默认」标记，Search Center 将默认使用该 Provider。

### 删除 Provider

点击 Provider 旁的删除按钮。需要二次确认。

## AI 聚合搜索

开启后，AI 对话中的外部上下文会同时从所有启用的 Provider 获取结果，聚合后提供给 AI。

> 需要 Pro 订阅。

## API Key 获取

各 Provider 的 API Key 获取入口在设置页面中有链接按钮。

## 缓存

外部搜索结果缓存到本地：

- 搜索缓存 TTL：6 小时
- AI 上下文缓存 TTL：24 小时
- 在存储管理中可清除缓存
