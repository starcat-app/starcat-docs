## What they are for

Bind Search Center, list search, AI, and RAG to keys you already use. Docs that said “⌘F opens global search” are outdated: **⌘K** is Search Center, **⌘F** is the current list.

## Common defaults

| Action | Default |
|--------|---------|
| Search Center | **⌘K** |
| Focus list search | **⌘F** |
| Refresh | **⌘R** |
| Repo AI overlay | **⇧⌘A** |
| RAG workspace | **⇧⌘K** |

Follow the settings page. Master and per-item switches can disable shortcuts without clearing recorded keys. **Restore default** appears only after you change a binding.

Usually you need a modifier plus a letter / digit. Occupied combinations are rejected.
