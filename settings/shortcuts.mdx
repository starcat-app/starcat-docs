## Purpose

Bind Search Center, list search, AI, and RAG to keys already in use. Default: ⌘K opens Search Center; ⌘F focuses the current list.

## Common defaults

| Action | Default |
|--------|---------|
| Search Center | ⌘K |
| Focus list search | ⌘F |
| Refresh | ⌘R |
| Repo AI overlay | ⇧⌘A |
| RAG workspace | ⇧⌘K |

The settings page is authoritative. Master and per-item switches can disable shortcuts without clearing recorded keys. Restore default appears only after a binding changes.

Usually a modifier plus a letter / digit is required. Occupied combinations are rejected.
