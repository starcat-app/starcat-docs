## Entry

## Agent Runtime

Starcat Direct can detect and configure Codex App Server and DeepSeek Harness from
this page. Follow the [external Runtime setup guide](/agent-workspace/runtime-setup)
before selecting a Runtime in Agent Workspace.

## Local API Key

Authenticates the local HTTP API for plugins on this Mac. Please:

- Rotate periodically (when the UI offers it)  
- Never commit it to public git  
- Use only on trusted local machines  

## Browser plugin

| Item | Description |
|------|-------------|
| Enable | Starts the plugin local service |
| Port / Token | Must match what the extension sends |
| Prerequisite | **Starcat must be running** |

Request shape: `http://127.0.0.1:{port}/plugin/v1/...` with `Authorization: Bearer <token>`.

See [Chrome](/browser-plugin/chrome), [Features](/browser-plugin/features), and [Safari](/browser-plugin/safari).

## Direct: CodebaseMemory and CodeFlow

**CodeFlow** is a 3D code graph for public repositories (Pro), opened from the list / detail toolbar. Private repos do not get this entry.

The Direct build no longer ships large bundled executables. Settings can auto-detect a current official install, or you can choose the executable or output directory yourself. If no compatible version is found, follow the on-page prompt to install or pick a path again. Graph startup reuses an account-level shared service so “already installed but not found” and port timeouts are less likely.

**CodebaseMemory** uses the same local official-install detection. The Mac App Store build cannot launch user-installed executables because of the sandbox.
