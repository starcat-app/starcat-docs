## Purpose

Settings → Integrations wires local companions: the plugin, web search, Direct Agent runtimes, and CodeFlow. GitHub Stars sync is under [Sync](/settings/sync). Self-hosted explore backends are under [Services](/settings/services).

## How to use it

Agent Runtime (Direct): detect Codex App Server and DeepSeek Harness. Read [Runtime setup](/agent-workspace/runtime-setup) before the workspace.

Local API key: auth for the plugin and local HTTP API. Rotate it. Do not commit it. Trusted Mac only.

Browser plugin: enable the local service; port / token must match; Starcat must be running. `http://127.0.0.1:{port}/plugin/v1/...` plus Bearer. See [Chrome](/browser-plugin/chrome).

External Search is configured here: web search and AI live context. See [External search](/search/external-search). The nav item [External search settings](/settings/external-search) points here.

Alfred / Raycast: [Desktop launchers](/integrations/desktop-launchers).

CodeFlow (Pro, public repos): 3D code graph from list / detail. No entry on private repos. Direct can detect the official local install or a manual path. CodebaseMemory uses the same detection. App Store cannot launch those user-installed binaries.

## Notes

Do not screenshot tokens into chat. App Store has no external Runtime / CLI launch.
