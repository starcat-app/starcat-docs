## 列表偏好

Starcat 的列表偏好按模块独立记忆，让你的浏览习惯得到保留。

## 排序偏好

每个模块（Manage / Explore / Weekly / Activity）独立保存排序设置。

可用的排序方式：

| 排序 | 适用范围 |
|------|----------|
| 默认 | 全部 |
| Stars | 全部 |
| 更新日期 | 全部 |
| 创建日期 | 全部 |
| 名称 | 全部 |
| 上升趋势 | Trending |
| OpenSSF 评分 | Manage（Pro） |

> 排序偏好跨启动持久化，下次打开自动恢复上次的排序方式。

## 感兴趣语言

在设置中管理你的感兴趣语言池：

- 从预设列表中选择语言
- 支持所有主流编程语言
- 按字母排序便于查找
- 语言池用于工具栏筛选

### 用途

- 工具栏语言筛选的候选列表
- Explore 模块的默认过滤
- Weekly 的语言筛选

## 重置偏好

设置 → 列表偏好 → 重置，恢复所有模块的偏好到默认值。
