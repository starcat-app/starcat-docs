## 关于 Starcat

在 设置 → 关于 中查看版本信息和致谢。

## 版本信息

- 当前版本号
- 构建号 (Build Number)
- 分发渠道（App Store / Direct）

## 系统原生关于窗口

按 `Cmd+I` 或从菜单栏 Starcat → About Starcat 打开系统原生关于窗口，其中包含 Credits（第三方库致谢）。

## 开源致谢

Starcat 使用了以下开源技术（完整列表见 About Credits）：

- **GRDB.swift** — SQLite 数据库
- **SwiftSoup** — HTML 解析
- **MarkdownUI** — Markdown 渲染
- **Sparkle** — 自动更新框架（Direct 版）
- 以及更多...

## 隐私政策

Starcat 的隐私政策可在 [starcat.ink/privacy](https://starcat.ink/privacy) 查看。

菜单栏 Help → Release Notes 可以查看版本更新日志。
