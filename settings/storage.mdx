## 存储管理

在 设置 → 存储中管理 Starcat 的本地数据。

## 缓存用量

查看各类缓存的磁盘占用：

| 缓存类型 | 说明 |
|----------|------|
| README 缓存 | 仓库 README HTML 和 Markdown |
| 图片缓存 | README 中的图片 |
| AI 对话历史 | 仓库 AI 助手对话记录 |
| RAG 会话历史 | 知识库 RAG 对话记录 |
| 外部搜索缓存 | 第三方搜索 API 缓存 |
| AI 摘要缓存 | 生成的 AI 摘要 |

## 清除缓存

- **清除单项**：点击某个缓存行的「清除」
- **清除全部**：点击「清除所有缓存」

> 清除 README 缓存后，下次打开仓库详情会自动重新下载。

## Finder 入口

每个缓存行旁的文件夹按钮可打开对应目录的 Finder 窗口（如果沙盒允许）。

## 危险区

### 恢复出厂设置

删除所有本地数据，包括：

- 用户数据（标签、笔记、状态）
- 仓库缓存
- AI 对话历史
- 设置偏好

<Warning>
  恢复出厂设置**不可逆**。操作前请确认已通过 CloudKit 同步或手动导出数据。
</Warning>

### 数据删除

删除本地数据库中的所有数据，保留应用设置。
