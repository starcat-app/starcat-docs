## What it is for

**Settings → Storage** shows cache size and lets you drop rebuildable rows. The danger zone deletes user data. Cloud sync and JSON export are not shipped. [Back up](/data-privacy/backup) first.

## How to use it

| Type | Detail |
|------|--------|
| README / images | Detail render; rebuildable |
| AI chat history | Single-repo overlay |
| RAG sessions | Knowledge Q&A |
| External search cache | Web search and AI context |
| AI summary cache | Generated summaries |
| Issue comments and events | Activity threads |
| Issue drafts | Unsent handwritten or AI replies |

Clear one row or all. README clears re-download on next open. Folder buttons reveal paths when the sandbox allows. App Store and Direct paths differ.

**Factory reset** deletes local user data and caches (follow the confirm copy). **Irreversible.** “Delete the database but keep settings” also needs a backup first.

## Notes

Clearing RAG sessions does not un-ingest. Clearing summaries only costs tokens next time.
