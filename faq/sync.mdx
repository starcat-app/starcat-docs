## What this is for

Stars will not pull, counts disagree, or you expected tags on a second Mac. Tag cloud sync is **not shipped**.

<AccordionGroup>
  <Accordion title="Sync failed?">
    Network → manual sync → rate-limit countdown → relaunch. See [Sync settings](/settings/sync).
  </Accordion>
  <Accordion title="What is a rate limit?">
    GitHub caps API frequency. Starcat reads the headers and backs off. Wait for reset, then sync.
  </Accordion>
  <Accordion title="A new Star is missing?">
    Sync again. Still missing: sign out and in for a fuller refresh.
  </Accordion>
  <Accordion title="Local Star count disagrees with GitHub?">
    Interrupted sync, deleted/private repos, or an unfinished pull. Manual sync or sign in again.
  </Accordion>
  <Accordion title="Do tags sync across two Macs?">
    User-data cloud sync is not shipped. [Back up by hand](/data-privacy/backup).
  </Accordion>
</AccordionGroup>
