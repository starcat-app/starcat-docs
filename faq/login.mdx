## Purpose

Login loops, rejected PATs, or the wrong list after switching accounts. App Store is Web OAuth only. PAT and Device Flow are Direct-only.

<AccordionGroup>
  <Accordion title="GitHub login never finishes?">
    1. Confirm [github.com](https://github.com) loads
    2. Sign in to GitHub in a browser, then authorize Starcat
    3. If the company network blocks the callback, Direct can use a PAT; App Store cannot
    See [Account connection](/getting-started/github-connection).
  </Accordion>
  <Accordion title="Getting Started never checks sync?">
    You must tap toolbar sync. See [Quickstart](/getting-started/quickstart).
  </Accordion>
  <Accordion title="Token / session 401?">
    Sign in again. PAT users mint a new GitHub token and paste it (Direct only).
  </Accordion>
  <Accordion title="How do I switch GitHub accounts?">
    Sidebar avatar → sign out → sign in. Data is isolated per account.
  </Accordion>
  <Accordion title="Which PAT scopes?">
    Classic: `read:user` + `public_repo`. Fine-grained: read user and public repo metadata as GitHub currently labels them. PAT UI is Direct-only.
  </Accordion>
</AccordionGroup>
