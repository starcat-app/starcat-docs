## What this is for

Doc-site language prefixes, so English URLs are not pasted into a Chinese issue by accident.

English is the **default** locale (unprefixed paths). Simplified Chinese lives under `/zh-Hans/...`. Use the header language switcher anytime. Missing nuance? [Tell us](/support/feedback).
