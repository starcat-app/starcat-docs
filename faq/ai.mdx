Locked AI, empty semantic search, or RAG that ignores the library. Attach screenshots in email, never API keys.

<AccordionGroup>
  <Accordion title="AI controls are locked?">
    You need Pro and a provider in Settings → AI. See [Purchase](/subscribe/purchase) and [Configuration](/ai-features/configuration).
  </Accordion>
  <Accordion title="I paid but nothing unlocked?">
    App Store: Settings → Pro → Restore. Direct: License and device seats. See [Restore](/subscribe/restore). Receipts do not cross channels.
  </Accordion>
  <Accordion title="Semantic search unavailable?">
    Pro plus a mapped Embedding and a built index. Chat alone is not enough.
  </Accordion>
  <Accordion title="RAG answers the wrong thing?">
    Confirm ingest and index coverage; @ the repos; check [citations](/knowledge-base/citations). Uningested Stars are outside default RAG.
  </Accordion>
  <Accordion title="Auto Tidy tags everything?">
    Turn it off, review confirm-before-write and the free 20-tag cap, then tighten actions. See [Auto Tidy](/ai-features/auto-tidy).
  </Accordion>
  <Accordion title="Index spins forever or pause looks like a network error?">
    Coverage and last prefetch live in [Settings → AI](/settings/ai). Pausing vectors is not "offline". External Meilisearch / Qdrant use their own test-and-save (green / amber / red). See [Index management](/knowledge-base/index-management).
  </Accordion>
</AccordionGroup>
