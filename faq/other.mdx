## 其他常见问题

<AccordionGroup>
  <Accordion title="应用崩溃了怎么办？">
    1. 重启 Starcat
    2. 如果持续崩溃，尝试导出诊断日志（菜单栏 Actions → Export Diagnostics）
    3. 将诊断日志发送给 dong4j@gmail.com
    4. 最后手段：恢复出厂设置（设置 → 存储 → 危险区）
  </Accordion>
  <Accordion title="如何清理缓存？">
    前往 设置 → 存储，查看各类缓存用量并清除不需要的缓存。详见 [存储管理](/settings/storage)。
  </Accordion>
  <Accordion title="应用很卡/内存占用高？">
    - 尝试清除 README 缓存
    - 关闭不需要的功能（如后台自动整理）
    - 减少活动窗口数量（Agent 工作台、RAG 工作台等独立窗口）
    - 重启应用
  </Accordion>
  <Accordion title="如何反馈问题或建议？">
    - 邮件：dong4j@gmail.com
    - GitHub Issues：在 Starcat 公开仓库提 issue
    - App Store 评分：附上你的建议
  </Accordion>
  <Accordion title="Starcat 会支持 Windows/Linux 吗？">
    目前 Starcat 仅支持 macOS。Windows/Linux 版本暂不在计划中。
  </Accordion>
  <Accordion title="如何更新到最新版本？">
    - **App Store**：通过 App Store 自动更新
    - **Direct**：通过 Sparkle 自动检查更新。你也可以在 设置 → 通用中手动检查更新。
  </Accordion>
</AccordionGroup>
