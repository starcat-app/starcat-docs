## Purpose

[`starcat-skill`](https://github.com/starcat-app/starcat-skill) describes CLI capabilities as a loadable Skill so Claude Code / Codex can search Stars / the knowledge base, read READMEs, and change notes, tags, and status under dry-run plus app authorization. It does not open SQLite.

## Prerequisites (all required)

1. Install the [CLI](/cli/installation)
2. Starcat running, [MCP](/settings/mcp) on, `starcat pair` done
3. Understand `--apply` and the app's write switches

Copy into the agent's skills directory per the Skill README (Claude / Codex paths differ).

| | Skill + CLI | In-app Agent workspace |
|--|-------------|------------------------|
| Runs | External agent terminal / session | Starcat window |
| Status | Ships with CLI/MCP | [Beta](/agent-workspace/overview) |
