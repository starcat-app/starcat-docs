## What it is for

[`starcat-cli`](https://github.com/starcat-app/starcat-cli) is a CLI and a **stdio MCP** bridge for agents. It does **not** open SQLite. Reads and writes go through the app’s MCP tools. Permission, dry-run, Pro, and audit stay in the **macOS Starcat app**. The app runs on a Mac; the CLI can live on that Mac or a trusted network to a paired app.

## Install

### Homebrew

```bash
brew tap starcat-app/starcat-cli
brew install starcat
```

Tap: [`homebrew-starcat-cli`](https://github.com/starcat-app/homebrew-starcat-cli).

### macOS / Linux script

```bash
curl -fsSL https://github.com/starcat-app/starcat-cli/releases/latest/download/install.sh | sh
```

Default `~/.local/bin/starcat` (`STARCAT_INSTALL_DIR` overrides). The script checks SHA-256.

### Windows PowerShell

```powershell
irm https://github.com/starcat-app/starcat-cli/releases/latest/download/install.ps1 | iex
```

## Pairing (required)

1. Starcat → **Settings → MCP** → enable. Needs [Pro](/subscribe/plan-comparison)
2. Copy the pair command; URI lasts about 5 minutes, single use
3. Terminal:

```bash
starcat pair "starcat-pair://connect?..."
starcat doctor
```

4. **Confirm the device** in the app. Unconfirmed pairing is incomplete. Or run `starcat pair` and paste the URI. Long-lived credentials go in the Keychain. See [MCP](/settings/mcp).

```bash
starcat --version
starcat doctor
starcat capabilities
```

## Notes

The App Store sandbox is not a generic CLI launcher. The CLI is a separate process and still needs a running app that can host MCP. Next: [Usage](/cli/usage), [Agent Skill](/cli/skill).
