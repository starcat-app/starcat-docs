## What it is for

The in-app **Agent workspace** is for multi-step work that calls tools: inspect repos, compare, and change local tidy data **after you authorize it**. It complements single-repo AI and RAG; it is not a third copy of the same chat.

It is **Beta**. The UI and tools will still move. This page documents shipped entry points and safety rails, not unreleased roadmap items as if they were buttons.

## How to use it

Requires [Pro](/subscribe/plan-comparison) and a working [AI configuration](/ai-features/configuration). External runtimes also need [Codex and DeepSeek setup](/agent-workspace/runtime-setup).

Open the Agent window, pick a Runtime, and send a **small** task first. Watch the timeline: thinking summary, tool calls, errors, artifacts. The task inspector adds structured steps and run metrics.

**Direct** can switch among built-in Loop, Codex App Server, and DeepSeek Harness. External runtimes are local child processes, not inside the DMG. **Mac App Store always uses the built-in Runtime** and cannot launch user-installed executables.

## Notes
