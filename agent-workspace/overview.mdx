## Agent 工作台 (Pro)

Agent 工作台是 Starcat 的高级 AI 功能，支持多步骤的自动化任务执行。

<Note>
  Agent 工作台的详细文档正在编写中，敬请期待。
</Note>

## 概述

Agent 工作台允许 AI 在你的授权下执行多步骤任务，例如：

- 批量整理未分类仓库
- 生成技术调研报告
- 多仓库对比分析

## 安全设计

与所有 Starcat AI 功能一样，Agent 工作台遵循保守策略：

- 需要你的明确确认才会执行修改操作
- 所有操作有审计记录
- 可以随时取消任务
