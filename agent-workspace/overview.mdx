## Role (Beta)

The in-app **Agent workspace** targets multi-step tasks with tool calls, complementing single-repo AI panel and RAG Q&A.

Currently **Beta**: UI and available tools still evolve; this doc covers enforced safety boundaries and entry points—not roadmap items like “research report generator” as if shipped.

## Runtimes (Direct)

Agent Workspace can switch among the built-in Loop, Codex App Server, and DeepSeek Harness. External runtimes run as local child processes and are not bundled in the Starcat DMG. The Mac App Store build always uses the built-in runtime.

Setup: [Runtime setup](/agent-workspace/runtime-setup). The execution timeline shows thinking summaries, tool calls, errors, and artifacts. The task inspector adds structured steps and run metrics.

## Prerequisites

- [Pro](/subscribe/plan-comparison)

## Safety (enforced)

- **Confirm before changing data**  
- Cancel in-flight runs  
- Key steps leave traceable information  

Aligned with Starcat’s conservative AI policy. See [AI overview](/ai-features/overview).
