## 购买渠道

Starcat Pro **现已开放购买**，任选其一即可：

| 渠道 | 适合谁 | 入口 |
|------|--------|------|
| **Mac App Store** | 希望用 Apple ID 管理订阅 | [App Store 页面](https://apps.apple.com/cn/app/starcat-for-github/id6788809803?mt=12) |
| **官网 Direct** | 从 [starcat.ink](https://starcat.ink) 下载 DMG 的用户 | 官网定价区，或 App 内「设置 → Pro」 |

<Note>
  两种渠道的 Pro 权益一致。价格以购买页实时展示为准（当前官网参考：月付 $3.99 / 年付 $29.99 / 买断 $39.99）。
</Note>

## App Store 购买

1. 从 [Mac App Store](https://apps.apple.com/cn/app/starcat-for-github/id6788809803?mt=12) 安装 Starcat  
2. 打开 **设置 → Pro**  
3. 选择 **Monthly / Yearly / Lifetime**  
4. 用 Apple ID 完成 StoreKit 支付  
5. 权益即时生效  

## 官网 / Direct 购买

1. 打开 [starcat.ink](https://starcat.ink) 或 App 内 **设置 → Pro**  
2. 选择方案并完成结账  
3. License 激活到当前设备（买断等方案受设备席位限制，见 [许可证管理](/subscribe/license)）  

## 购买后

- Pro 功能立即解锁  
- 侧边栏 / 设置页会出现 Pro 状态  
- 订阅制可查看到期日；买断为永久有效（需遵守设备席位规则）  

## 免费试用

目前不提供独立试用期。免费版已包含 Stars 同步、标签（有限额）、搜索等基础能力，可先使用再升级。
