## 恢复购买

更换设备或重装系统后，可以恢复之前的 Pro 购买。

## App Store 用户

1. 在新设备上使用**同一 Apple ID** 登录
2. 打开 Starcat 设置 → Pro
3. 点击「恢复购买」
4. Pro 权益自动恢复

## Direct 用户

1. 在新设备上安装 Starcat Direct 版本
2. 打开 设置 → Pro → 许可证管理
3. 登录你的账号
4. 选择可用设备席位激活

<Note>
  如果设备席位已满，需要先在旧设备上解绑。详见 [许可证管理](/subscribe/license)。
</Note>

## 常见问题

<AccordionGroup>
  <Accordion title="换设备后数据还在吗？">
    Stars、标签、笔记等数据可以通过 CloudKit 同步（如果开启了同步功能），或通过 JSON 导出/导入迁移。
  </Accordion>
  <Accordion title="买断版可以换设备吗？">
    可以。买断版 License 支持在有限数量的设备间切换。在旧设备解绑后即可在新设备激活。
  </Accordion>
</AccordionGroup>
