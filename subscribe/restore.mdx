## 恢复购买

更换 Mac 或重装系统后，可按渠道恢复 Pro。

## App Store 用户

1. 新设备登录**同一 Apple ID**  
2. 安装 [Starcat for GitHub](https://apps.apple.com/cn/app/starcat-for-github/id6788809803?mt=12)  
3. 打开 **设置 → Pro**  
4. 点击 **恢复购买**  
5. 权益恢复后即可使用 Pro 功能  

## Direct 用户

1. 安装 Direct 版（[starcat.ink](https://starcat.ink)）  
2. 打开 **设置 → Pro → 许可证**  
3. 按提示登录 / 输入 License  
4. 若席位已满：先在旧设备解绑，再在新设备激活  

详见 [许可证管理](/subscribe/license)。

## 常见问题

<AccordionGroup>
  <Accordion title="换设备后标签和笔记还在吗？">
    用户数据（标签、笔记、状态等）目前保存在本机。换机请先手动备份 Application Support 目录，或等待后续的跨设备同步能力。详见 [备份与恢复](/data-privacy/backup)。
    Stars 列表可随时从 GitHub 重新同步，无需备份。
  </Accordion>
  <Accordion title="买断可以换设备吗？">
    可以。Direct Lifetime 支持本人使用的最多 2 台 Mac；超出需先解绑旧设备。App Store 买断遵循 Apple 账号与设备规则，优先使用「恢复购买」。
  </Accordion>
  <Accordion title="App Store 和 Direct 的购买能互通吗？">
    不能自动互通。请在对应渠道恢复：MAS 用恢复购买，Direct 用 License。
  </Accordion>
</AccordionGroup>
