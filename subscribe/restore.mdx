## Purpose

After a new Mac or reinstall, Pro does not come back with GitHub Stars sync. Restore on the same channel you bought. Tags and notes still live in the old machine’s local database. See [Backup](/data-privacy/backup).

## How to restore

App Store: same Apple ID on the new Mac → install [Starcat for GitHub](https://apps.apple.com/cn/app/starcat-for-github/id6788809803?mt=12) → Settings → Pro → Restore purchases.

Direct: install Direct ([starcat.ink](https://starcat.ink)) → Settings → Pro → License → sign in / paste the License. If seats are full, unlink the old Mac first. See [License](/subscribe/license).

## Notes

User data (tags, notes, status) is on-device today. Back up Application Support before you move, or wait for unshipped cross-device sync. Stars can be pulled from GitHub again.

Direct Lifetime is 2 Macs for personal use. Unlink extras. App Store Lifetime follows Apple’s account rules; prefer Restore.

App Store and Direct do not restore each other.
