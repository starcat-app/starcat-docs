## 两种授权方式

| | Mac App Store | Direct（官网） |
|--|---------------|----------------|
| 支付 | Apple / StoreKit | 官网结账 |
| 凭证 | Apple 订阅 / 买断交易 | License |
| 换机 | 「恢复购买」+ 同一 Apple ID | 解绑旧设备 → 新设备激活 |
| 设备 | 遵循 Apple 订阅规则 | Lifetime 等：本人最多 **2** 台 Mac |

## Direct：激活许可证

购买后，License 通常会自动绑定当前设备。也可在 **设置 → Pro → 许可证** 中查看状态与设备列表。

## Direct：设备席位

- 查看已激活设备  
- **解绑**：释放席位后再在新 Mac 上激活  
- 席位已满时无法在新设备启用 Pro，需先解绑一台  

## 许可证状态（Direct）

| 状态 | 说明 |
|------|------|
| **有效** | Pro 可用 |
| **已过期** | 月付 / 年付未续费 |
| **席位已满** | 已达设备上限 |
| **已解绑** | 本机已移除授权 |

## 离线使用（Direct）

- 启动时从本地恢复权益  
- 定期静默校验  
- 异常或过期时提示重新验证  

## App Store 用户

无需手动管理 License。换机或重装后用同一 Apple ID，在 **设置 → Pro → 恢复购买** 即可。详见 [恢复购买](/subscribe/restore)。
