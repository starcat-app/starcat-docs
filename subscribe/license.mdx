## 许可证管理 (Direct)

Direct 分发版本使用 License 机制管理 Pro 授权。

## 激活许可证

购买 Pro 后，License 自动激活到当前设备。

## 设备管理

- 查看已激活的设备列表
- **解绑设备**：在设置中解绑不用的设备，释放席位
- **授权中心**：管理所有许可证

## 许可证状态

| 状态 | 说明 |
|------|------|
| **有效** | License 有效，Pro 功能正常 |
| **已过期** | 订阅到期（年度订阅未续费） |
| **席位已满** | 激活设备数达到上限 |
| **已解绑** | 设备已被移除 |

## 离线使用

Direct License 支持离线验证：

- 启动时从本地恢复权益
- 定期静默校验
- 过期或异常时提示更新

## App Store 用户

App Store 用户无需管理 License，订阅状态由 Apple 自动维护。使用「恢复购买」即可在新设备恢复。
